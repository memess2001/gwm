## 执行方式与卫生规则

每一个结论都经过了一个"任务就是推翻它"的独立 agent。下面是流程、约束和一处需要如实交代的偏离。

**环境。** 工作在 claude.ai 的云端容器里完成：4 核 CPU、15 GB 内存、没有 GPU。这不是 HANDOFF 写的 Mac mini 或 3080 笔记本，所以预算要重新分配（见对照组一节）。代码不区分设备，在 CPU、MPS、CUDA 上都能直接跑。

**流程（用多 agent workflow 编排）：**

1. **建造 → 审稿。** 动物园、对照组、测量仪器各有一个 builder 和一个独立审稿人。审稿人故意换一种方法重写检查，并做变异测试：在代码副本里注入已知 bug，看测试是否报错。动物园注入 11 类、对照组注入 13 种，全部被抓到。
2. **文献第二轮。** 5 路并行：格 10 | 7+9 | 6+12+2 | 3+15+总体项 U | 0+1+4+8。合计约 155 次检索，决策关键的引用都核对了原文。
3. **思想实验 → 怀疑者。** 格 0、1、3、7、9、15 的思想实验结论（格 3 的论证来自文献第二轮）各交给一位独立的怀疑者去推翻，允许做小的数值实验；格 6 的逻辑修正在预注册审稿时一起审。
4. **预注册 → 找漏洞的审稿人。** 格 0、格 6 各一位。

**卫生规则：**

- **没有跑任何 kill test。** 按 HANDOFF §0 的约定，预注册要先给 Z 看。
- 格 0 的结局量（潜空间上的持续同调、能量探针、接缝比）只在真值嵌入上算过，用于校准。唯一的例外是下面披露的 pilot。
- 对照组的训练脚本只记录损失，禁止在里面做持续同调或探针。

**需要如实交代的偏离：一次非盲 pilot。**

负责格 0 的怀疑者在 Z 批准预注册之前，用自己写的小模型做了一次复现：约 5 万参数，4000 步，3 个种子，测的是 angle\_raw 上的"粘合"。

- 原预测 P0.3 / P0.4 写于 pilot 之前，没有改动。
- pilot 引出的设计修正和新增的 P0.4′ 都标了"非盲"。
- 预注册审稿人进一步指出这份披露还不完整：计分方式在 pilot 之后变了，pilot 的摘要表也有不准确的地方。这两点都已列入格 0 的 v2 修订，审稿人还建议训练前用哈希冻结预注册和分析代码。

**其他：**

- 中途两次碰到用量上限（5 小时上限和周上限），都从缓存续跑，没有丢结果。
- 所有结果已推到私有仓库 `memess2001/gwm`。第一次提交是原始的三个文件（HANDOFF v0.3、cells.yaml v0.3、第一轮审计），第二次是这一轮的全部结果，所以 `cells.yaml` 从 v0.3 到 v0.4 的改动可以直接 diff。

## 动物园：三个世界与建造中发现的真值问题

动物园的三个世界都建好了，每条真值都有两套互相独立的测试核对：builder 写了 64 个，审稿人另写了 63 个并做了变异测试。建造过程本身就挖出了 6 个影响各格设计的真值问题。所有世界都由 `zoo.make(name)` 创建；`sample(seed, …)` 是种子的纯函数；`ground_truth(**cfg)` 按采样配置给出真值。

| 世界 | 观测模式 | ground\_truth 给出什么 | 关键约定 |
| --- | --- | --- | --- |
| pendulum | angle\_cs、angle\_raw（在 ±π 处有意撕开）、pixels64 | 采样区域的 Betti 数（分初态与轨迹两种）、绕柱面的 H₁ 个数、能量、散度 −2γ、向量场 | θ = 0 朝下；θ'' = −ω₀² sin θ − 2γθ' + u；Verlet 积分，1000 步的相对能量漂移 6.7e-6；渲染平滑且单射，约 1 万帧/秒 |
| toggle\_grid | grid、pos | 开关进入次数的 Z₂ 和乐、小方格曲率图、每个房间的不确定位数、瓶颈格 | 进入开关格即翻转门；默认门隐藏；新增 `switches_enabled`、`switch_visible` 两个对照选项 |
| wright\_fisher | freq、counts、logratio | 逐步的机制标签、α 标签、θ/η 坐标、势函数、RPS 守恒量、精确的 Hodge 判据 | Amari 约定：α = +1 为 e，−1 为 m（Koide 的号相反）；要求 K ≥ 3 |

**建造中发现的真值问题**（都已写进对应格的 notes）：

1. **格 0 的"H1 = 1"有歧义。** 只采摆动能量环时也得到 b₁ = 1，但这个圈在柱面里可以缩成一点。ripser 测得的持久度是 1.54，与真柱面圈的 1.49 同量级。所以判据必须测"绕柱面"。另外，"采样区域"要分初态和轨迹扫过的区域：E\_lo = 2.5 时前者是 \[2,0\]，后者是 \[2,2\]。
2. **格 0 的负对照离分界线太近。** 能量窗 E ∈ \[−1, 0.8\] 在真值嵌入上就会产生长 0.46–0.52 的伪 H1 条（真环带是 1.47）。改为 E\_hi ≤ 0.5 后，伪条只有 0.14。
3. **格 2：迁移也是 Fisher 梯度流。** 迁移 μ(m−x) 和均匀突变都是 Shahshahani 度量下的精确梯度流，势为 −μ·KL(m‖x)。因此"带突变的落在中间"对均匀突变不成立，而且 Hodge 分不出选择和迁移。这一条有两个独立来源：zoo agent 和文献第二轮的 R3 各自推导并做了数值核对。
4. **格 6 的标签与对照。** 经过开关的随机环路里，有 29.5% 进入偶数次，和乐恰为 0，所以标签应取奇偶。"全可观测时 AUC ≈ 0.5"只对观测闭合的环路有定义。不确定位数随所在房间而变。观测里开关格是画出来的。
5. **格 7 的上限。** 约 10% 的随机 20 步段在两个坐标系里都几乎是直的。counts 观测取 n\_obs = 1000 时，每步噪声（0.0165）和每步增量（0.0188）差不多大。
6. **格 8 的判据无定义。** 确定性阻尼摆的相体积收缩率处处等于 −2γ，和一个常数算 Spearman 没有定义。

审稿人还修了 3 个真 bug，默认配置都不受影响：自定义 payoff 时 RPS 的 Hodge 标签与"闭轨"声明有两处错误，angle\_raw 在 float32 下有一处端点问题。

## 对照组世界模型与算力预算

对照组已建好并经过审稿，审查范围内没有发现 bug。但实测预算显示，HANDOFF 里的完整设计在这台 4 核 CPU 上需要约 320 机时，所以必须分阶段，大模型交给 Mac 或 3080。

**结构**

- 编码器 E：低维观测用 MLP；像素用步长 2 的卷积栈（64 → 32 → 16 → 8 → 4）。
- 转移 F(z, a)：残差 MLP。
- 解码器 D。
- 三个变体的编码器和转移完全相同：
  - **recon**：对开环 rollout 的 j = 0..K 步都做重建，再加 0.1 倍的潜一致性项（目标取 stop-gradient）。
  - **jepa-sym**：VICReg 式的对称损失，权重 25 / 25 / 1，梯度流过两支。
  - **jepa-sg**：目标取 stop-gradient，VICReg 只作用于在线那一支。这是格 0 的 pilot 显示 stop-grad 与否至关重要之后拆出来的。
- 尺寸阶梯 S / M / L / XL，对应总参数约 0.1M / 0.5M / 2M / 8M。同一尺寸下各变体宽度相同，所以 jepa 的参数量只有 recon 的 50–67%。
- 格 6 用的整段开环训练：`--anchors episode --history 1 --horizon 63`。

**建造过程中的发现**

- 像素解码器原先用 sigmoid 输出，因为背景大部分是黑的，输出饱和，模型卡在"输出平均图像"上。改成线性输出后，像素 recon S 在 1500 步内 val nmse 从 0.97 降到 0.14。
- jepa-sg 起步慢：像素 S 训练 1000 步时，预测还不如直接复制 z\_t；3000 步时，k = 8 的误差是 0.0075，复制基线是 0.96。所以 gate 里加了"预测误差 < 复制误差"这一条。
- 审稿人加固了 4 处：MPS 上的 float32 转换、拒绝把真值状态当作观测、circular 损失只允许用于 angle\_raw、载入检查点时不消耗全局随机状态。另有 12 个新测试，13 种变异全部被抓到。

**吞吐实测**（秒/步，batch 128，机器空闲时；表内为 4 线程 / 1 线程）

| --- | --- | --- | --- | --- |
| angle\_cs recon | 0.013 / 0.016 | 0.024 / 0.050 | 0.052 / 0.144 | 0.151 / 0.481 |
| pixels64 recon | 0.159 / 0.472 | 0.338 / 1.08 | 1.01 / 3.57 | 3.71 / 12.3 |
| pixels64 jepa-sym | 0.082 / 0.259 | 0.219 / 0.658 | 0.70 / 2.21 | 2.15 / 7.86 |

**预算**（每次 20k 步，按本机速度）

- 格 0 的 angle 部分：111 次运行，约 17.5–17.9 小时。
- 格 0 的像素部分：45 次运行，约 172–187 小时；其中单个 XL 运行就要约 21 小时。
- 格 6 的原设计：90 次运行，约 129–131 小时。草案里写的"每次约 5 分钟"是错的，实测 S 尺寸约 36 分钟。经审稿缩减为 k = 1、S + M 后，约 5 小时。
- 本机 12 小时内放得下：格 0 的 angle S/M/L、负对照、K = 1 副因子，再加像素 S，共 99 次，约 10.5–11.8 小时。只有 3 个空闲核时约 14–16 小时。
- 一个坑：只要有一个核被占着，4 线程运行就会慢 125 倍（OpenMP 超订）。所以并行方案一律用单线程。
- MPS 的速度还没有测；小 MLP 在 MPS 上未必比 CPU 快。

## 格 0 的测量仪器与校准

六件仪器都只在真值嵌入上校准，分拟合、留出、新种子确认三段，种子和决策互不重叠，并经过两轮审稿。只有接缝比在预注册审稿里又踩到一个校准没覆盖的区域，必须先修。详细数字见 `cells/0/calibration.md`。

| 仪器 | 判据 | 已知错误率 | 看不见什么 |
| --- | --- | --- | --- |
| H₁ 计数 | FPS 取 n = 600 点；数 death/birth ≥ 2.8 的 H₁ 条；4 次"随机半数 + FPS"子样本全票一致。τ 与 n 绑定：n = 300 时为 2.2，n = 1000 时为 3.2 | 新种子确认：正对照 280/280，负对照 140/140。按图计 TNR 区间为 0.974–1.00，按重复计下限为 0.83 | 圆方向只有 ω 方向的 1/10 或更薄时检不出；b₁ 是"分辨率 n 下的 b₁"；不区分环是否绕柱面 |
| 绕柱面 | 用顶类的 Z₄₇ cocycle 调和化得到圆坐标（de Silva et al. 2011）；与真值 θ 的 Fisher–Lee 圆相关 \|ρ\| ≥ 0.5 | 确认集 200/200 与 40/40。绕柱面的类 ≥ 0.93，只摆动的环 ≤ 0.09 | 要用真值 θ，只能在分析阶段用。审稿人核对：85,180 个三角形上 cocycle 零违反，结果对旋转和缩放逐位不变 |
| 能量可解码 | kNN R² ≥ 0.966（k = 10，n = 2000），并且冻结的二次岭回归 R² ≥ 0.972 | 两条同时满足：留出 88/100，即约 12% 假阴性；在撕开的图卡上假阴性达 50% | 沿能量对称性（θ → −θ，ω → −ω）的折叠；"可解码"不等于"被模型使用"。线性探针在真值图上只有 0.15，所以只作描述 |
| 能量平滑 | 局部 Lipschitz 尾比 q99/q50 ≤ 4.13 | 平滑对照 98/100；非平滑对照 1/70 被误判为平滑 | 5% 以上的噪声也会被判"不平滑"；少于 1% 边的撕裂看不见 |
| 接缝比 SR | 切口两侧（ω 匹配）的潜距离，除以其他 θ 处同样角间隔的距离；SR > 5 为撕开 | 粘合最大 1.21，撕开最小 26.3。新种子上粘合 180/180、撕开 160/160 判对 | 见下方第一条 |
| θ 可解码 gate | 从潜变量回归 cos θ、sin θ 的 kNN R² ≥ 0.99，n = 8000 | 大约拒掉折叠了 5% 以上状态的潜空间。n = 2000 时会误拒 ω 主导的单射潜空间 | n = 8000 是审稿人看过探索性种子后提出的，新种子上只有 20 个重复 |

**待修和已知的陷阱：**

- **接缝比必须先修。** 预注册审稿人在真值上找到两个校准没覆盖的区域，都会让 SR 偏向"粘合"：
  - history = 2 的窗口里，切口附近有 33–36% 的窗口两帧横跨切口。一个"错位撕开"的潜空间（H1 = 0）会读出 SR 2.8–4.9，而且所有旗标都不报警，这正好是 pilot 里 jepa-sym 的读数特征。
  - ω 各向异性 κ < 10 时，撕开的弧会读出 SR 2–5。
  - 修法：只用不跨切口的窗口计算（真值上，错位撕开 → 44–46，粘合 → 1.01）；匹配容差随 κ 自适应；在"间隙 × κ"网格上重新校准。
- 二阶折叠（例如 (cos θ, ω)）接缝比看不见，所以"粘合"的判读必须同时过 θ gate。
- Bobrowski–Skraba 显著性检验不采用：它在随机子采样下零分布近似成立（实际 3.5%，名义 5%），但功效低，n = 1000 时正对照只认出 117/140；在 FPS 下零分布失效。
- 汇总的二项分布区间把每张图当作独立试验，偏窄。同一重复里的对照共享状态，误差相关，所以也要报告按重复计的下限。

## 文献第二轮：等级变化与漏掉的最近邻

第二轮补齐了第一轮到预算耗尽时没来得及跑的搜索词，结果是五格改了等级。第一轮自己标出的三个盲区里，格 10（零次搜索）和格 15（只靠 HF 索引补查）都漏了关键近邻；格 7（只搜了两次）补查后仍然是空的。全文在 `literature_audit_round2.md`，原始输出在 `results/lit_round2_raw.json`。

| 格 | 等级 | 漏掉或新出现的最近邻 | 对设计的影响 |

### 格 0：重建型 WM 的 H1 几乎由定理保证

**论证（单射性）。** 设解码器能从 z\_t 重建当前帧，误差小于图像流形的 reach。那么 π = frame⁻¹ ∘ D 是潜点云到 S¹ 的连续映射，π ∘ E 与数据环带到 S¹ 的投影同伦，所以 H₁(潜点云) → H₁(S¹) 是满射，b₁ ≥ 1。angle\_cs 同理，此时 π = atan2 ∘ D。有信息量的只剩两种情况：angle\_raw（输入在 ±π 处撕开）和没有解码器的 JEPA。

**原来的方向性预测：** angle\_raw 上，P(b₁ = 1 | JEPA) > P(b₁ = 1 | recon)。

**审稿：成立，有保留；方向性预测没有得到支持。**

- 论证要改写成三个条件：数据区含一条 θ-环绕数非零的环（审稿人构造了阻尼螺旋带的反例，只说"覆盖 S¹"不够）；解码角的逐点误差 < π；有限样本下只保证存在一条 VR 条，不保证它最显著。
- 有限样本下，"连续解码器做不到跳变"是错的：MSE 解码器可以把 2π 跳变放进输入切口在潜空间留下的空隙里。

### 格 1：解码器拉回只看渲染，修正方案也被推翻 → thought\_killed

**我的论证。** 高斯解码器 p(o|z) = N(μ(z), σ²I) 的 Fisher 拉回是 g = J\_μᵀJ\_μ/σ²，也就是解码器均值的欧氏拉回，完全由渲染决定。反例是一个墙不画出来的点迷宫：曲率图处处为零。如果把墙画出来，"曲率 = 障碍"又会因为遮挡伪迹而通过。第一轮审计给格 1 的 must（度量钉在 p(o|z) 的 Fisher 拉回上）解决了可辨识性，却让读数看错了对象。我提的修正是改用预测分布的拉回 g\_k = Σ\_{j≤k} J\_{F^j}ᵀ g\_obs J\_{F^j}。确定性动力学下，它就是有限时间 Cauchy–Green 张量（FTLE / LCS）。

**审稿：前半成立，修正方案被推翻。** 脚本在 `cells/1/exploratory/`。

- **前半成立。** 平坦俯视渲染下，拉回度量在隐形内墙处精确平坦，偏差 ≤ 1e-7。可见墙只通过合成起作用：遮挡或 alpha 混合会造出约一个斑宽的伪带，加性渲染完全没有。图像边框本身也像一个遮挡物。
- **体积守恒的接触看不见。** 平直墙上的弹性反射，或 toggle\_grid 用的"受阻就原地不动"：流映射 Jacobian 几乎处处是正交阵或单位阵，C\_k 在墙面上等于自由空间的值。
- **耗散接触也救不回来。** 滑动、停止、非弹性接触才让 C\_k 变化，而且表现为单侧压缩带（λ\_min 和 log det 下降），不是峰。
- **平凡基线同样做得到。** 非几何的"位移亏损" ‖F^k(z) − 自由飞行预测‖ 在 6 种接触规则下都点亮同一条带，IoU 0.91–0.98。数据密度也恰好在压缩处堆积（1.84×，远处 0.95×），这正是 Liouville 定理：压缩 ⟹ 堆积。所以修正方案过不了它自己的 kill test。
- **不变性。** log det C\_k 本身不是不变量。相对量 log det(g\_obs⁻¹ C\_k) 是不变的，但它等于 2∫div\_ν f，正好是格 15 的解码器体积散度，于是继承了同样的相机依赖。
- 剩下的窄缝是：带 reject 规则的薄墙，或弯曲的弹性障碍上，C\_k 能否同时打败位移亏损图和密度图。这撑不起"曲率即规律"。

### 格 3：WFR 的搬运 / 改权读数只是 ∂tρ 的频谱滤波 → thought\_killed

论证来自第二轮文献的 R4 路，我复核了线性化部分。

- 任何基于密度的 WFR 分解只依赖密度曲线 ρ\_t。一个刚性平移的 Lenia glider，与一个同形同速的 Flow-Lenia glider，密度曲线相同，δ-谱也就相同。机制真值从密度上不可辨识。
- 在近均匀密度下线性化，最小作用解为 v = −∇φ、g = −φ/δ²，波数 k 上的搬运占比 = k²δ²/(1 + k²δ²)。
- 能从 ρ\_t 辨识的只有质量收支，这是平凡量。

**审稿：成立，并给出精确形式。** 脚本在 `cells/3/exploratory/`。

- share(δ) = 1 − d ln WFR²/d ln δ²。它在 L\_ρ = −ρ⁻¹∇·(ρ∇) 的特征基里是对角的，模式份额为 λδ²/(1 + λδ²)。近均匀时，δ-谱等价于 ∂tρ 的归一化功率谱，所以"δ-谱打败平凡基线"这条复活路几乎走不通。
- 真实 Orbium 在 δ = w 处读出 62% 搬运，纯属运动学。原预测还有别的失败：纯搬运在 δ \~ w 时份额 < 1；呼吸振子的份额比 glider 还高。
- 标签更正：标准 Lenia 不是"纯逐点改权"，而是带截断的加性局部源，能在 A = 0 处造质量，应改称"纯局部源、无通量"。
- 复活路线比我原来写的宽：给定共享生长场作为生成器先验，在被动帧上做结构模型选择（把 ρ̇ 分别对反应形式和守恒形式回归），就能精确识别机制，残差 1e-16。但那是方程发现，不是 WFR，所以仍记 thought\_killed。

### 格 7：连续 α-计被计算杀掉 → thought\_killed

- **成立的部分（计算）：** α-测地线 ⟺ x^((1−α)/2) 张成过原点的二维子空间。数值验证到 1e-11，对时间参数化不变。α-Flow 的附录 B 从另一方向也给出了同样的秩 2 刻画。
- **被杀的部分：** 混合动力学（选择 + 迁移）的 α̂ 对选择占比 ρ 不单调。全局拟合的 Spearman 为 0.29，逐点为 0.42，读数有一半落在 \[−1.2, 1.2\] 之外。

**审稿：成立，有保留。** 原因是结构性的：混合轨迹在 w = 0 附近的一阶响应对适应度向量 f 是奇函数，所以任何光滑、参数化不变的 α 读数都会在一半方向上先跌到 −1 以下。审稿人试了 9 种读数，Spearman 只有 0.27–0.64。

我原来写"只剩二分检验"说得太重。还剩一个分级的 e/m 残差对比，Spearman 0.75–0.78，但不严格单调；它是一个软分数，不是 α。二分 e/m 检验（Fujiwara 1993 级的旧结论）、r\_min（"不是直线"的检测）和这个软分数，都并入格 2 当工具用。

### 格 9：σ 恒定时 Fisher 弧长等于白化欧氏弧长；风险是假性存活

**我的论证。** 对角高斯后验的 Fisher–Rao 线元是 ds² = Σ\_i (dμ\_i² + 2dσ\_i²)/σ\_i²。σ 贴在下限不动时，ds 只是 μ 的固定加权欧氏速度，所以"Fisher 弧长时间"就是缩放后的欧氏弧长时间（TOTR）。按格 9 自己的判据，它在确定性世界里必死。

**审稿：核心成立，结论方向要改。** 脚本在 `cells/9/exploratory/`。

- σ 恒定时，Fisher 弧长等于**白化**均值 μ\_i/σ̄\_i 的欧氏弧长，而不是原始潜空间的欧氏弧长。只要 σ̄ 各向异性，Fisher 时钟就会假性胜出原始欧氏时钟。确定性单摆上的高斯 RSSM 实测：比原始时钟低 0.031，CI 为 \[0.022, 0.041\]；与冻结 σ 时钟只差 0.004，不显著。所以风险是"假性存活"，不是"必死"。
- σ 变不变由观测通道决定，与动力学是否确定无关。"单摆、Lorenz 不能用"应改为"让差异检验来决定"。
- 我把"σ 贴下限"归到 DreamerV3 的 min\_std，这是错的：DreamerV3 用的是类别潜变量。
- 修正后的设计：欧氏基线用冻结 σ 的白化弧长；所有时钟用同一种离散化；前置 gate 改为"Fisher 时钟与冻结 σ 时钟的配对差必须排除 0"。

### 格 15：局部散度图依赖体积形式；仿射相机无害，射影相机造假，对称化可修

**我的论证。**

1. 潜空间做微分同胚 φ 之后，散度改变 f·∇log|det Dφ|，所以局部散度图不是规范不变量。
2. `cells.yaml` 的候选一是平稳密度 ρ。对确定性流，平稳性 ∇·(ρf) = 0 给出 div\_ρ f ≡ 0，读数恒为零。
3. 候选二是解码器拉回体积 ν，此时 div\_ν f = 真散度 + F·∇log ν。只重建当前帧的解码器不依赖 ω，拉回体积是退化的，必须用多帧解码。单摆两帧观测下 ν = dt · a(θ) · a(θ − ω dt)，其中 a(θ) = ‖∂frame/∂θ‖。只要 a 随 θ 变，一个完全保守的单摆就会显示假耗散 ≈ 2ω · ∂θ log a(θ)。它对 ω 反对称，沿轨道平均为零。
4. 规范不变的只有轨道平均散度，即 Lyapunov 指数之和，它已被 Wang 2026 占住。

**计算**（`cells/15/exploratory/fake_divergence.py`）。用 zoo 的单摆渲染器，加一个绕水平轴倾斜的射影相机（倾斜强度 k）。k = 0 时假散度为 0；k = 0.3 时低频部分 RMS 为 0.54；k = 0.6 时为 0.92。作为对照，γ = 0.05 的真实阻尼散度是 −0.1。

**审稿：核心数学成立，但我的"Klein 层级"说法是错的；另外找到一个建设性修法。** 脚本在 `cells/15/exploratory/reviewer/`。

- Gram 公式精确成立，不需要正交性假设。
- 由 a(θ)² = ∫|∂θ I\_src|² · |det DH| ds，只要面积 Jacobian 在扫过的环带上恒定，a 就是常数。所以：
  - 欧氏、所有仿射相机（含斜视正交投影）、以支点为中心的径向畸变：都不造假散度；
  - 透视倾斜、偏心畸变、裁切、非均匀背景：会造。刚体相机加上背景亮度梯度，假散度就有 0.26。
  - 因此 camera\_ladder 的预测应改为"欧氏 ≈ 仿射 ≈ 0，射影 ≠ 0"，格 14 与格 15 的合并理由变弱。
- **数字修正。** 用解析扭曲加超采样重算：k = 0.3 时 RMS 0.47、最大值 1.2；我报的 0.54 / 1.78 混进了双线性重采样的莫尔纹。假散度 RMS ≈ 1.57k；k ≈ 0.064（60° 视场下约倾斜 6°）时，假信号就和真信号一样大。
- **学到的解码器**会继承相机项（还放大 10–20%），再加上它自己的一项：等变渲染器上，重建误差 10% 时约 0.1 RMS。所以解码器拉回图必须先在保守世界上标定。
- **建设性修法。** 对称帧窗下，假项对时间反演 T 严格为奇，摩擦型耗散对 T 为偶。所以不需要标签，只要做"窗口反演对称化"，就能把假项压到信号的 3% 以下。这可能是格 15 剩下最有新意的方向。
- **"解码到物理坐标、用 Lebesgue 体积"并不普遍可行。** 只有质量矩阵为常数时，Lebesgue 体积才是 Liouville 体积。保守双摆上，Lebesgue 散度的 RMS 达到 0.93，刚体渲染的解码器拉回反而接近正确（det g ∝ det M）。探针导数只要有毫弧度级的误差，也会造出 0.11–0.29。有物理意义的"耗散地图"得相对一个学到的辛 / Liouville 结构来算，这会把格 15 推向 D-HNN、GENERIC、Zhu 2025 的地盘，新颖度进一步下调。

原版问的是：MLP 世界模型的潜空间会不会自发出现 S¹×ℝ，能量能不能平滑解码。由于单射性论证，recon 在 angle\_cs 和像素上的 H1 降为仪器与定理检查（P0.1）。新的问题是：**潜空间的拓扑由谁决定？输入的编码、输出损失的几何，还是动力学？** 原版的预测保留，照常打分。

文献定位：前提已被部分测过，但都是目测（Ivashkov 2026 的 PCA 环面，DySIB 2026 在十个种子里挑最好的 R² 环形，Bao 2026 在 DreamerV3 里找到的类能量不变量）。两个问题是零命中的：WM 潜空间持续同调的定量、跨种子、跨尺寸测量；原始 wrapped 角度在无解码器训练下会不会被粘成圆。还要写明一点：S¹×ℝ ≅ ℝ²∖{0}，二维及以上的欧氏潜空间本来就能无切口地承载单摆，所以出现 H1 不说明需要几何约束（Kvalheim & Sontag 2025）。

### v1 锁定的设计

- **世界**：pendulum，ω0 = 1，γ = 0，无动作，dt = 0.1。主数据用 box 采样，omega\_max = 2.5，采样区域是环带（真值 b₁ = 1）。负对照取能量窗 E ∈ \[−1, 0.5\]，只含摆动，区域是圆盘（b₁ = 0）。E\_hi 从 0.8 改到 0.5，因为 0.8 时真值嵌入上会出现长约 0.5 的伪 H1 条（真环带的条长是 1.47）。
- **条件**：angle\_cs × {recon, jepa-sg, jepa-sym}；angle\_raw × {recon-mse, recon-circular, jepa-sg, jepa-sym}；pixels64 × {recon, jepa-sg, jepa-sym}。d = 8，history = 2，K = 8，尺寸 S / M / L / XL，3 个种子，每次 20k 步。

- **测量**：见"格 0 的测量仪器与校准"一节。

### v0 相对 cells.yaml v0.3 改了什么

- **和乐需要记忆**，判据只在观测闭合环路上算（见"思想实验与对抗审稿"一节）。模型从 episode 起点开环滚动：开局门是关的，隐状态是动作历史的确定函数。
- **主读数 M2（观测空间和乐）**：H\_obs(γ, z) = max\_{π∈Π} mean\_t ‖D(F\_π F\_γ z)\_t − D(F\_π z)\_t‖₁ / 智能体通道质量。它对潜空间微分同胚不变。
- **诚实定位。** 离散情形下"和乐 ≠ 0 ⟺ 有隐状态"已被 HCDP（Zhang et al. 2026-07）占住。本格主张三件事：无标签、规范不变的读数；小方格曲率把隐状态的来源定位到开关上；和乐谱数出隐状态位数。"主动探测胜过被动观测"有 30 年的根（Rivest–Schapire 1993 的 homing sequence，Holmes–Isbell 2006 的 looping suffix tree），本格不主张这一点。
- **文献第二轮带来的两处改动。** HCDP 的"被动日志不可辨识"（Thm 4.2）依赖采样策略恰好漏掉一个可区分动作，而不是"被动"本身，所以操纵变量改为"数据是否覆盖可区分环路"，分三档（被动不覆盖 / 被动覆盖 / 主动）。零和乐对照从 Delliaux 2025 换成 WLA 式阿贝尔模型 z′ = z + δ\_a，因为 Delliaux 的转移依赖状态，并没有假设可交换。

### v1 修订清单（我全部接受）

1. **P6.6 升为共同主判据。** 非几何基线事先写死：在没有环路结构的历史对之间，比较停在同一观测上的预测未来差异；定位用"差异在轨迹哪一步被制造出来"的归因。和乐与基线用同一套指标比较：分层 AUC、precision@4，以及在 250 / 500 / 2000 个 episode 下的数据效率。和乐必须至少在一项上以事先写死的幅度胜出：AUC 高 0.05，或 precision@4 高 0.25，或所需数据少一半。基线 ≥ 和乐，则几何主张判死，并入 HCDP。
2. **P6.1 改为分层对比。** 真值上，只要知道"环路进过开关没有"这一个二值标记，合并计算的 AUC 就有 0.92。主对比改为"奇数次进入"对"≥ 2 次的偶数次进入"，按长度匹配或分层；对开关环路过采样。
3. **gate 改为脚本化的平衡事件集。** 原 gate 下门开的比例只有 12–17%，"门开当且仅当进过开关"这条启发式就能拿到 95.6%。新做法：每个 episode 先进入 S₁ n ∈ {0, 1, 2, 3} 次再尝试过门，每个 (n, 门状态) 格子 ≥ 200 个事件，每格都要 ≥ 95%。
4. **P6.3 的阈值不能再循环。** 阈值在留出的校准 z 上定，要求超阈比例的 95% 上界 ≤ 10%（按 z 聚类）。负对照改为同构的两个：`switches_enabled=False, init_doors=(1,)`（门常开；门关时根本走不出 R₀）和门可见世界。另加模型内部的对照：≥ 2 次进入的偶数环路，以及时间匹配的零环路。
5. **删掉"开关不可见"条件。** 标记是静态输入，会被第一层偏置吸收，这个条件对模型没有任何改变。改为把"读标记"的定位器（precision@4 = 1）明写为平凡基线。（zoo 里的 `switch_visible` 开关保留，以后可能有用。）
6. **探针集写成代码。** 主读数用 64 条带种子的均匀随机 20 步序列。真值上，16 条随机探针检出隐藏位的概率最低只有 0.51，64 条 ≥ 0.94。"走到门前尝试通过"的探针利用了"隐藏位在哪里变得可观测"的知识，只作 oracle 上界报告。
7. **只做 k = 1。** 分析起点全在 R₀，指定的环路到不了 S₂、S₃；训练数据里 D₂ 只被尝试过 3 次，D₃ 一次都没有。所以真值上就数不出 2^k 类，P6.4 和 2、3 位扫描删掉。
8. **控制时间混淆。** 两个分支都用时间匹配的参照（同长度的零环路）；前缀 + |γ| + |π| ≤ 63（原设计中 8–12% 的 rollout 超出训练时程）；AUC 按长度分层报告。
9. **数据档位写死，并先做操纵检查。** zoo 的 `loops` 策略覆盖反而比均匀随机少（1.5% 对 4.2% 的 episode 走出 R₀），所以训练前先核对各档的开门尝试次数。P6.5 改成可以被证伪：预测"覆盖才是关键"，即被动覆盖档与主动档的 AUC 差 ≤ 0.05；覆盖匹配时主动档高出 > 0.1 则被证伪。
10. **阿贝尔对照改为单元测试。** 自由的 δ\_a 并不能保证和乐为零，只有 δ\_L = −δ\_R、δ\_D = −δ\_U 时才为零，而那时 H\_obs 恒为 0，所以不训练。
11. **决策表补全。** 一个尺寸可以评判当且仅当 ≥ 2/3 个种子过 gate；写出 gate × (P6.1, P6.2, P6.3) 的全部组合；删掉未预注册的"换滤波器 WM"兜底，一律记 inconclusive；分析单位按 z 聚类；"死"只在分析集 rollout 的同分布模型检查也通过时才成立。
12. **邻居更新改正。** 格 1 已 thought\_killed，1+6 合并候选删除；格 2 的"通量 = 曲率"桥写明不更新；死亡和 inconclusive 两个分支也写出对邻居的影响。
13. **P6.2 只在 R₀ 的 16 个小方格上做主判据**（随机 precision@4 = 0.25），R₁ 只占约 1% 的训练帧，作副读数。门邻接小方格排名靠前写成一个具名失败模式：读数定位的是"隐状态的后果"，不是"来源"。
14. **测量细节。** H\_obs 用 argmax 解码出的智能体位置（不再除以解码出的通道质量，线性输出层在稀有状态下不稳定）。所有潜变量都来自 `model.rollout(E(o₀), actions)`；`baselines.encode` 是无记忆的 E(o\_t)，不能用。

## 跨格教训

### 1. 不少 kill test 在精确状态上测的是定理

格 7（选择段 = e-直线）、格 2（对称适应度的 replicator = Shahshahani 梯度流）、格 15（解析散度）、格 0（重建型 WM 的 H1）都是这样：拿真值去测，结果只能是"通过"。真正能错的只有三类：

1. 从**学到的模型或有噪观测**里能否恢复；
2. 读数对**潜空间重参数化**是否不变；
3. 相对**非几何的最近替代**是否多给了信息。

我建议把这条写成生成器的硬规则：每格的判据必须落在这三类上，精确状态只当 sanity check。

### 2. 最常见的死因：几何读数与一个更笨的量数学上同源

本周死掉、降级或被迫改判据的格里，有五格的理由是同一种：几何量与一个非几何量由同一条恒等式连着，所以前者不可能比后者多给多少信息。

| 格 | 几何读数 | 同源的笨量 | 连接它们的事实 |
| --- | --- | --- | --- |
| 1 | 预测 Cauchy–Green 的压缩带 | 数据密度、位移亏损 | Liouville：压缩 ⟹ 堆积 |
| 3 | WFR 搬运份额 | ∂tρ 的功率谱 | L\_ρ 特征基里的对角化 |
| 6 | 观测空间和乐 | HCDP 的历史可分辨性指纹 | 两者是同一个比较 |
| 9 | Fisher 弧长 | 白化欧氏弧长 | σ 恒定时两者相等 |
| 8 | 拟度量的反对称部分 | 熵产生 | NEEP / LENS 已经证明并做了定量对照 |

建议：每格的 must 加一条"写出与读数同源的非几何量，把它当主对照"，并且在思想实验阶段就问这个问题。格 6 的 P6.6 升为共同主判据，就是这条规则第一次落地。

### 3. 观测几何会冒充动力学几何

格 1（拉回只看渲染）、格 15（射影相机造出假耗散）、格 9（σ 各向异性造出假优势）是同一类问题。只要读数经过解码器或后验方差，就要先在"已知没有该效应"的世界上标定：保守世界、等变渲染器、冻结 σ 的白化基线。动物园里的 camera\_ladder 和保守单摆的价值主要在这里。

### 4. 规范不变性与几何内容之间有张力

局部散度、log det C\_k、‖F\_γ z − z‖ 都不是不变量。不变的有三种：轨道平均量（如 Lyapunov 指数之和）、相对量（如 log det(g\_obs⁻¹ C\_k)），以及观测空间里的比较（如格 6 的 M2）。轨道平均量大多已被占住（Wang 2026）；相对量继承观测几何（格 1 崩回格 15）；观测空间比较又容易退化成只看预测的非几何检验（格 6）。读数越不变，越接近"只看预测"。我还没想清楚这是不是一个普遍障碍，列在下一节的问题里。

### 5. 对称性是免费的标签

格 15 的窗口反演对称化不需要任何真值，只用"假项对 T 为奇、耗散对 T 为偶"就把观测几何从动力学里分离出来。这是本周唯一一个"几何结构真的买到了东西"的例子。它提示：有价值的几何不一定在读数本身，而可能在"用对称性把两个混在一起的效应拆开"。

### 6. 流程上的教训

- **对抗审稿有效。** 上一节列了 12 处我自己写错的地方，全是怀疑者或实测抓出来的，其中 5 处是核心结论。关键是怀疑者的任务写成"推翻"，而且要自己写脚本做数值核对，不是"审阅一下"。
- **代价是越界。** 格 0 的怀疑者在 Z 批准之前自己训练了小模型，造成非盲 pilot。之后的审稿都限定为只在真值上核对、不训练模型；这条应当写进以后每一份审稿指令。
- **搜索工具的自动摘要会编造。** Flow-Lenia"受 OT 启发"就是一例。影响决策的引用必须核对全文。
- **自报的盲区是真的。** 第一轮自己标出的三个盲区（格 10、15、7）里，两个在第二轮补查时找到了关键近邻。所以以后每轮审计都要列未执行的搜索词，下一轮先补。
- **算力估计要实测。** 格 6 的"每次 5 分钟"实际是 18 分钟，格 0 阶段 1 从 10.5–11.8 小时涨到 14–16 小时。像素 M/L/XL 只能去 Z 的 Mac 或 3080 笔记本。

## 想请你判断的问题

Z 暂时搁置了两件事：先把哪一格做成可批版本，以及是否接受格 1、3、7、8 的状态变更。下面的问题都不涉及这两件事，而是我判断不了、需要当初设计这张表的人来回答的。每个问题后面附上我目前的倾向，欢迎反驳。

1. **格 0 的改写是否偏离了它作为"公共前提"的本意？** 原版格 0 是要给格 1、4、9、15 提供"通用潜空间能承载几何"的前提。改写后它问的是"拓扑由输入、输出还是动力学决定"，更像一个独立的科学问题，和下游格的联系变弱了：对格 9 的联动已删，对格 4 的联动也改了。
   - 我的倾向：改写是对的，因为原版有一半测的是定理。但如果你们当初的意图是"先验证 JEPA 路线下可以只读、不约束"，那么真正的前提检验是 P0.5（像素上的 JEPA），它要等阶段 2 的 Mac 算力。
2. **格 6 如果打平非几何基线，是并入 HCDP，还是有别的保留理由？** 修订后，几何主张只活在"环路读数胜过同样规范不变的非几何探测器"上。
   - 我能想到的唯一保留理由在连续情形：小方格曲率在连续状态空间里有极限对象（联络的曲率 2-形式），"差异在哪一步被制造"的归因没有。但格 6 只在离散网格上测，这条理由在这里测不到。你们当初设想的"几何增量"是什么？
3. **"读数越不变，越接近只看预测"是不是一个普遍障碍？** 见"跨格教训"第 4 条。如果是，整张表里 readout = diagnose 的格先验都应下调，生成器应偏向 predict / plan，也就是把几何当约束或归纳偏置，而不是当读数。
   - 我的倾向是部分同意：它对"从通用 WM 里读几何"成立，对"把几何当约束"不一定成立。但这与 HANDOFF 把"可测不变量"作为统一交付形式有冲突，需要你们判断要不要改交付形式。
4. **格 15 的窗口反演对称化要不要单独成格？** 它不依赖 Hamiltonian 结构，对任何"从学到的 WM 读局部耗散"的工作都可能有用；LeHami 已预告耗散版，有时效。
   - 我的倾向：单独成格，或作为格 15 的新主线。先做标定 benchmark（保守世界 × 射影相机 × 噪声 × 架构），再做对称化，两件事放进同一份预注册。
5. **生成器下一步：先扩表，还是先把现有幸存格做完？** `cells.yaml` 的 next\_generation\_todo 是让五个算子对现有 15 格各作用一遍，预计扩到 30–40 行。现在 4 格已死、5 格改了判据。
   - 我的倾向：先把"判据必须落在三类可错的事上"和"必须写出同源的非几何量"两条写成入表过滤规则，再扩表。否则新格会重复本周的错误。
6. **格 2 与格 7 的剩余工具合并后，算一格还是两格？** 格 2 改为 Fisher 对欧氏 Hodge 的度量归因测试；格 7 剩下的二分 e/m 检验、r\_min 和软 e/m 分数，都是 Wright–Fisher 上的工具。
   - 我的倾向：算一格（"Wright–Fisher 上的度量归因"），格 7 的工具作为它的副读数。
7. **格 9 需要什么新世界？** 它只能在观测通道让后验不确定度真正变化的世界里做，动物园里目前没有这样的世界：需要部分可观测（遮挡）、带噪声的观测，或者相变附近的世界。
   - 我的倾向：在单摆上加随时间变化的遮挡或观测噪声，代价最小。但这样做是否还符合格 9"时间即弧长"的原意，需要你判断。

本周所有计算都在一台 4 核、无 GPU 的云端容器上完成。代码不区分设备，CPU、MPS、CUDA 都能跑。命令都从仓库根目录执行。

建环境：

```bash
python3 -m venv .venv
```

```bash
.venv/bin/pip install -r requirements.txt
```

跑全部测试：

```bash
.venv/bin/python -m pytest
```

重做格 0 的仪器校准（只用真值嵌入，不训练模型）：

```bash
.venv/bin/python cells/0/calibrate.py
```

重做吞吐基准（约 1 小时）：

```bash
.venv/bin/python scripts/bench_baselines.py
```

探索性检查都是单文件脚本，例如格 15 的假散度：

```bash
.venv/bin/python cells/15/exploratory/fake_divergence.py
```

训练单个 baseline 的写法如下。这只是接口示例，不是 kill test；任何预注册里的运行都要等 Z 批准。

```bash
.venv/bin/python -m baselines.train --world pendulum --obs angle_raw --variant jepa-sym --size M --seed 0 --steps 20000 --out runs/example
```
