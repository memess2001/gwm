## 1. 结论

## 5. 第一性原理

每格都打平，我认为有三层原因。仓库写明了第一层，后两层是我的判断。

1. **R3。** 规范不变的读数是预测分布的泛函。
2. **"几何对非几何"不是良定义的对比。** 几何是推导归纳偏置和统计量的语言，不是另一种信息来源。同一条约束写成切触哈密顿量，或写成"二阶模型加标量阻尼"，是同一个函数族（格 19 的预检 §2）。越典范的几何对象，越容易被别的领域从别的路走到：Fisher 度量由不变性唯一确定，而 Wright–Fisher 的抽样噪声协方差恰好是它的逆，所以这个世界里凡是 Fisher 几何的量都已是随机热力学的量（格 2、格 9）。
3. **动物园的选择效应。** "答案是定理"的世界，正是邻域已经算透的例子：Wright–Fisher 属于群体遗传与随机热力学，单摆属于经典力学，开关网格属于自动机理论。定理给出真值的同时，也给出了那个同源量。几何如果有独占的用处，只会出现在邻域还没算透的世界里，而那样的世界很难满足"答案是定理"这条入园规则。

由此三条建议：

- **约束格不是出路。** 格 4、19、9 的学习主张、11 的约束版，预检结论与读数格相同：约束要么等于一个现成的非几何函数族，要么胜负由所造的世界是否落在约束族里决定（格 19 预检 §5 的世界表）。顾问提的第二个方向"离支撑外推"会遇到同一个问题，格 2 审稿 §3.5 自己也写了"参数化模型在 `zoo` 世界里先天占优"。
- **仍想做约束，就把实验变量从"有没有几何"换成"世界违反这条结构多少"。** 让世界偏离约束族一个可调的量，看在不同数据量和模型尺寸下硬约束何时帮忙、何时拖累。这个问题不新（偏差与方差的权衡），但结局不被恒等式锁死，动物园的真值也用得上。
- **没被锁死的是 R3 的第二层：模型怎样实现规律。** 这类读数不是预测分布的泛函，结论只能靠实验。HANDOFF §9 留的问题是"训练目标决定潜空间拓扑"这类关于模型的结论算不算要的发现。我的回答是算，而且证据目前只指向这里。

## 8. 核对中发现的动物园数值问题

**现象**（已核对，`main` 与 `cell9/v1` 上的 `zoo/wright_fisher.py` 相同，都能复现）。确定性模式（`pop_size=None`）下，`mixed` 与 `mutation_selection` 两种机制用 RK4 积分，每步之后不投影回单纯形。视界长时，一部分路径会离开单纯形。K = 3、600 步（60 个时间单位）、400 条路径、种子 1：

| 预设 | 偏离 > 1e-9 | > 1e-6 | > 0.1 | 其中变成非有限值 |
|---|---|---|---|---|
| `mixed_only` | 14 | 9 | 4 | 3 |
| `mutation_selection` | 52 | 36 | 20 | 9 |
| `selection_only`、`migration_only`、`alternating`、`rps` | 0 | 0 | 0 | 0 |

前三个不受影响的预设走的是闭式解；`rps` 走 RK4，但零和收益下 x·Ax = 0，偏离不放大。

**原因。** 记 s = Σx。两种机制的向量场都满足 d(s − 1)/dt = −r·(s − 1)：选择加迁移时 r = x·f + μ，选择加突变时 r = x·f。r < 0 时舍入误差按指数放大。精确动力学对 f 加常数不变，离开单纯形后的数值动力学却依赖这个常数。实测增长率与 −r 三位小数一致：

| 预设 | 路径 | 实测增长率 | −r |
|---|---|---|---|
| `mixed_only` | 16 | +0.836 | +0.836 |
| `mixed_only` | 177 | +0.483 | +0.483 |
| `mutation_selection` | 69 | +1.009 | +1.009 |
| `mutation_selection` | 228 | +0.908 | +0.908 |

哪些路径会出事也对得上：

- `mixed_only`：按 r 的符号判为不稳定的有 25 条，离开单纯形的 14 条全在其中；判为稳定的 375 条里没有一条离开。
- `mutation_selection`：三个适应度全为负的路径有 54 条（f 取标准正态时期望是 1/8，即 50 条），离开单纯形的 52 条里有 49 条在其中。

**影响。**

- 只在长视界上出现：舍入误差 1e-16 放大到 1e-6 约需 25 个时间单位。默认 `seg_steps = 20`，现有测试用的视界短，所以 273 个测试都过。
- 有限种群模式不受影响，因为每步的多项式重抽样会重新归一化。
- 格 9 的 `c9_clock_metric.py` 用到了 600 步的 `mixed_only`，脚本只过滤了非有限和带负分量的路径。再剔除偏离超过 1e-6 的路径后，mixed 两行的 CV 只在第三位小数上变化，最优时钟不变。格 9 的结论不受影响。
- 格 2 的独立核对用的是自己的格点 Fokker–Planck 和有限种群的链，不受影响。其余脚本我没有逐个排查。

**修法。** 每个观测步之后截断并归一化：`mixed_only` 最差的 20 条路径上，最大偏离从 0.69 降到 2e-16。也可以把 f 平移成非负，或在 log-ratio 坐标里积分。修的同时应加一条长视界的单纯形不变性测试，并排查用到长视界确定性 `mixed` 或 `mutation_selection` 的脚本。

复现（在仓库根目录，`PYTHONPATH=.`）：

```python
import numpy as np
from zoo.wright_fisher import WrightFisher

T = 600
w = WrightFisher(K=3, schedule="mixed_only", seg_steps=T)
tr = w.sample(seed=1, horizon=T, n_traj=400, obs_mode="freq")
X, f, mu = tr.state, tr.info["fitness"], tr.info["mu"]
fin = np.isfinite(X).all((1, 2))
Xz = np.where(np.isfinite(X), X, 0.0)
dev = np.abs(Xz.sum(-1) - 1.0)                                   # 每步离单纯形的距离
worst = np.where(fin, dev.max(1), np.inf)
print([int((worst > t).sum()) for t in (1e-9, 1e-6, 0.1)], int((~fin).sum()))   # [14, 9, 4] 3
pred = -((Xz[:, :-1] * f).sum(-1) + mu)                          # 推导的增长率
for i in (16, 177):
    slope = np.polyfit(np.arange(150, 350) * 0.1, np.log(dev[i, 150:350]), 1)[0]
    print(i, round(slope, 3), round(pred[i, 150:350].mean(), 3))               # 0.836 0.836 / 0.483 0.483
```

把预设换成 `"mutation_selection"`、增长率换成 `-(Xz[:, :-1] * f).sum(-1)`、拟合窗口换成 100–250 步，得到表里另两行。
