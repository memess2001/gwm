# Wright–Fisher 的 RK4 分支离开单纯形：修复记录（2026-11-17 JST）

写给 Z。对应外部评估 §8（`reports/2026-11-17_external_review.md`，在分支 `claude/gallant-gates-6ye5ox` 上）。写的人是 Claude Code 的一个会话，没有参与此前的工作。本分支基于 `main`；`zoo/wright_fisher.py` 在各分支上是同一个文件，补丁可以直接用到 `cell9/v1`。

**大白话。** 这几种机制的方程本身保证"各类型频率之和 = 1"，但数值积分时，这个和的舍入误差在一部分参数下会按指数放大，几十个时间单位后把路径带出单纯形。现在每个 RK4 子步之后都把状态拉回单纯形，误差没有机会放大。拉回只动舍入误差那一位，所以原来没出事的路径基本不变，出事的路径变成了正确的解。仓库里没有任何结论因此改变。

## 1. 改了什么

- `zoo/wright_fisher.py` 的 `_flow`：RK4 每个子步之后做一次 `_normalize`（负分量截到 0，再除以总和）。代码改动一行，模块 docstring 加了一段原因。
- 三条闭式分支（selection、migration、mutation）没有动。
- 改的是整个 RK4 分支，所以 `rps` 也在内。理由见 §6 第 1 条。

两个选择的理由：

- **每个子步，而不是每个观测步。** 偏离在一个观测步内按 exp(−r·dt) 放大。放进子步后，只要步长 dt / n_sub 够细，结果就不依赖 dt 取多大。
- **除以总和，而不是减去平均偏差。** 除以总和不改变各分量之比，也就是不改变 θ 坐标；很小的分量也只受到相对 1e-16 的扰动，不会变号。

## 2. 结果

外部评估的复现脚本（K = 3，600 步，400 条路径，种子 1；四个数依次是偏离 > 1e-9、> 1e-6、> 0.1 的路径数和非有限的路径数）：

| 预设 | 修复前 | 修复后 |
|---|---|---|
| `mixed_only` | `[14, 9, 4] 3` | `[0, 0, 0] 0` |
| `mutation_selection` | `[52, 36, 20] 9` | `[0, 0, 0] 0` |

修复后的路径不只是"在单纯形上"，而且就是方程的解。这两种机制在归一化之前是线性方程（§6 第 2 条），所以有闭式精确解。400 条路径、全部 601 个时刻，与精确解的最大差：`mixed_only` 2.4e-10，`mutation_selection` 1.2e-10。这是 RK4 自己的截断误差，三种稳定化办法（每子步投影、每观测步投影、平移 f）给出的数相同。

加测：8 个种子 × 6 种配置（K = 3、4、5，均匀与循环突变，收益平移过的 `rps`），2000 步，每种 200 条路径，numpy 警告一律当错误。全部有限、非负；max |Σx − 1| = 4.4e-16；与精确解最大差 3.0e-10。

## 6. 顺带发现

1. **`rps` 在非默认收益下有同样的问题。** 外部评估说 `rps` 干净，这对默认的零和收益成立（x·Ax = 0）。但 docstring 写着"给 A 的列加常数不改变向量场"，而离开单纯形后的增长率 r = x·Ax 会变。`rps_A = RPS_A − 1` 与默认收益是同一个向量场，修复前 600 步时 48 条路径全部出事（25 条非有限）。这个配置在修复前违反了 `ground_truth()` 的"H 守恒"声明，只是没有测试覆盖到。现在修好了，并有测试。
2. **这两种机制有闭式精确解。** 令 y′ = y·(diag f + uQ)，这是线性方程，x = y / Σy 正好满足选择 + 突变的方程；迁移到库 m 就是 Q = 1mᵀ − I 的突变。所以 x(t) ∝ x₀·expm(t·(diag f + uQ))。这次只把它用作独立测试的参照，没有换掉 RK4。
3. **RK4 的截断误差随选择强度增长。** 默认 `f_scale = 1` 时是 2.4e-10。`f_scale = 5` 时 2.8e-7，`f_scale = 20` 时 2.7e-5（600 步、400 条路径的最大值）；`f_scale ≥ 200` 时 RK4 本身不稳定，输出没有意义，修复前后都是如此。这不是本次的 bug，仓库里也没有脚本用非默认的 `f_scale`。

- **没有改 `cell9/v1`。** 我只被允许推本分支。修复合到 `cell9/v1` 之后，在那里重新生成 `c9_clock_metric.out`（上表两行），并去掉脚本第 40 行那句已经用不上的过滤注释。
