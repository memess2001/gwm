## 大白话

阶段 1 只训练了 20000 步，结束时损失还在降。所以它的结论（只有对称 JEPA 把原始角度的切口粘上）可能只是训练中途的样子。这次用同一配方，把四种训练目标都训练 5 倍长。

结论没有变：24 个 run 都和阶段 1 同类。
- 三个撕开的臂大多撕得更开：18 个 run 里 16 个的接缝比上升，最低的也有 11.1，远高于撕开阈值 5。
- 对称 JEPA 的 6 个 run 接缝比都在 0.94 以下，低于粘合阈值 1.5。S 尺寸粘得更紧，M 尺寸基本不变。
- 我在预注册里点名最可能出错的 stop-grad JEPA 也没有动。

所以"训练目标决定切口粘不粘"不是 20000 步时的过渡态。在这个配方、这两个尺寸下，到 100000 步都成立。

三条限定：
- 按预注册的收敛口径，100000 步时仍然一个都没收敛。主要原因是口径与余弦调度不相容（见"收敛口径"），但"更长训练会不会改变分类"只能说到 100000 步为止。
- 只量了训练结束时的模型。训练脚本只保存最后一个检查点，训练中途的分类不知道。
- 只有 angle_raw，只有 S 与 M。L、K = 1、λ_lat = 0、angle_cs、像素都没跑（预注册 §2）。

## 副读数（只作描述）

**val 损失的终值。** 重建臂取 recon 项，JEPA 臂取 inv 项。表中是 100000 步与 20000 步终值之比，取 3 个种子的中位数。

| 臂 | S | M |
|---|---|---|
| recon-mse | 0.47 | 0.45 |
| recon-circ | 1.09 | 1.02 |
| jepa-sg | 0.75 | 0.91 |
| jepa-sym | 0.16 | 0.13 |

- recon-mse 与 jepa-sym 的损失明显下降，分别降到约一半和约七分之一。
- recon-circ（S、M）与 jepa-sg（M）几乎不变。
- 两种情况下分类都没变。

**跨切口超额损失。** 跨切口窗口与同 |ω| 非跨切口窗口的损失之比：重建臂是当前帧的重建误差，JEPA 臂是一步潜空间误差。不同臂之间不可比，审稿在未训练的检查点上就量到 mse 11.7、circ 4.0、jepa-sym 5.5e4（`cells/0/review_v2.md`）。

| 臂 | S | M |
|---|---|---|
| recon-mse | 3–7 → 28–53 | 5–6 → 17–28 |
| recon-circ | 23–54 → 1–13 | 12–42 → 1–15 |
| jepa-sg | 1219–1436 → 4374–10759 | 1557–2536 → 7261–15129 |
| jepa-sym | 397–797 → 266–497 | 461–678 → 381–901 |

- 粘合的 jepa-sym 在跨切口窗口上的一步误差，仍是非跨切口窗口的几百倍（阶段 1 记为约 500 倍）。更长的训练没有让它学会跨过切口的那一步；"粘合"仍只指切口两侧的状态在潜空间里彼此靠近。
- 两个重建臂的方向相反，说的都是输出端。圆上的损失把 +π 与 −π 当成同一点，切口附近的帧越学越准，比值降向 1；MSE 把它们当成相距 2π，非跨切口的误差下降后比值变大。潜空间在两个臂里都照样撕开。

## 收敛口径

v2.2 的口径：val 损失在最后 25% 的训练里相对变化 < 10%。

- 100000 步时 0/24 收敛，相对变化 0.14–0.95；20000 步时是 0.17–0.85。
- 学习率按余弦衰减到 0（`baselines/train.py` 的 `lr_factor`）。最后 25% 开始时，学习率只剩峰值的 15%（20000 步配方 0.161，100000 步配方 0.149），之后降到 0。学习率降低本身就会让损失下降，不论训练多长。
- 例证：recon-circ（S）在 20000 步时被判为未收敛（最后 25% 里变化了 27–31%），但训练 5 倍长之后，终值几乎一样（比值 1.09）。recon-circ（M）与 jepa-sg（M）类似（比值 1.02、0.91）。
- 所以在余弦衰减到 0 的配方下，这个口径分不清"退火带来的下降"与"还没训练完"。recon-circ 属于前者；recon-mse 属于后者，训练 5 倍长后损失降到约一半。以后的预注册如果要判收敛，可以在常数学习率的一段上量，或者保存中途检查点、直接比较读数的变化。这只是给以后的建议，不改 v2.2，也不改本次的判定。

**中途的损失。** 100000 步配方在第 20000 步时学习率仍接近峰值，val 损失远高于阶段 1 的终值。例：recon-mse（M）在第 20000 步是 0.65–2.73，阶段 1 的终值是 0.070–0.075。这就是预注册 §2 说的"同一配方、5 倍长度"，不是"把 20000 步的模型接着训练下去"。
