## 大白话

给模型看原始角度（到 ±π 就跳回去的数）时，四种训练目标里有三种把这条切口原样撕开，S / M / L 三个尺寸、每臂 9 个 run 全部撕开：重建（MSE）、重建（圆上的损失 1 − cos Δθ）、stop-grad JEPA。只有对称 JEPA（两支都传梯度）9/9 把切口粘上。

所以我的主预测 P0.3（"输出损失的几何决定潜空间拓扑"）不成立：把重建损失换成圆上的损失，潜空间照样撕开。审稿人的 pilot 之前就显示了这个方向（§8 已披露，P0.3 / P0.4 都不是盲的），这次正式检验把它重复了出来。

两条限定：
- 对称 JEPA 的粘合依赖多步预测。预测时程 K = 1 时，它 3/3 撕开（副因子，只作描述）。
- "粘合"指切口两侧的状态在潜空间里彼此靠近，不是说模型能顺利预测跨过切口的那一步。对称 JEPA 在跨切口窗口上的一步潜空间误差，是同 |ω| 非跨切口窗口的约 500 倍（见"副读数"）。

## 零对照（未训练编码器，M，3 个种子）

| 观测 | H1 | 接缝比 | 一致性表 | θ 的 kNN R² |
|---|---|---|---|---|

- angle_raw 上，训练过的臂（撕开或粘合）与未训练编码器（不绕的环、不确定）的分类**不同**，所以不能打这个标注。未训练编码器的接缝比远大于 5，方向上同样是"撕开"，但 PH 读法不同。判定表给 jepa-sg 记的"继承切口"按撕开率给出，零对照不提供直接支持。这一点要如实写进格 0 的 notes。

## 同源对照（rules.R2）：PH 与接缝比的分歧

在 105 个训练 run 里，PH 判"环"而接缝比判"撕开"，或 PH 判"无环"而接缝比判"粘合"的，共 3 个（2.9%），全在像素 S 上：
- `pix-jepa-sg_S_s0`、`pix-jepa-sg_S_s2`：不绕的环 + 接缝比粘合；
- `pix-jepa-sym_S_s2`：无环 + 接缝比粘合。这个 run 不承载 θ（r2_min = −0.10），在它上面算接缝比没有意义。

angle 的 run 上分歧为 0。像素仪器检查（像素的 P0.1 / P0.2）要到阶段 2 才有。

结论：在 angle 输入上，拓扑读数没有说出接缝比说不出的东西，两者完全一致。按 R2 的要求，本格的拓扑读数在 angle 上只是局部距离的另一种读法；它能否多给信息，要看像素。

## 收敛（清单第 11 条，单独标注）

按预注册的口径（val 损失在最后 25% 里的相对变化 < 10%），105 个训练 run 里只有 3 个算收敛（cs-recon 负对照、pix-jepa-sg、raw-recon-circ λ_lat = 0 各 1 个）。各臂相对变化的中位数：
- angle_cs：0.91–0.94；
- angle_raw：0.29–0.78；
- 像素：0.18–0.52。

按预注册，未收敛的 run 照常计分。这说明 20k 步结束时损失还在下降，不说明拓扑分类会随更长的训练改变，但也排除不了：本结果只对 20k 步成立。不过，每个臂的分类在 S / M / L 三个尺寸上完全一致，不像是停在过渡态。
