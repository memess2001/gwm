## 1. 问题

**原问题。** 世界模型的潜空间里会不会出现单摆的相空间几何（S¹×ℝ），能量能不能被平滑地读出？

**为什么改。** 重建型模型的 H1 几乎由单射性定理保证（`cells/thought_experiments_2026-11-03.md` §1），所以这一部分降为仪器和定理检查（P0.1）。有信息量的是两种情况：
- 输入本身不带圆的原始角度（angle_raw）：圆要么被粘起来，要么被撕开；
- 没有解码器的 JEPA 式目标。

**v2 的问题：** angle_raw 上，潜空间到达哪一种零损失解（粘合还是撕开），由输入编码、输出损失的几何，还是动力学目标决定？

**这是关于模型的问题（rules.R3 第二层）。** 潜空间拓扑只对潜空间微分同胚不变，不是预测分布的泛函。它描述"模型怎样实现规律"，不描述世界。所以本格的结论是关于训练目标与表示的，不是关于世界几何的。

**同源对照（rules.R2，`cells.yaml` 格 0 的 `same_source`）：** 持续同调（H1 与绕柱面）的同源局部量是接缝比（切口两侧 ω 匹配的局部距离比），再加上 θ 的 kNN 可解码性。两者在每个 run 上都算，PH × SR 一致性表（§5）本身就是这一对照：拓扑读数要说出接缝比说不出的东西，否则只是局部距离的换算。两者的分歧率作为副读数报告。

## 2. 世界与数据

- **世界：** `pendulum`，ω₀ = 1，γ = 0，无动作，dt = 0.1，Verlet；init = "box"，omega_max = 2.5（`c0lib.WORLD`）。采样区域是环带，真值 b₁ = 1，含转圈运动。
- **负对照世界：** 同上，加能量窗 E ∈ [−1, 0.5]，只含摆动，真值 b₁ = 0（`c0lib.NEG_WORLD`；E_hi = 0.5 的理由见 v1 §1）。
- **规模：** 每条轨迹 64 步（65 帧）；train 2000 条，val 200 条，种子 `split_seed("train"/"val", 0)`。
- **分析集：** 主世界 500 条，负对照 2000 条（v1 P0.2 写死的条数；v2.1 改回，审稿 B4），种子 `split_seed("analysis", i)`，i 由数据门决定；只用于测量。

**数据门**（`c0_score.data_gate`，只用真值，在任何训练之前跑）：分析集的真值嵌入 (cos θ, sin θ, ω) 必须在 H1 规则下得出 `ground_truth()` 的 region_betti[1] 与绕柱面数。主世界应判"环"，负对照应判"无环"。不对就换下一个 i，最多 3 次；连续 3 次失败就停（清单第 14 条）。冒烟检查：主世界在 i = 0 上通过。

## 4. 排除性 gate 与运行分类（清单第 4、6、14 条）

一个 run 只因两种原因被排除，排除后不进分母：

1. **没学会。** recon 的 val nmse ≥ 0.05（recon-circular 用模 2π 的 nmse）。jepa 的 latent_pred_err[8] ≥ latent_copy_err[8]，且 copy 误差不近于 0。
2. **塌缩。** 只对 jepa：分析集潜变量某一维的 std ≤ 0.1，或有效秩 < 2。有效秩用 baseline 的 RankMe（奇异值熵，`baselines.mlp_wm.effective_rank`），与 v1 的 gate 相同（v2.1，审稿 B3：v2 用了协方差特征值熵，会把各向异性的潜空间误判为塌缩）。
3. **训练发散**或没有最终指标，记为没学会（v2.1）。

没有被排除的 run，按下面的规则分类（`c0_aggregate.run_class`）：
- **不承载 θ：** θ gate（n = 8000，cos θ 与 sin θ 的 kNN R² 都 ≥ 0.99）不过，且 κ̂ ≤ 5。这类 run 算"有结论"，既不算粘合也不算撕开。审稿指出：γ = 0 时，"折叠到能量和 ω 的符号上"是零损失解，旧 gate 会把能证伪 P0.5 的结局删掉。θ gate 不过而 κ̂ > 5（或未知）时，已超出 gate 的校准范围，记为不确定。
- **粘合、撕开或不确定：** 由 §5 的 PH × SR 一致性表决定。

**比例的分母是"有结论"的 run**（粘合、撕开、不承载 θ），不确定的 run 不进分母（v2.1，审稿 B1：v2 把不确定留在分母里，四个臂全部不确定时会判成 F，与 §11 矛盾）。这样一条预测判 F，只能是因为有结论的 run 里确实出现了反面结果。**臂可评判**，当且仅当 9 个 run 都在，且至少 6 个有结论；否则这条预测记为 I。

**收敛**（清单第 11 条）：val 损失分量（recon 看 'recon'，jepa 看 'inv'）在训练最后 25% 里的相对变化 < 10% 算收敛。pred_err[8] 只在训练结束时记录，所以用 val 损失代替。未收敛的 run 照常计分，单独标注。

## 5. 测量（`c0_score.measure`，对条件不可见）

对每个 run，在分析集上取 z_t = E(o_{t−1}, o_t)，t = 1..64，共 32,000 个点。真值 θ_t、ω_t、θ_{t−1} 只在分析阶段使用。

1. **H1 规则：** FPS n = 600；death/birth ≥ 2.8 的 H₁ 条数；R = 4 次"随机取一半点再做 FPS"必须全票一致；绕柱面条件是顶类 Z₄₇ 圆坐标与真值 θ 的 |ρ| ≥ 0.5。状态分四种：
   - 环：主样本和全部子样本都恰好 1 条，且绕柱面；
   - 不绕的环：恰好 1 条但不绕柱面；
   - 无环：全部为 0 条；
   - 不稳定：其余情况。
   阈值来自 `calibration.md`。
2. **接缝比 v2**（`seam.seam_ratio_v2`）：去掉跨切口窗口；ω 匹配容差 = 0.08 / max(1, κ̂)；按轨迹做 bootstrap 200 次。三分类：粘合 SR ≤ 1.5，部分 1.5 < SR ≤ 5，撕开 SR > 5。旗标照旧报告：折叠、ω 主导、fold_index > 1.3 为"疑似错位"。
3. **PH × SR 一致性表**（`seam.seam_ph_consistency`，angle_raw 的主读数）：
   - 粘合 ⟺ 环 且 SR 判粘合 且 未折叠；
   - 撕开 ⟺ 无环 且 SR 判撕开 且 κ ≤ 5；
   - 其余都是不确定，包括分歧、"部分"、不稳定、数据不足、折叠、接缝比超出仪器范围（`in_range3` 为假：折叠，或 κ > 10 时的非撕开读数，即 v1 的"κ > 10 时粘合无效"）、κ̂ 未知（nan / inf，v2.1 起如实记录，不再记成 1），以及 κ > 5 时的无环（清单第 6 条：各向异性造成的 PH 假阴性）。

   校准（`calibration.md` §11）：20 个新种子上，核心真值图 0 次判反。粘合图 75% 判粘合、25% 不确定；撕开图 60% 判撕开、40% 不确定。撕开图的不确定一部分来自 κ = 9.5，另一部分来自 κ = 5 的图：其 κ̂ 读成 5.0000x，按 κ ≤ 5 的规则被判为不确定（浮点边界，审稿指出）。粘合阈值 1.5 没有在非线性嵌入上按 v2 重新校准，实测最高读到 1.59；这类读数落入"部分"，一致性表判不确定，方向保守。
4. **θ gate：** n = 8000 为主，n = 2000 为敏感性。
5. **能量（P0.6）：**
   - 判"可解码"：在 2000 个随机点上，kNN R²（k = 10，5 折）≥ 0.966，且冻结的二次岭回归 R² ≥ 0.972。angle_raw 只用 kNN（清单第 8 条）。
   - 判"平滑"：Lipschitz 尾比 ≤ 4.13。
   - 线性探针只作描述。
6. **逐点检查（P0.1 的 gate，清单第 14 条）：** recon 模型对每个分析点解码当前帧，得到角度：angle_cs 用 atan2；angle_raw 取包裹值；像素取 0.5° 网格渲染帧库里最近帧的角度。要求每个点与真值的误差都 < π/2。
7. **二级能量漂移**（交给格 15 的声明产出）：从 100 条分析轨迹的第一个窗口开环推 32 步，用一级的冻结 kNN 能量探针读出能量，报告 |E(z₃₂) − E(z₀)| 的中位数，并附真值能量的标准差作尺度（`c0_score.energy_drift`）。
8. **副读数：** 快速转动（|ω| ≥ 1.6）下的接缝比 v2，以及 placebo 最大值，存进 measures。
9. **跨切口超额损失**（清单第 5 条，angle_raw 全部 run）：跨切口窗口与同 |ω| 档的非跨切口窗口相比，逐窗口损失的中位数之比。recon 看当前帧误差，jepa 看一步潜空间误差。只作描述，用来区分"输出几何"与"λ_lat 动力学项"两种机制。

**仪器的已知错误率**（清单第 8 条，按此写容差）：
- H1 规则：新种子上正对照 280/280，负对照 140/140。
- 能量：两条判据同时满足时，假阴性约 12%；在撕开的图卡上约 50%。v1 写的"2–7%"删去。
- 一致性表：上面第 3 条。

## 7. 判定表（`c0_aggregate.aggregate`）

**第一步：仪器检查。** angle_cs 的 P0.1 或 P0.2 不通过（"fail"）→ **停**。这说明仪器或理论有问题：只允许在真值上重新校准，然后换新的模型种子和分析种子重跑；不允许看了训练出来的潜变量再改仪器（清单第 7 条）。不更新任何邻居。angle_cs 的 P0.1 / P0.2 只要不是"pass"（数据不足或缺 run），就不出任何判定，也不更新任何邻居（v2.1，审稿 B2）。阶段 2 里像素的 P0.1 / P0.2 不通过 → 只停像素部分（P0.5 不判），阶段 1 的改动保留。

**第二步：主预测。** P0.3、P0.4-sg、P0.4-sym 各自取 T / F / I（I = 臂不可评判）。

| 结果 | `cells.yaml` 的具名改动 |
|---|---|
| P0.3 = T | 格 0 status → alive；confidence.exists 保持 high；格 4 的 must 加一句："输出损失的几何决定潜空间拓扑，必须当成受控变量" |
| P0.3 = F | 格 0 confidence.exists high → mid；status 不变，等 P0.4 / P0.5（v2.1：只凭 P0.3 判 dead 太重） |
| P0.3 = I | 格 0 status 不变 |

## 8. pilot 披露（重写 v1 的 §0b，清单第 10 条）

## 11. 风险

- **全部 angle_raw 臂都判"不确定"。** 一致性表在撕开图上有 40% 不确定（κ 大时）。如果多数 run 落在不确定，P0.3 / P0.4 就判不出来（I）。这是仪器保守的代价：宁可不判，也不判反。
- **能量判据假阴性约 12%**，所以 P0.6 只要求 ≥ 2/3 个种子。
- **gate 卡掉太多。** 那就是"小模型学不会"，照实报告；不为了凑判据放宽 gate。

## 12. 大白话

我们给模型看单摆，有时给的是一个圆上的角度（cos、sin），有时给的是"−180° 到 180°、到头就跳回去"的原始数字。问题是：模型脑子里，这根"跳回去"的线最后是被粘成一个圆，还是被撕开？由谁决定？是让它把输入原样画回来的方式（输出几何），还是让它预测未来（动力学）？

审稿人的小实验显示，潜空间大多原样继承输入的切口，只有梯度能同时拉动切口两边的那种目标才可能把它粘上。这次是正式的、预先写死判据的检验。它回答的是"训练目标怎样塑造表示"，不是"世界的几何是什么"。
