## 大白话

阶段 1 的结论是：给模型看原始角度时，对称 JEPA 把切口粘上，另外三种训练目标把切口留着。但那批模型只训练了 20000 步，训练结束时损失还在明显下降。这次把同样的四种目标用同样的配方训练 5 倍长，看结论会不会变。变了，说明阶段 1 看到的只是训练中途的样子。

## 1. 为什么要查

- 阶段 1 的 105 个训练 run 里，按预注册口径收敛的只有 3 个（`cells/0/result.md` "收敛"一节）。本次要重复的 24 个 run 里一个都没有收敛，val 损失在最后 25% 里的相对变化是 0.17–0.85。
- 学习率是线性预热后余弦衰减到 0（`baselines/train.py` 的 `lr_factor`）。所以 20000 步的模型是"学习率被降到 0 时停下来的模型"，不是损失走平的模型。例：`raw-recon-mse_S_s0` 的 val 重建损失在 15000 步是 0.479，20000 步是 0.074。
- 阶段 1 的结果自己写了这条限定："本结果只对 20k 步成立"。

## 2. 设计

**重复哪些 run。** 阶段 1 主实验里 angle_raw 的四个臂：`raw-recon-mse`、`raw-recon-circ`、`raw-jepa-sg`、`raw-jepa-sym`；种子 0、1、2；尺寸 S 与 M。共 24 个 run，名字与统一运行表里的相同。

**改了什么。** 只改一处：训练步数 20000 → 100000。其余全部照 `c0lib.train_args`：世界、数据种子、d = 8、history = 2、K = 8、λ_lat = 0.1、batch 128、AdamW lr 1e-3、VICReg 25 / 25 / 1、单线程 CPU。`tests/test_c0_ext.py` 检查训练参数与阶段 1 只差步数这一项。

**这一处改动带来的后果。** 余弦衰减的终点跟着移到 100000 步，预热仍是 1000 步。所以这是"同一配方、5 倍训练长度"，不是把 20000 步的模型接着训练下去；它的前 20000 步与阶段 1 的 run 不相同。

**Z 那句话之外，我做的选择：**

| 选择 | 取值 | 理由 |
|---|---|---|
| 尺寸 | S 为主，M 为次 | 阶段 1 里分类不随尺寸变化；S 最便宜，保证跑完；M 是副因子所在的尺寸 |
| L 尺寸 | 不跑 | 单个 run 约 2–4 小时，超过本环境单个后台任务 2 小时的上限 |
| 只测训练结束时的模型 | 是 | 训练脚本只保留最后一个检查点；不改训练脚本 |
| K = 1、λ_lat = 0、angle_cs、像素 | 不跑 | 不在"四个臂"之内 |

**执行顺序**（`c0_ext.WAVES`，每批 3 个单线程 job，每批控制在 2 小时以内）：S 的两个 JEPA 臂 → S 的两个重建臂 → M 的 jepa-sg → M 的 jepa-sym → M 的 recon-mse → M 的 recon-circ。会话或容器中断时，后面的批次可能跑不到。只有完成训练的 run 才计分；没跑到的格子如实记为"未完成"。

## 4. 预测

写在任何延伸 run 之前。**方向不是盲的**：阶段 1 的结果已知。

- **E1.1（主）：** 四个臂在 100000 步下都保持阶段 1 的分类。依据是阶段 1 给出的机制：切口两侧能不能被拉到一起，取决于梯度路径（stop-grad 与否、有没有多步预测），不取决于训练多久。
- **E1.2（只描述）：** 按 v2.2 的收敛口径，收敛的 run 数比 20000 步时多。我不预测具体数目。

**我认为最可能出错的地方：** `raw-jepa-sg`。它在阶段 1 的接缝比最接近阈值（8.5–13.5，撕开的阈值是 5），而且 stop-grad JEPA 起步慢。

## 5. 判读规则

对每个（臂 × 尺寸）格子，看 3 个种子的分类（`c0_ext.cell_verdict`）：

| 读法 | 条件 |
|---|---|
| 保持 | 至少 2 个种子是阶段 1 的分类 |
| 翻转 | 至少 2 个种子是相反的有结论分类（撕开 ↔ 粘合） |
| 不清楚 | 3 个种子都在，但上面两条都不满足 |
| 未完成 | 完成的种子不足 3 个 |

总读法（`c0_ext.overall_verdict`），只看完成的格子：

| 总读法 | 条件 |
|---|---|
| 稳定 | 每个完成的格子都是"保持" |
| 过渡态 | 至少一个格子"翻转" |
| 部分不清楚 | 其余 |

E1.1 成立 ⟺ 总读法是"稳定"。
