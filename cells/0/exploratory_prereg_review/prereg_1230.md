## 0. 为什么改了原版设计

原版的问题是"MLP 世界模型的潜空间里会不会自发出现 S¹×ℝ 拓扑、能量能不能平滑解码"。
读完之后我认为原版设计有一半测的是定理。论证见 `cells/thought_experiments_2026-11-03.md` §1：

- 只要解码器能把当前帧重建好，潜点云到 S¹ 就有一个连续映射，且它在 H₁ 上是满射，所以 **b₁ ≥ 1 几乎是必然的**。这对 angle_cs 和像素观测都成立。
- 有信息量的是另外两种情况：
  - 没有解码器的潜空间预测（JEPA 式）；
  - 输入本身不带圆的原始角度（angle_raw），这时圆要么被模型"粘"起来，要么被撕开。

所以本预注册把问题改成：**潜空间的拓扑是由谁决定的？输入的编码、输出损失的几何，还是动力学？**
原版的预测保留下来，照常打分。

## 0b. 审稿人 pilot（非盲，如实披露；2026-11-03）

本草案写好之后，对抗审稿 workflow 中负责"格 0 单射性论证"的怀疑者没有等预注册获批，就用自己写的小世界模型做了一次小规模复现。设置：d = 8，K = 8，约 50k 参数，4000 步，3 个种子；脚本和原始输出在 `cells/0/exploratory_reviewer_pilot/`。

**预测部分没有动。** P0.3 和 P0.4 写在 pilot 之前，原样保留，照常打分。

**pilot 的结论**（仅为提示性证据，不是 kill test）：
- §1 的论证成立，但要改写成三个条件：数据区含一条 θ-环绕数非零的环（只说"θ 投影覆盖 S¹"不够，审稿人构造了阻尼螺旋带的反例）；解码角逐点误差 < π；有限样本下那条 H1 不保证是最显著的一条，各向异性的潜空间会把它压到阈值以下。
- angle_raw 上，**潜空间主要继承输入编码的切口**，具体如下表。

| 条件 | 结果 |
|---|---|
| stop-grad JEPA | 0/3 粘合，到 20k 步仍是撕开的 |
| recon-circular | 0/3 粘合 |
| recon-mse | 共 1/9 粘合：MSE 解码器把 2π 跳变放进了输入切口在潜空间留下的空隙，几乎零代价 |
| 对称（无 stop-grad）JEPA | 接缝比从约 40 降到 3–4.5，1/3 明确粘合 |

  所以 P(b₁=1 | JEPA) − P(b₁=1 | recon) 的符号取决于 stop-grad，而这一点原设计没有固定。

**并入设计的改动**（都是测量和因子上的修正，不改预测）：
1. jepa 拆成两个变体：jepa-sg（目标为 stop-gradient）和 jepa-sym（对称 VICReg 式，梯度流过两支），作为预注册因子。
2. angle_raw 加一个连续读数，**接缝比**：在 ω 匹配的前提下，±π 两侧潜点的距离，除以其他 θ 处同样角间隔的潜点距离。≈ 1 表示粘合，≫ 1 表示撕开。它与持续同调并列为 angle_raw 的主读数。
3. jepa 的 gate 加一条 θ 可解码检查：cos θ 和 sin θ 的 kNN R² ≥ 0.99。γ = 0 时，"折叠到守恒量（能量、ω 的符号）上"是零损失解，VICReg 的方差 / 协方差项和原 gate 都排除不了它。
4. P0.1 的定理条件改成逐点检查：每个分析点的最近帧解码角与真值相差 < π/2。只看 NMSE < 0.05，像素上仍可能有 RMS ≈ 0.53 reach 的误差。

**新增一条 pilot 之后的预测**（明确标为非盲，单独打分，不能当作"预注册命中"来报告）：
- P0.4′：angle_raw 上，所有带 stop-grad 或解码器的目标（recon-mse、recon-circular、jepa-sg）在 ≥ 2/3 运行上撕开（接缝比 > 5），jepa-sym 的接缝比中位数 < 5。也就是"潜空间继承输入拓扑，除非梯度能同时拉动切口两侧"。

## 1. 世界与数据（锁定）

- **世界**：`pendulum`，ω0 = 1，γ = 0，无动作，dt = 0.1，Verlet n_sub = 20。
- **主数据**：init = "box"，omega_max = 2.5。采样区域是环带，真值 b₁ = 1；有一部分轨迹是转圈运动（E > 1）。
- **负对照数据**：同上，加能量窗 E ∈ [−1, 0.5]（只含摆动）。采样区域是圆盘，真值 b₁ = 0。
  最初的草案写的是 E_hi = 0.8。zoo 审稿人实测发现，真值嵌入上会因此出现长约 0.5 的伪 H1 条（真环带为 1.47），E_hi = 0.9 时达到 0.8，原因是离分界线太近。改为 0.5 后伪条只有 0.14。
- **规模**：每条轨迹 T = 64（65 帧）。train 2000 条（seed = SPLIT_SEEDS["train"]），val 200 条，analysis 500 条（seed = SPLIT_SEEDS["analysis"]，只用于测量）。

## 2. 条件与模型（锁定）

| 观测 | 变体 | 说明 |
|---|---|---|
| angle_cs | recon、jepa-sg、jepa-sym | 输入里已经有圆 |
| angle_raw | recon-mse、recon-circular、jepa-sg、jepa-sym | 输入里没有圆。recon-mse 的输出空间是区间；recon-circular 的损失是 1 − cos Δθ，输出空间是圆 |
| pixels64 | recon、jepa-sg、jepa-sym | 高维观测，渲染本身是 θ 的周期函数 |

（jepa-sg：预测目标取 stop-gradient；jepa-sym：对称 VICReg 式，梯度流过两支。按 §0b 拆分。）

- 共同设置：d = 8，history = 2，K = 8，尺寸 S / M / L / XL（≈ 0.1M / 0.5M / 2M / 8M），种子 0 / 1 / 2。
- 训练：AdamW，lr = 1e-3，batch = 128，angle 与像素都是 20k 步。像素解码器输出层为线性（`pixel_out="linear"`）：用 sigmoid 时，因为背景饱和，S 尺寸会卡在"输出平均图像"的平台上（baseline agent 实测）。
- 负对照只跑尺寸 M：angle_cs 与 pixels64 两种观测 × recon、jepa 两种变体 × 3 种子。

**副因子（第二轮文献 R5 的方法学警示；只在尺寸 M、3 个种子上跑）：**
- jepa 的正则器类型：VICReg vs SIGReg。Nicollier 2026 指出，JEPA 正则器的目标几何本身就是拓扑先验。观测取 angle_raw 和 pixels64，共 2 × 3 = 6 次。若实现 SIGReg 超过半天就放弃，并如实记录。
- 预测时程：K ∈ {1, 8}。Tan 2026 显示时程决定潜空间编码哪些物理量。观测取 angle_cs 和 angle_raw，变体取 recon 和 jepa，共 2 × 2 × 3 = 12 次（K = 8 的运行与主实验共用）。

**gate（不过 gate 的运行不进判据，单独计数报告）：**
- recon：val 上的归一化重建 MSE（除以观测方差）< 0.05。recon-circular 用模 2π 的 `final.val_recon.nmse_wrapped`，否则只差 2π、实际重建完美的运行会被误拒；recon-mse 用原始 nmse。
- jepa（两个变体）：每一维潜变量的 std > 0.1，有效秩 ≥ 2（不塌缩），并且 k = 8 的潜空间预测误差低于"复制 z_t"的误差（metrics.json 里的 latent_pred_err[8] < latent_copy_err[8]）。最后这一条是 baseline agent 发现的：jepa-sg 在训练早期能通过前两条，预测却还不如原样复制。
- θ 可解码 gate（所有变体，在分析集上计算，用真值 θ）：从潜变量回归 cos θ、sin θ 的 kNN R² ≥ 0.99，n = 8000（`analysis/gates.py`）。这条排除"折叠到守恒量上"的解，大约拒掉折叠了 5% 以上状态的潜空间。阈值 0.99 来自校准；n = 8000 是审稿人看过探索性 seed 之后提出的，用来去掉 ω 主导造成的误拒，它在新种子上的数字是干净的，但只有 20 个重复（calibration.md §10.2 第 5 条）。

## 3. 测量（锁定，阈值来自校准）

1. 在 analysis 集上取 z_t = E(o_{t−1}, o_t)，t = 1..64，约 32k 个点。
2. **子采样**：在分析集约 32k 个点上直接做 FPS（最远点采样），n = 600。阈值 τ 与 n 绑定，二者一起锁定（校准 §4.3）。
3. **H1 判据**：数满足 death/birth ≥ τ = 2.8 的 H₁ 条，条数恰为 b₁，并且 R = 4 次"随机取一半点再做 FPS"的子样本中 4 次都如此，才判为"H1 = b₁"。Bobrowski–Skraba 检验只报告、不进判据：它在随机子采样下功效低，在 FPS 下零分布失效（校准 §4.2）。
   已知错误率见第 5 条。
   **另加"绕柱面"条件。** zoo agent 指出，只摆动的能量环也给 b₁ = 1，但这个圈在柱面里可缩，不是 S¹ 因子。所以"H1 = 1"还要求显著类绕柱面一圈：由该类的持续上同调 cocycle 构造圆坐标，它与真值 θ 的 Fisher–Lee 圆相关 |ρ| ≥ 0.5（圆坐标由顶类的 Z₄₇ cocycle 在半寿命尺度上调和化得到，de Silva et al. 2011）。校准中，绕柱面类的 |ρ| ≥ 0.93，只摆动的环 ≤ 0.09，两类间隔很大。判定用的是分析集里每个点的真值 θ，模型看不到这个量。
4. **能量（分级）**：
   - 一级（主判据）：kNN 回归 R² ≥ 0.966（k = 10，n = 2000，5 折 CV），且冻结的二次岭回归 R² ≥ 0.972，两条同时满足才判为"可解码"。局部 Lipschitz 尾比 q99/q50 ≤ 4.13（k = 10，n = 2000）判为"平滑"；Dirichlet 分数 s 只作辅助读数。线性探针 R² 只作描述，不进判据，因为它在真值图 (cos θ, sin θ, ω) 上也只有 0.15。探针只读冻结表示，不微调（Internò 2026）。
   - 二级（副）：开环 rollout 中，解码后物理能量的漂移。recon 用解码帧反推 θ、ω；jepa 用一级的冻结探针。它回答模型的动力学是否在守恒能量。
   - 三级（不做，记为后续）：donor-swap 因果干预（Liao & Cao 2026：可解码 ≠ 被使用）。格 0 只问"承不承载"，不问"用不用"。
5. **仪器的已知错误率**（真值嵌入上，见校准 §0、§4.6）：
   - H1 判据：新种子确认集上正对照 280/280、负对照 140/140 报对。按图计，TNR 的 95% 区间为 0.974–1.00；按重复计（同一重复的对照共享状态，误差相关），20/20，下限 0.83。稳定性规则有 1/140 判为"不稳定"。
   - 绕柱面：200/200 与 40/40。
   - 能量："可解码"要求两条同时满足，留出集上只有 88/100（0.80–0.94），即约 12% 的假阴性；再加上平滑判据是 87/100。在撕开的坐标图上，假阴性达到 50%。单条判据：kNN 93/100，二次 95/100；不可解码对照 0/40 误报；非平滑对照 1/70 误判为平滑。
   - 接缝比：阈值 5 落在粘合（最大 1.21）与撕开（最小 26.3）之间的空隙里。新种子上，粘合 180/180、撕开 160/160 判对，0/340 的 bootstrap 区间跨过 5。
   - 能量仪器的假阴性率为 2–7%，下面所有"≥ 2/3""≥ 90%"类的预测都要把这部分算进去。
6. **数据门**（模型无关，校准 §7 第 4 条）：先在分析集的真值嵌入上跑同一套仪器，必须得出 `ground_truth()` 的 region_betti 与 wrapping。不对就换下一个 seed 重采分析集，最多 3 次，规则事先写死。
7. **超出仪器范围**：校准中，圆方向 ≤ ω 方向的 1/10 时检不出环。凡是潜空间主成分比例超出这个范围的运行，都标为"仪器外推"，并报告 pca3 白化下的诊断读数（不进判据）。
8. **接缝比（angle_raw 的主读数之一，`analysis/seam.py`）**：参数全部锁定为切口窗口 ±0.12 rad、|Δω| ≤ 0.08、7 个对照角、4 个 Δθ 分箱、0.25 的 ω 分箱、min_cut_groups = 10。
   - **主读数**：用全部 ω 计算。
   - **副读数**：只用快速转动（|ω| ≥ 1.6）计算。审稿人 pilot 用的就是这种算法，它和主读数在"随速度变化的部分粘合"上可能给出相反结论，所以两者都报告。
   - **判读**：SR > 5 为撕开，SR ≤ 1.5 为粘合，1.5 < SR ≤ 5 记为"部分粘合"，单独计数，并给出等效间隙。
   - **失效旗标（仪器给出）**：ω 各向异性 κ > 10 时，"粘合"判读无效（拉长 ω 会把撕开的潜空间读成粘合）；fold_index < 0.7 表示一阶折叠。二阶折叠（如 (cos θ, ω)）接缝比看不见，所以"粘合"判读必须同时通过 θ 可解码 gate。

## 6b. 文献定位（第二轮，2026-11-03）

前提已被部分测过，但都是目测：Ivashkov 2026 的 PCA 环面、DySIB 2026 的 R² 环形（十个种子里挑最好的）、Bao 2026 在 DreamerV3 里找到的类能量不变量。

- WM 潜空间持续同调的定量、跨种子、跨尺寸测量；
- 原始 wrapped 角度在无解码器训练下会不会被粘成圆（P0.4）。

还要写明一点：S¹×ℝ ≅ ℝ²∖{0}，所以二维及以上的欧氏潜空间本来就能无切口地承载单摆。单摆上出现 H1，不说明需要几何约束（Kvalheim & Sontag 2025）。

## 7. 风险

- **gate 卡掉太多运行**：那就是"小模型学不会"的结论，照实报告；不能为了凑判据去放宽 gate。
- **H1 判据对潜空间的各向异性敏感**：圆方向 ≤ ω 方向的 1/10 时检不出（校准 §4.4）。超出校准范围的运行标为"仪器外推"。
- **jepa 的 VICReg 权重**：如果只有调过权重才不塌缩，所有 jepa 运行统一用调好的那组，并在报告里写明。

## 大白话

我们想知道：一个只学"预测下一帧"的模型，脑子里会不会自然长出"摆的角度是一个圆"这种结构。

先想清楚一件事。如果模型还被要求"把当前画面画回来"，它就必须分得清所有角度，而角度本身就是一个圆，所以这个圆几乎一定会出现。这部分不是发现，只是检查我们的仪器灵不灵。

真正有意思的是两个情况。

第一，如果给模型的是原始角度数字（从 −180° 到 180°，到头就跳回去），模型脑子里的圆会被撕开还是被粘上？
我的预测：要求它"把角度数字原样画回来"的模型会撕开；只要求"预测未来"的模型会把它粘上。
也就是说，**模型内部的形状由我们让它干什么决定，而不是由数据决定**。

第二，不要求画回画面、只预测内部状态的模型（JEPA 那一类，也是上规模的主流路线），还能不能保住这个圆。
如果保不住，那以后走 JEPA 路线就必须显式地加几何约束。
