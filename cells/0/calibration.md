## 2. 文献核对：Bobrowski & Skraba 2023

出处：O. Bobrowski, P. Skraba, *A universal null-distribution for topological data analysis*, Sci. Rep. 13, 12274 (2023)，doi:10.1038/s41598-023-37842-2。
全文：https://www.nature.com/articles/s41598-023-37842-2 ，PMC：https://pmc.ncbi.nlm.nih.gov/articles/PMC10382541/ 。核对的是正式发表版 PDF。

| 内容 | 原文 | 本仓库实现 |
|---|---|---|
| 乘性持续度 | π(p) = death(p)/birth(p) | 同 |
| ℓ 变换（Eq. 1） | ℓ(p) = A·log log π(p) + B | `topology.bs_ell` |
| 常数 A（Eq. 2） | **A = 1（Rips），A = 1/2（Čech）** | `BS_A = {"rips": 1.0, "cech": 0.5}` |
| 常数 B（Eq. 2） | B = −λ − A·L̄，L̄ = 图中**所有**点的 log log π 均值，λ = Euler–Mascheroni 常数 | 同 |
| 零分布（Eq. 3） | 左偏 Gumbel：F(x) = 1 − e^(−e^x) | `lgumbel_cdf` |
| p 值（Eq. 4） | p = e^(−e^ℓ) | 同 |
| 多重比较 | Bonferroni：p < α/\|dgm_k\| 为信号，文中 α = 0.05 | 同 |

需要更正和提醒的四点：

- **任务说明里的记忆把 A 记反了。** 原文是 Rips 取 1、Čech 取 1/2。ripser 算的是 Rips，所以 A = 1。
- 原文说 LGumbel 的期望"是 Euler–Mascheroni 常数"。严格说期望是 −γ：B 的定义正是让 ℓ 的均值等于 −γ。这只是表述问题，不影响公式。
- **i.i.d. 假设。** 猜想 1 明说点是 i.i.d.。猜想 2 后有一条 Remark："models with homogeneous spacing between the points, such as perturbed lattice models, or repulsive point processes, do not follow Conjecture 2"。**FPS 子样本正是这种排斥过程**，§4.1 的实测证实零分布在 FPS 下失效。
- **B 用整张图估计，并假定信号可以忽略。** 原文的图有成千上万个点。本仓库的图约有 70–2500 条 H₁ 条；m ≈ 150 时，一条信号条对 B 的影响约为 0.02，可以忽略。

### 3.1 世界与采样（与预注册一致）

- pendulum：ω0 = 1，γ = 0，dt = 0.1，init = box，omega_max = 2.5。
- 每个重复用 500 条轨迹 × 64 步，保留 t = 1..64，共 32,000 个状态，与预注册分析集同构。
- box 对照用同样数量的 i.i.d. 初态。
- 真值 b₁ 和绕柱面数直接取 `ground_truth()`：轨迹样本取 `region_betti` / `region_b1_wrapping`，box 样本取 `init_region_*`。
- 非单射映射会改变 b₁，结果由构造给出：撕开图 (θ, ω) 和折叠图 (cos θ, ω) 的 b₁ 都变成 0。
- 随机平滑嵌入用 i-ResNet 式可逆残差 tanh 块：每块残差的 Lipschitz 常数 < 1，所以每块都是同胚。前面接随机等距抬升到 R⁸，后面接条件数为 κ 的随机线性映射。三档强度在 kNN 边上的局部伸缩比 q99/q01 分别约为 1.1、1.5–2.1、3.5–4.3。
- 噪声：各向同性高斯，RMS 范数 = p × 点云 RMS 半径。

### 3.3 能量对照

E = ω²/2 − cos θ。点数 n ∈ {1000, 2000, 4000}，从 32,000 点中随机取。

- **平滑组 S**（用来定阈值）：
  - 恒等 (cos θ, sin θ, ω)；
  - ω × 3 与 ω / 3；
  - 三档 R⁸ 嵌入；
  - 沿能量对称性的折叠：(cos θ, \|sin θ\|, ω) 与 (cos θ, sin θ, \|ω\|)；
  - 撕开图 (θ, ω) 与折叠图 (cos θ, ω)。
- **非平滑组 N**（用来算 FPR）：
  - ω 换成 sin(kω)，k = 3, 10, 30。这时 \|ω\| 有歧义，E 不再是 Z 的函数。
  - patch shuffle：把 (θ, ω) 分成 K × K 格，K = 4, 8, 16，每格随机平移，平移幅度为 ±0.5 × RMS 半径，平移后各格互相重叠。
  - 打乱 E 与 Z 的对应（perm）。
- **分级组 G**（只报告剂量–反应，不参与阈值）：
  - 潜变量噪声 2%、5%、10%、20%；
  - 单射但陡峭的 ω + 0.9 sin(kω)/k，k = 3, 10, 30；
  - 极端各向异性 ω × 10、ω / 10。
- 可解码性的 FPR 只在 sin(kω) 和 perm 上算。patch shuffle 在可解码性上算分级。

## 4. 拓扑：方法与结果

### 4.1 方法

1. **子采样。** FPS（贪心最远点，起点由 seed 决定）或随机无放回。可选 PCA 白化，在全部 32,000 点上拟合后再子采样：pca3 是前 3 个主成分各自缩放到单位方差；full 是全部主成分，等于仿射不变化。
   所有判据只用 π = death/birth，对全局缩放不变，所以按中位 kNN 距离做尺度归一化不改变任何判定（已实现，记录在案）。
2. **持续图。** ripser，Vietoris–Rips，H₁，Z₂ 系数。为省时间，阈值从 T₀ = 2 × q99(10-NN 距离) 起，逐步抬高，直到每一条都满足二者之一：精确，或被证明 π ≥ π_need（默认 6；做 B&S 检验时取 Bonferroni 临界值）。
   所以凡是"π 与 ≤ 6 的数比较"的判定都是精确的。和完整 filtration 对比过（测试 `test_adaptive_threshold_matches_full_filtration`）。n = 1000 时最多快 27 倍（13.2 s → 0.48 s）。
3. **判据。**
   - (a) Bobrowski–Skraba，Bonferroni，α = 0.05；
   - (b) 乘性持续度：`thr` 数 π ≥ τ 的条；`gap` 取 π₍ₘ₎/π₍ₘ₊₁₎ 最大处的 m，要求比值 ≥ g；`thrgap` 两者都要；
   - (c) 稳定性：R = 4 个子样本（随机，或"随机半数 + FPS"），众数出现比例 ≥ τ_s 才报告。
4. **拟合 / 留出 / 确认三分。**
   - 每个对照 20 个独立重复：r < 10 拟合，r ≥ 10 留出，r = 20..39 是新种子确认集（§4.6）。每个重复的 zoo 状态和随机嵌入都重新抽。
   - 拟合目标：在核心对照上最大化 min(TPR, TNR)。TPR 是 b₁ ≥ 1 的核心对照"报对 b₁"比例的平均，TNR 是 b₁ = 0 的核心对照"报 0"比例的平均。
   - 取最优参数集合的几何中心（"高原中心"），让阈值离噪声上沿和最弱信号都远。
   - 配置之间的排序规则在全量运行前写死：核心目标 > 压力对照得分 > 较小的 n > 较少的部件 > FPS。

### 4.2 Bobrowski–Skraba：随机子采样下近似成立，FPS 下失效，两种情况功效都低

零分布检查用核心负对照的全部 H₁ 条，正对照去掉真信号条：

| | 随机 300 | 随机 600 | 随机 1000 | FPS 300 | FPS 600 | FPS 1000 |
|---|---|---|---|---|---|---|
| 名义 5% 下的单条拒绝率（应为 5%） | 3.3% | 3.6% | 3.9% | **0.0%** | **0.0%** | **0.0%** |
| 名义 1% 下的单条拒绝率 | 0.2% | 0.2% | 0.2% | 0.0% | 0.0% | 0.0% |
| 每图 KS 距离（均值） | 0.082 | 0.059 | 0.047 | 0.130 | 0.121 | 0.123 |
| 合并 ℓ 的 KS 距离 / 标准差（LGumbel：1.283） | — | 0.025 / 1.23 | — | — | 0.107 / 1.07 | — |
| Bonferroni 临界 π*（中位数） | 4.0 | 5.0 | 5.7 | 5.6 | 7.0 | 8.5 |
| 负对照整图假阳性 | 0/140 | 0/140 | 0/140 | 0/140 | 0/140 | — |
| **功效：核心正对照报对 b₁（留出）** | 65/140 | 92/140 | 117/140 | 44/140 | 59/140 | — |

- **随机子采样。** ℓ 的分布贴近 LGumbel，合并 KS 距离 0.025；尾部略保守，名义 5% 实为 3.5% 左右。
- **FPS。** ℓ 分布明显变窄：标准差 1.07 对 1.28，q99 为 0.80 对 1.53。原因是 FPS 把点排得像格点，噪声环一律很短命、彼此相似。检验因此极保守，单条拒绝率 0%；临界 π* 也更高，真环反而认不出来。
- **功效低的原因。** Bonferroni 要对 70–1300 条修正，而本场景的真环 π 在 n ≤ 1000 时只有 4–9（随机子采样下约 √n 增长），刚好在临界值附近。
- **结论。** B&S 安全但近乎失明，不适合 n ≤ 1000 的格 0；FPS 时不能用。FPS n = 1000 时 B&S 没有精确计算：精确计算要把 filtration 推到临界值，成本高，且零分布已经失效。

它在留出集上有一个假阳性：disk_ref 的留出重复 r = 13，π = 3.24。原因已经查清：

- 这个重复的 500 条轨迹里，最内层轨道的相空间半径是 0.215（E + 1 = 0.023）。其余 19 个重复的中位数是 0.075，最大 0.155（由 `analysis.controls.pendulum_states` 对同一批 seed 重算）。所以样本在稳定平衡点周围真的留了一个洞。
- FPS 在 n = 1000 时点距约 0.11，能分辨出这个洞，于是出现 π ≈ 3 的条。同一样本在 n = 600 时 π = 2.61，低于 2.8。
- 在洞里补点以后，这条消失：n = 1000 时 π 从 3.04 降到 1.69。这次检查的 FPS 起点（seed 0）与校准运行不同，所以补点前是 3.04，不是 3.24。

所以这不是仪器噪声，而是**有限轨迹样本在当前分辨率下的真实拓扑**。n 越大，越容易看见采样空洞。这一条直接影响预注册的负对照（§7）。

### 4.5 稳定性判据

- "随机半数 + FPS"的 4 次子采样（τ_s = 0.8，R = 4 时即 4/4 全票）在 n = 300 和 600 上都是 140/140、70/70。随机子样本的稳定性判据（n = 300，τ_s = 0.6 即 ≥ 3/4）是 135/140、70/70。
- 稳定性没有让单次 FPS 判据变得更好，因为单次已经满分。它的价值是给预注册的"在 R 次子采样上报告恰好 b₁ 的比例"一个已知行为：FPS-half 下，留出集里的核心对照全部 4/4 一致。
- 代价约是单次判据的 3 倍（n = 600 时中位 0.89 s）。

### 4.7 绕柱面

- **方法。** 在 FPS n = 600 子样本上，用 Z₄₇ 系数算顶类的持续上同调 cocycle，提升为整数 cocycle，在半寿命尺度 r = b + (d − b)/2 的 Rips 复形上做最小二乘调和化，得到圆坐标 φ = 2π(f mod 1)（de Silva, Morozov & Vejdemo-Johansson 2011）。然后算 φ 与这些点的真值 θ 的 Fisher–Lee 圆相关 \|ρ\|，并在 12 个 θ 分箱上估计映射度。
- **阈值与留出表现。** 拟合高原中心是 \|ρ\| ≥ 0.5。留出：绕柱面的核心类 100/100 通过（0.96–1.00），只摆动的环 20/20 被拒（0.83–1.00）。"映射度 = ±1"判据给出同样结果。
- **分布。** 绕柱面核心对照的 \|ρ\| 中位数在 0.944–0.997，最小 0.930。能量环 ring_ref / ring_emb8 的中位数为 0.021 / 0.027，最大 0.084。
- **压力对照。** emb8_strong 中位 0.89，最小 0.75；thin 1/10 中位 0.84。thin ≤ 1/20 和 aniso 1/10 的顶类本来就不是那个环，\|ρ\| ≈ 0。
- **适用条件。** 这一步要用分析集每个点的真值 θ（模型看不到），只能在 H1 已检出之后用。

## 5. 能量：方法与结果

### 5.1 方法

- **探针。** 5 折 CV，合并折外预测，R² = 1 − SSE/SST。
  - 线性岭回归（标准化，RidgeCV）；
  - 二次岭回归（二次多项式特征）；
  - kNN 回归，k ∈ {5, 10, 20}，用 Z 本身的欧氏度量；
  - RBF 核岭回归：每个训练折内用精确留一法选带宽和岭参数，n = 600。
- **平滑度。** 在 Z 的 kNN 图上：
  - D(Z, E) = 边上 (E_i − E_j)² 的均值 / Var(E)；
  - D_perm = 2N/(N − 1)，是置换零分布的精确期望；
  - D_ref 是同一批状态的 (cos θ, sin θ, ω) 上的 D；
  - s = (D_perm − D_Z)/(D_perm − D_ref)；
  - 另算 kNN 边上 \|ΔE\|/\|Δz\| 的 q99/q50（Lipschitz 尾比）。
- **阈值。** 平滑组拟合一半的第 5 百分位（尾比取第 95 百分位）。在留出一半上报告平滑组的 TPR 与非平滑组的 FPR。

读法：

- **线性探针在真值图上只有 0.15。** E = ω²/2 − cos θ 对 ω 是二次的，而 ω 的分布关于 0 对称，ω² 与 ω 不相关。线性 R² 取决于潜空间恰好有没有类似 ω² 的方向：R⁸ 随机嵌入给 0.67–0.71，折叠 \|ω\| 给 0.93。
  所以预注册里的"冻结的低容量**线性**探针 R² ≥ 阈值"在这个世界里定义不良：阈值会落到 0 附近，FPR 达 78%（31/40）。
  建议改成**二次岭回归**。它仍然冻结、低容量：d = 8 时只有 44 个特征。在全部平滑对照上它是 1.000，撕开图是 0.972，因为 cos θ 不是 θ 的二次函数。
- **s 本质上是"相对真值图的局部可预测性"**，数值与 kNN R² 很接近。它能认出 sin(kω) 和打乱，但对大格 patch（少量撕裂）几乎不敏感，K = 4 时 0.976。

- **KRR（选好带宽）对所有平滑对照都给 R² ≈ 1**（到 1e-6），所以"第 5 百分位"阈值退化成 0.9999992，留出 TPR 只有 0.89。它只适合当上限读数，不适合当判据。CV 选出的带宽本身有信息：平滑组选宽核（γ ≤ 2），patch 与 k = 3 的陡峭函数选窄核（γ = 8）。

### 5.4 沿能量对称性的折叠：能量仪器看不见，拓扑仪器部分看得见

E 在 θ → −θ 与 ω → −ω 下不变。所以三种折叠在所有能量分数上都与恒等无异：s ≈ 1.01，尾比 2.8–3.2，kNN ≈ 0.995，二次 = 1.000。

- (cos θ, \|sin θ\|, ω) 和 (cos θ, ω) 把圆折成线段，拓扑仪器报 b₁ = 0（folded 对照 70/70 报 0）。
- (cos θ, sin θ, \|ω\|) 把柱面折成半柱面，**仍是环带，b₁ = 1，绕柱面**。两套仪器都不会报异常。另用 3 个新 seed 核对过（FPS n = 600）：π₁ ≥ 6，\|ρ\| = 0.97–0.99，映射度 ±1；(cos θ, \|sin θ\|, ω) 则报 b₁ = 0。
- 结论："能量可解码、平滑"**不**意味着潜空间是单射的。判断单射要靠拓扑与绕柱面检查，而且 ω → −ω 折叠两套仪器都看不见。要检查它，得看 ω 的符号能否被解码，比如用 sin θ·ω 或 ω 本身的探针。这一项不在本次校准范围内。

## 6. 每个仪器能检测什么、不能检测什么

| 仪器 | 能检测 | 不能检测 / 失效模式 |
|---|---|---|
| FPS + π 阈值（H1 计数） | 粗细合适的环：b₁ = 0 / 1 / 2 在核心对照上留出全对。对 R⁸ 平滑嵌入、5% 噪声、密度不均、环不在前 3 主成分都稳健 | (1) 度量上很薄的环：圆方向 ≤ ω 方向的 1/10 时检不出，强畸变时只检出 70%。(2) 分辨率以下的结构：比 FPS 点距小的撕裂会被"粘上"，比点距大的采样空洞会被当成真环（§4.3）。所以 b₁ 是"在分辨率 n 下的 b₁"。(3) 不区分环是否绕柱面 |
| B&S 检验 | 随机子采样下单条 p 值近似校准：实际 3.5%，名义 5% | n ≤ 1000 时功效低；FPS 下零分布失效、极保守 |
| PCA 白化 | 线性压扁的环：thin 到 1/30、aniso 1/10 | pca3：环不在前 3 个主成分里时把环删掉。full：放大纯噪声方向，把环淹没 |
| 绕柱面（\|ρ_FL\|） | 区分"绕柱面一圈"和"柱面里可缩的环"，两类间隔很大 | 依赖真值 θ（仅分析用）；只对已检出的类有意义 |
| 二次岭 R² | E 是否为潜坐标的低次函数（冻结、低容量） | 依赖坐标图：撕开图只有 0.972；对"弯得厉害"的平滑嵌入会偏低 |
| kNN R² | E 是否由潜变量局部决定，与坐标图无关 | 对各向异性敏感：ω ÷ 10 时 0.876；对少量撕裂不敏感（patch K = 4 时 0.96） |
| s（Dirichlet） | E 是否几乎处处局部恒定（sin(kω)、打乱） | 看不见少量撕裂；对各向异性敏感 |
| Lipschitz 尾比 | 撕裂、陡峭区 | 噪声 ≥ 5% 也会被判"不平滑"；只占不到 1% 边的撕裂看不见 |
| 全部能量仪器 | — | 看不见沿 E 对称性的折叠；"可解码"不等于"被模型使用"（Liao & Cao 2026） |

  - 切口窗口里约有 1,010 个点、9,930 对跨切口点对。
  - i.i.d. box 样本是 1,210 个点、11,600 对。
- 结果在 JSON 的 `seam`（汇总，含 `seam.theta_gate`）和 `raw_seam`（逐重复）里。运行命令见 §8。

### 9.2 接缝比的定义

1. **参考角。** 切口 a = π，外加 7 个对照角：每 45° 一个，π 本身除外。
2. **窗口与点对。**
   - 窗口是 \|wrap(θ − a)\| < w，w = 0.12 rad，分成左右两侧。
   - 跨窗口点对：左右各取一点，并要求 \|Δω\| ≤ 0.08，即 ω 匹配。
3. **分层。** 按点对的平均 ω（宽 0.25 的箱）和角间隔 Δθ（把 (0, 2w) 等分成 4 箱）分层。"同样的角间隔、同样的 ω"因此逐层成立。
4. **每层的比值。**
   - 分子：切口在该层的中位距离 m_cut(s)。
   - 分母 den(s)：7 个对照角各自的中位距离，再取中位数。用中位数而不是合并，是为了不让某一个各向异性的方向决定尺度。
   - 至少 3 个对照角、每个角至少 10 对，该层才可用。
5. **合成。** SR = exp( Σ_s n_s · log(m_cut(s) / den(s)) / Σ_s n_s )，n_s 是切口在该层的点对数。也就是逐层的中位数之比，按切口点对数加权取几何平均。
6. **数据不足。** 可用层少于 3 个，或可用点对少于 50 对时，报"数据不足"。例如只摆动的数据到不了 θ = π。
7. **不确定性。** 按轨迹做 cluster bootstrap，200 次，取百分位 95% 区间。
   - 同一轨迹内的点对按 m_g 计权，轨迹之间的点对按 m_g·m_h 计权，两者的期望都约为 1。
   - 第一版用的是 m_g²，同一轨迹相邻帧的点对被加倍计权，区间会系统地偏到点估计的一侧，已改正。
8. **诊断读数**（都不进判据）：
   - **placebo**：把某个对照角当作切口、其余对照角当作分母算出的 SR。平滑潜空间上应约为 1，可以当作同一潜空间的内部零分布。
   - **ω 剖面**：每个 ω 箱单独算的 SR，用来看部分粘合。
   - **fast-only**：只用 \|ω\| ≥ 1.6 的点，也就是审稿人 pilot 的限制条件。

性质：

- 对平移、旋转、整体缩放严格不变。测试里变换前后的相对差 < 1e-9。
- 对各向异性缩放不是不变的，见 §9.4。
- SR 的刻度与窗口绑定。切口处间隙为 g 时，SR ≈ g / 典型点对距离。所以 w、Δω 容差和箱宽必须与阈值一起写死，这和 τ 与 n 绑定是一回事。

**一处估计量的修订，如实说明。** 第一版取的是"所有切口点对的 d / den(s) 的中位数"。

- 在撕开的点云上，归一化距离会按 Δθ 箱聚成几团，中位数在团之间跳，重复之间最多差 40%：torn_r2 的 20 个重复散在 40.6–57.9。
- 改成逐层几何平均以后，torn_r2 的范围是 47.5–51.7，圆弧族每个 α 的离散度在 ±5% 以内。
- 第一版的分离结论相同：粘合核心最大 1.21，撕开核心最小 25.9，阈值 5 在留出集上全对。
- 修订时只看过本节的真值对照。本节所有数字都来自修订后的完整重跑。

### 9.6 随速度变化的部分粘合：两种口径会给出相反结论

| 对照 | SR（全部 ω） | 判为撕开（> 5） | fast-only（\|ω\| ≥ 1.6） | pilot 公式 | H1 判 b₁ = 1 |
|---|---|---|---|---|---|
| arc_rot_glued（只粘快转） | 16.0（8.7–21.5） | 20/20 | 0.995（0.962–1.03） | 1.01 | 0/20 |
| arc_rot_torn（只粘慢转） | 3.88（2.67–8.53） | 5/20 | 42.8（40.7–48.5） | 41.8 | 20/20 |

- **ω 剖面能把两种情况分开。** arc_rot_glued 在 \|ω\| ≥ 1.5 的箱里 SR ≈ 1.0，在 \|ω\| ≤ 1 的箱里是 43–45。arc_rot_torn 正好相反。
- **全部 ω 的 SR 是按点对数加权的平均，切口窗口里慢的点对占多数。** 约 62% 的切口点对 \|ω\| < 1.25，只有约 19% 在 \|ω\| ≥ 1.5（由 `raw_seam` 里 ω 剖面的点对数算出，20 个重复的中位数）。
  所以"只粘快转"被判为撕开；"只粘慢转"落在阈值附近：中位数 3.9，bootstrap 区间的中位是 2.6–6.2，跨过 5。
- **H1 看的是整体拓扑。** 它对 arc_rot_glued 判 b₁ = 0，对 arc_rot_torn 判 b₁ = 1。
- **pilot 公式只看 \|ω\| > 1.6 的快转动。** 它给出的结论与全部 ω 的 SR 相反。所以 pilot 报告的"jepa-sym 接缝比 3–4.5"是只看快转动的口径，不能直接搬到全部 ω 的口径上。
- **两种口径在完全粘合或完全撕开时一致。**
  - fast-only 下，粘合核心最大 1.17，撕开核心最小 26.3，阈值 5 下判对 180/180 与 160/160。
  - pilot 公式与本仪器在 §9.4、§9.5 的对照上数值接近：粘合约 1，撕开 31–51，α = 0.9 时是 6.27 对 6.50。

### 9.7 内部零分布与 bootstrap 的诚实度

- **placebo。** 核心对照共 17 × 20 = 340 次，placebo 最大值的中位数是 1.014，q99 是 1.19，最大 1.23。强畸变下可到 1.74，各向异性下 1.27–1.36。
  所以 placebo 最大值超过约 1.3，说明潜空间的度量沿 θ 变化很大。这是一条只用同一潜空间就能做的自检。
- **bootstrap 区间。** 用 11 个固定映射的核心对照检查（随机 R⁸ 嵌入每个重复都重抽，bootstrap 看不到这部分变异，所以排除）：
  - 95% 区间覆盖该对照 20 个重复中位数的比例是 205/220 = 0.93（0.89–0.96）；
  - bootstrap 的 log 标准差与重复之间的 log 标准差之比，中位数 1.14，范围 0.68–2.25。
  区间大体诚实。撕开对照的比值偏窄（0.68–0.90），但它们的 SR 约为 50，不影响判定。
- **运行时间。** 32,000 个点、含 200 次 bootstrap，每个点云中位 0.33 s，最长 0.66 s。

### 9.8 θ 可解码 gate

- **定义。** 在 2000 个随机点上，用 kNN（k = 10，5 折）预测 cos θ 和 sin θ，取两者 R² 中较小的那个，记为 r2_min。探针设置与能量探针相同。
- **gate。** r2_min ≥ 阈值。预注册提议 0.99。

| 组 | 对照 | r2_min 中位数（最小） | 0.99 下通过 |
|---|---|---|---|
| θ 单射·核心（13 个） | ref、ref_s3、box、emb8_mild、torn、fold_omega (cos θ, sin θ, \|ω\|) | 0.997–0.999 | 20/20 |
| | emb8_medium、torn_emb8、helix、noise2、noise5 | 0.994–0.997（最小 0.993） | 20/20 |
| | ref_s0.3（ω 方向拉长 3.3 倍） | 0.9901（0.9880） | 13/20 |
| | emb8_strong | 0.9951（0.9690） | 17/20 |
| 折叠 / 只剩守恒量·核心（7 个） | (cos θ, \|ω\|)、(cos θ, ω)、(cos θ, \|sin θ\|, ω) | −0.10 左右；cos θ 的 R² 仍有 0.998–0.999 | 0/20 |
| | (E, sign ω)、(E)、(E, sign ω) → R⁸ | −0.09 左右；cos θ 的 R² 约 0.24 | 0/20 |
| | (E, \|ω\|) | −0.10；cos θ 的 R² 0.9955 | 0/20 |
| 分级 | 噪声 10% / 20% | 0.985 / 0.946 | 0/20、0/20 |
| | thin 1/3、1/10 | 0.991、0.961 | 19/20、0/20 |
| | aniso 1/10 | 0.634 | 0/20 |

- **拟合。** 规则与能量判据相同，取单射核心拟合一半的第 5 百分位，得 **0.990**，与预注册的 0.99 一致。
- **留出，阈值 0.99。** 单射对照 125/130 通过（0.913–0.987），折叠对照 0/70 误放（0–0.051）。阈值取拟合值 0.9903 时是 123/130 与 0/70。
- **两类分得非常开。** 折叠类全部 ≤ −0.055，单射核心全部 ≥ 0.969。gate 能可靠地排除"折叠到守恒量上"的零损失解。
- **0.99 的代价在单射一侧。** 留出集上约 4% 的单射核心被误拒。核心里的误拒集中在 ω 方向拉长 3.3 倍（20 个重复里 35% 被拒）和强畸变（15%）；分级对照里，噪声 ≥ 10% 全部被拒。
  原因是 cos θ 的 kNN R² 量的是"10 个潜空间近邻之间 θ 变化多少"。ω 主导度量时，近邻沿 θ 方向铺得更开，R² 就下降。
- **可选方案。** 两类之间的空档很大，把阈值降到 0.9 也会拒掉全部折叠对照，并让全部单射核心通过（最小 0.969），thin 1/10 和 20% 噪声也能过。但这是看过数据之后的选项，它的错误率要用新 seed 另测。
- **gate 不管的事。** 它只看 θ，看不见 ω → −ω 的折叠（fold_omega 能通过）；它也看不见撕开（torn 能通过），那是接缝比的事。

### 9.9 P0.1 的逐点检查

- `pointwise_angle_check(θ̂, θ)` 返回圆周误差 < π/2（严格小于）的点所占比例。非有限值算失败。P0.1 的定理条件是 `all_ok`，即每个分析点都通过。
- 解码角的来源：
  - angle_cs 用 `angle_from_cs`；
  - 像素用 `nearest_frame_angle`：取一组已知角度渲染出的帧，找离解码帧最近的那一帧。
- 这是定义，不需要校准。测试覆盖了 ±π 处的回绕、π/2 的严格边界、NaN，以及最近帧解码的误差小于网格步长。

### 9.10 对预注册的建议（只是建议，`cells/0/prereg.md` 没有改动）

1. **P0.4′ 的阈值 5：校准支持。**
   - 它落在核心对照的分离高原 [1.23, 26.9] 内，离两侧都有 4 倍以上的余量。事先规则的拟合值 5.75 与它接近。
   - 在部分粘合族上，SR = 5 与 H1 判据的翻转点几乎重合（间隙 0.50 对 0.58）。用 5 时，angle_raw 两条主读数对"撕开"的定义一致。用 5.75 时 t_omega_x30 会漏判。

   - 5 在高原里的位置有一个未解决的问题，κ 与折叠指数两个范围条件也要一起写死，见 §10.2、§10.4。
2. **已知错误率。** 核心对照 20 个重复全部判对：粘合 180/180，撕开 160/160；留出一半是 90/90 与 80/80。检测极限是撕开图的 ω 方向拉长 30 倍，此时 SR ≈ 5.1。
3. **运行前要定的一件事。** P0.4′ 的接缝比用全部 ω（prereg 的文字，也是本仪器的默认），还是只用快转动 \|ω\| ≥ 1.6（pilot 的做法）？两种口径在完全粘合 / 完全撕开时一致，在随速度变化的部分粘合上结论相反（§9.6）。建议主读数用全部 ω，同时报告 fast-only 和 ω 剖面。
4. **区间。** 报告 SR 时附上按轨迹 bootstrap 的 95% 区间。区间跨过 5 的运行标为"接缝不确定"，并单独计数。
5. **θ gate。** 0.99 有校准支持（就是拟合值），已知会误拒约 4% 的单射潜空间，主要是 ω 主导度量的那些。另一个选项是 0.9，见 §9.8。由 Z 二选一，并在运行前写死。第二轮审稿又给出第三个选项：n = 8000、阈值 0.99（§10.2 第 5 条）。
6. **P0.1。** 用 `pointwise_angle_check(...)["all_ok"]`。

- **对照的真值。** 各对照的 b₁ 与绕柱面数和 zoo 的 `ground_truth()` 一致：全环带 1 / 1，能量环 1 / 0，只转动 2 / 2，圆盘 0。

### 10.2 发现的问题和改动

**1. ω 方向的各向异性能让撕开的潜空间读成"粘合"。**

ω 匹配允许 |Δω| ≤ 0.08。ω 方向拉得很长时，每个点对距离里的 Δω 部分都会压过 Δθ 部分，SR 被拉向 1。

| 撕开图 (θ, cω) | c = 10 | 20 | 30 | 50 | 100 |
|---|---|---|---|---|---|
| SR 中位数（20 个新重复） | 14.6 | 7.6 | 5.2 | 3.2 | 1.8 |

c ≥ 50 时被判为"粘合"，placebo 也看不出来（约 1.03）。

- **改动。** `seam_ratio` 新增 `omega_aspect` κ：在对照角的点对上用最小二乘拟合 |Δz|² ≈ aΔθ² + bΔω² + cΔθΔω，κ = √(b/a)。它就是潜空间里单位 ω 的长度与单位 θ 的长度之比，对 (θ, cω) 恰好等于 c。
- **规则。** `seam_flags` 在 κ > 10 且判为"粘合"时给出 `in_range = False`。稀释只会把 SR 拉向 1，所以"撕开"的判断照样成立，"粘合"的判断不再可信。拉长 ω 的粘合图读数约 0.84，不会越过 5。
- **核心对照不受影响。** κ 在 0.33–3.34 之间，340 次里没有一次被标记。

**2. "在切口处连续、但已经折叠"的潜空间会被读成"粘合"。**

(|θ|, ω) 和 (cos θ, |sin θ|, ω) 在 ±π 处是连续的，但 θ 与 −θ 重合，b₁ = 0。它们的 SR ≈ 0.48，判为"粘合"。

- **改动。** 新增 `fold_index`。在切口的每一层里，取两侧偏移 a ≈ b 的"镜像"点对与 a、b 悬殊的点对，比较两者的中位距离。
  - 20 个新重复上：一阶折叠 ≤ 0.58；核心对照 ≥ 0.97；非折叠的压力对照 ≥ 0.86，包括拉长 ω、沿切口压扁、强畸变和 20% 噪声。
  - 阈值 0.7 下，一阶折叠 60/60 被标出，非折叠 600/600 都没有被误标。
- **如实说明拟合的过程。**
  - 事先声明的规则把二阶折叠 (cos θ, ω) 也算作要抓的对象。
  - 但折叠指数按构造看不见二阶折叠：那里两侧的差是 Δθ 的二次量，被 Δω 淹没，指数在 0.85–1.08 之间。
  - 这条规则拟合出的阈值是 0.977，在留出集上误标了 16% 的非折叠压力对照，不能用。
  - 0.7 是跑之前写进代码的，但"保留 0.7"是看过结果以后的决定。事后只对一阶折叠重新拟合，高原为 [0.59, 0.955]，中心 0.74，0.7 在高原内。
- **二阶折叠没有被挡住。** (cos θ, ω) 的 SR = 0.36，判为"粘合"，κ 和折叠指数都不报警。它只能靠 θ gate 排除（r2_min ≈ −0.10）。
- **结论。** 接缝比的"粘合"必须和 θ gate 一起用，recon 变体也一样。recon 的解码器要求 θ 可解码，正常情况下 gate 会自动通过。

**3. 切口处的轨迹数。**

- **改动。** 新增 `n_cut_groups`。传入 `groups` 时，跨切口的可用点对如果来自少于 10 条轨迹，就判为"数据不足"。
- **影响。** 校准和复核数据里最少有 225 条，所以不影响任何已有数字。
- **稀疏切口的检查**（探索性 seed）。只留 10 条过切口的轨迹时，SR 仍然判对（粘合 0.94，撕开 49），区间变宽，没有退化成一个点。

**4. 能量判据的假阴性率被低估了。**

prereg §3.4 把"可解码"定义为 kNN R² ≥ 0.966 **且**二次 R² ≥ 0.972。§0 和 prereg §3.5 只给了单条判据的 93/100 和 95/100。

- **两条同时满足**：留出 88/100（0.80–0.94）。再加上平滑判据，是 87/100（0.79–0.93）。
- **逐个对照**：ω ÷ 3 只有 4/10。撕开图 (θ, ω) 只有 5/10，因为 cos θ 不是 θ 的二次函数。所以 angle_raw 上撕开的潜空间约有一半会被判为"不可解码"，这来自仪器，不是模型。
- **对预测的含义。** 设每次运行的通过概率是 0.88，即使所有模型都真的可解码：

| 预测形式 | 成立的概率 |
|---|---|
| 3 个种子中 ≥ 2 个 | 0.96 |
| 12 次中 ≥ 11 次 | 0.57 |
| 6 次全过 | 0.46 |

**5. θ gate 取 0.99 的含义和代价。**

- **新种子上，prereg 设定（n = 2000）。** 单射核心 250/260 通过（0.930–0.981），误拒集中在 ref_s0.3（30%）和 emb8_strong（20%）。折叠对照 0/140 误放。按重复计，20 个重复里只有 12 个全部单射对照都通过。
- **新增分级对照。** 只对能量最低的 q 比例状态做 θ → −θ 折叠，r2_min 的中位数如下：

| q | 2% | 5% | 10% | 20% |
|---|---|---|---|---|
| r2_min（n = 2000） | 0.996 | 0.986 | 0.952 | 0.833 |

  所以 0.99 会拒掉折叠了约 5% 以上状态的潜空间。0.9 放行 10% 的折叠，拒掉 20% 的折叠。
- **跑之前声明的两个替代方案**，新种子上都是单射 260/260、折叠 0/140：
  - n = 2000，阈值 0.9：10% 的折叠全部放行。
  - n = 8000，阈值 0.99：ω ÷ 10 与 thin 1/10 也能通过；5% 的折叠放行 55%，10% 的折叠全部拒掉；10% 噪声仍被拒。
- **建议。** 在"n = 8000，0.99"与"n = 2000，0.99"之间选。前者保留 0.99 的含义，同时去掉 ω 主导造成的误拒。代码默认仍是 n = 2000。

**6. 二项区间的口径。**

§0 的 Clopper–Pearson 区间把每张图当成独立试验。但同一个重复里的各个对照共用同一批 zoo 状态，出错时往往一起出错，所以这些区间偏窄。

最保守的口径是"按重复计"：一个重复里所有对照都对，才算这个重复对。

| 读数 | 按图计 | 按重复计 |
|---|---|---|
| H1 确认集（280/280、140/140） | 下限 0.987 / 0.974 | 20/20，下限 0.83 |
| 接缝比留出（80/80、90/90） | 下限 0.955 / 0.960 | 10/10，下限 0.69 |
| 接缝比新种子（160/160、180/180） | 下限 0.977 / 0.980 | 20/20，下限 0.83 |
| θ gate 留出（125/130） | 0.913–0.987 | 只有 5/10 个重复全部通过 |

真实的区间落在两种口径之间。prereg §3.5 引用的"TNR 区间 0.974–1.00"应注明它是按图计的。

### 10.3 冻结阈值在新种子上的复核

- 17 个核心对照 × 20 个新重复，阈值取 5 和 5.75 结果相同：粘合 180/180，撕开 160/160。
- 粘合最大 1.20，撕开最小 26.8；bootstrap 区间跨过 5 的有 0/340 次；fast-only 口径也全对。

### 10.4 仍不确定、要由 Z 决定的事

1. **5 在高原里的位置是任意的，而 pilot 的 jepa-sym 读数正好落在它下面。**
   - 核心对照只说明阈值应在 [1.23, 26.9] 内。P0.4′ 写于 pilot 之后，pilot 公式（只看快转动）给 jepa-sym 的值是 3–4.5。
   - 在圆弧族上，SR = 3 / 4.5 对应间隙 0.26 / 0.44，约为周长的 4–7%。在这些间隙上 H1 判据仍判 b₁ = 1。
   - 如果阈值取 2（同样在高原内），这些值就算撕开。支持 5 的只有一条真值上的论证：在圆弧族上，它与 H1 的翻转点重合（§9.5）。
   - 建议：报告 SR 时同时给出圆弧族上的等效间隙，并把 1.5 < SR ≤ 5 记为"部分粘合"，单独计数。
2. **ω 口径仍未定。** 用全部 ω 还是只看快转动，见 §9.6。
3. **κ 的上限 10 只来自 (θ, cω) 这一族。** κ ≈ 10 再叠加噪声或强畸变时，余量会更小，这种组合没有测过。
4. **折叠指数只对全局的一阶折叠校准过。** 只在切口附近折叠的潜空间没有对照。
5. **n = 8000 这个方案是看了探索性 seed（3_970_01x）之后提出的。** 新种子上的数字是干净的，但只有 20 个重复。
6. **angle_raw 上的能量判据。** 撕开图上二次探针失败是结构性的，"可解码"在 angle_raw 运行上是否只看 kNN，需要定下来。

## 大白话

我们要量的是两件事：模型脑子里的点是不是围成一个圈，以及能量能不能从这些点上平滑地读出来。
正式测模型之前，先在答案已知的假数据上把尺子校准好，知道尺子什么时候会说错。

**数圈。**

- 好用的办法是"最远点抽样"。从 3 万个点里挑 600 个尽量分散的点，再看哪些圈活得够久：消失时的尺度除以出现时的尺度要 ≥ 2.8。
- 在 20 种答案已知的情况里，包括真圈、两个圈、撕开、折叠、圆盘、高斯团，留出的 210 次测试全对。
- 文献里那个"通用零分布"检验很严谨，但在这个规模下太保守，真圈只认出一半到八成。用最远点抽样时它的前提直接不成立。

**尺子的盲区。**

- 太扁的圈认不出：圆的粗细不到另一个方向的 1/10 时就看不见。
- 分辨率之下的东西会被弄混：抽样留下的小洞会被当成圈。我们在一个只摆动的数据里真碰上了一次：平衡点附近恰好没有轨迹经过。所以负对照最好问"有没有绕柱子一圈的圈"，而不是"有没有圈"。

**绕柱子。**

用圈上的点算一个"圆坐标"，看它和真实角度是不是同步转一圈。真绕柱子的圈相关性在 0.93 以上，只摆动的圈在 0.09 以下，中间切一刀就分开了。

**能量。**

- "线性读出"这个尺子不能用：能量里有速度的平方，最完美的表示用线性读出也只能读出 15%。
- 改用"二次读出"或"看邻居猜"。
- "平滑"用"相邻两点能量差除以距离"的极端值来量，最能抓住撕裂。
- 有一种情况这些尺子永远看不见：模型把"往左摆"和"往右摆"叠在一起，因为它们的能量本来就相同。

**接缝。**

- 原始角度在 ±180° 处会突然跳一下。我们量模型脑子里"179°"和"−179°"这两个点离得多远，再和"别处同样只差 2° 的两个点"比。
- 粘起来时这个比值约为 1，撕开时约为 30 到 55。阈值 5 正好落在中间。
- 而且在"粘了一半"的假数据上，比值越过 5 的地方，正好也是数圈的尺子改口的地方。
- 要小心一件事：这个比值是把所有速度平均起来的。如果模型只把转得快的那部分粘上，平均值仍可能说"撕开"。所以还要看按速度分开的剖面，并在开跑之前定好用哪种口径。

**θ 检查。**

- 看能不能从模型脑子里读回角度。
- 只记住能量的"偷懒解"完全读不回 sin θ，正常的表示能读回 99% 以上，两类分得很开。

## 11. 接缝比 v2（2026-11-12 JST，预注册 v2 清单第 2、3、6、14 条）

**为什么改。** 预注册审稿在真值上发现，v1 接缝比在两个校准没覆盖的区域偏向"粘合"：
- history = 2 时，切口窗口里 33–36% 的窗口两帧横跨切口。"错位撕开"的潜空间读出 SR 2.8–5，所有旗标都不报警。
- κ < 10 的 ω 各向异性下，撕开的弧读出 SR 2–5。

**改法**（`analysis/seam.py` 的 `seam_ratio_v2`，审稿人的修法 A + B）：
- 去掉跨切口窗口（`straddle_mask`：|θ_t − θ_{t−1}| > π）。
- 匹配容差改为 ω_tol = 0.08 / max(1, κ̂)，κ̂ 取自第一遍（默认容差）的 `omega_aspect`。
- 半宽 0.12 rad、分箱和阈值都不变。判定改为三分：粘合（SR ≤ 1.5）、部分（1.5 < SR ≤ 5）、撕开（SR > 5），见 `classify_seam3`。
- 每个 run 的最终判定由 PH × SR 一致性表给出（`seam_ph_consistency`）：
  - 判"粘合"要求 PH 判环（H1 = 1 且绕柱面）且 SR 判粘合；
  - 判"撕开"要求 PH 判无环（H1 = 0）、SR 判撕开且 κ ≤ 5；
  - 其余一律为不确定，包括分歧、"部分"、PH 不稳定、数据不足和折叠。

**校准**（`cells/0/calibrate_seam_v2.py`，原始数字在 `cells/0/calib_seam_v2.json`）：
- 只用真值图，新种子 `split_seed("analysis", 994_000 + r)`，r = 0..19，与以往所有校准、审稿种子不重叠。
- 每个种子都算 SR；r < 10 的核心图另跑 H1 规则。
- 图族：粘合 (cos θ, sin θ, κω)；完全撕开 (θ, κω)；错位撕开（跨切口窗口挪到旧帧的分支，挪动比例 λ = 0.5 或 1）；弧 α ∈ {0.97, 0.95, 0.9, 0.85, 0.8}；一阶折叠 (|θ|, ω)。κ ∈ {1, 2, 5, 9.5}。
- 规则在抽第一个种子之前写进脚本头部。

| 规则 | 要求 | 结果 |
|---|---|---|
| R1 粘合图（全部 κ） | SR_v2 ≤ 1.5 的比例 ≥ 95% | 80/80（中位数 1.00–1.01） |
| R2 完全撕开与错位撕开（全部 κ） | SR_v2 > 5 的比例 ≥ 95% | 240/240（中位数 44–46；v1 上错位撕开读 3–5） |
| R3 一致性表 | 核心图上从不判反 | 0 次判反。粘合图：75% 判粘合、25% 不确定；撕开图：60% 判撕开、40% 不确定（κ = 9.5 被 κ ≤ 5 规则判为不确定，另有 PH 失效） |
| R4 折叠 | 折叠旗标 ≥ 95%，且从不判粘合 | 20/20；一致性表 100% 不确定 |

**等效间隙查表**（弧族，SR_v2 中位数；v2 之后几乎不随 κ 变）：

| 间隙 | κ = 1 | κ = 2 | κ = 5 | κ = 9.5 |
|---|---|---|---|---|
| 0.19 | 2.37 | 2.39 | 2.40 | 2.45 |
| 0.33 | 3.33 | 3.35 | 3.38 | 3.46 |
| 0.69 | 5.85 | 5.90 | 5.96 | 6.12 |
| 1.07 | 8.52 | 8.59 | 8.69 | 8.93 |
| 1.47 | 11.3 | 11.4 | 11.5 | 11.9 |
| SR = 5 处的间隙 | 0.57 | 0.56 | 0.55 | 0.54 |

所以 v2 下，"部分粘合"（1.5 < SR ≤ 5）大约对应 0.19 ≲ 间隙 ≲ 0.55；间隙小于 0.19 的弧这次没有测，SR = 1.5 的位置在网格之外。v1 的弧读数随 κ 下降（κ = 9.5 时 α = 0.9 只读 2.2），v2 消除了这个依赖。

**结论：** v2 修好了审稿指出的两个偏向，阈值不变。下一步按预注册 v2 清单把 v2 接缝比写进计分脚本。
