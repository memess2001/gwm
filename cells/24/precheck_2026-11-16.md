## 1. 主张与类型

**一句话：** 用世界模型算从 s 出发 k 步内可达的集合 R_k(s)，它的 Betti 数第一次改变时的视界 k* 标出了障碍或门的距离；把 k* 处的状态当子目标，探索覆盖率会好于计数基线。

**类型：读数（readout）。** 几何不进模型（`fix: 世界模型`），只从模型的可达集读一个数。`cells.yaml` 写 `readout: plan`，是因为这个读数下游被拿去选子目标。按 R3：
- k* 这一半只能主张"更好的统计量"；
- 子目标那一半，要跟用同一个可达集的非拓扑子目标规则比，不能跟不用模型的计数基线比。

## 2. 恒等式：Betti 曲线 = BFS 距离场的子水平集同调

设 T 是任一确定性转移表，可以是真世界，也可以是学到的模型在每个 (状态, 动作) 上的预测。d_T(s, ·) 是在 T 上做 BFS 得到的最短步数。那么

R_{≤k}(s) = { s' : d_T(s, s') ≤ k }

这就是 BFS 第 k 层的定义。所以对任何复形读法，

β_i(R_{≤k}(s)) = β_i({ d_T(s, ·) ≤ k })

也就是 d_T(s, ·) 的子水平集持续同调。k* 是这个过滤里第一个出生或死亡的时刻，等于某个临界格 c 的 d_T(s, c)，或者再加一个与 s 无关的常数。

推论：
- **同源：** "用模型算 k 步可达集"和"在模型上跑 BFS"用的是同一组模型查询，即每个被访问状态的每个动作各查一次。所以 R2 的同源对照就是 d_T 本身，`cells.yaml` 写的 same_source（BFS 最短步数）不是稻草人，它和读数恒等。
- **随机模型：** 可达集要先对转移概率取阈值，在阈值后的支撑图上，恒等式照样成立。
- **拓扑最多能多给两样东西，都不需要拓扑就能得到：**
  - (a) 自由空间本身的同调，即有几个可以绕的障碍。这是地图的静态性质，不需要 k。
  - (b) 出生时刻所在的位置，即两路前沿在障碍背后汇合的格子（距离场的割迹）。它可以直接从 BFS 场读出来：下面环形迷宫里，k* 恰好等于障碍 4 个邻格 BFS 距离的最大值。

## 3. 真值核对（`precheck_betti.py`）

设置：
- 复形：把到达的格子当闭单位方格取并集，角接触也算连通。b0 是 8 连通分支数，b1 = b0 − χ，χ = V − E + F。
- 起点：toggle_grid 默认布局（房间 5×5，隐门），起点为房间 0 的 25 个格子，门初始关闭，K ≤ 80。

| 读法 | 1 / 2 / 3 门的结果 | 说明 |
|---|---|---|
| V1：位置，≤ k，含门格（最自然的读法） | Betti 曲线恒为 (1, 0)，**25/25 起点都没有 k*** | toggle_grid 的墙都连着外墙，自由空间单连通。门只是一格宽的瓶颈，不改变拓扑 |
| V2：位置，恰好 k 步 | 16 个贴墙起点从头到尾不变（变化次数中位数为 0）。9 个内部起点从 k = 1 起出现 1–5 个"洞"：二部网格上恰好 k 步只能到同奇偶的格子，例如 k = 1 时十字形的四格围住起点。等到能撞墙原地停留，k ≤ 6 时洞全部消失 | 奇偶伪迹，与门无关（都发生在走到门之前） |
| V3：全状态，每种门位模式算一层 | **k* = 第一次进开关的 BFS 步数，25/25 逐点相等**。它和到门的步数差常数 5（开关到门的 L1 距离），所以 Spearman = 1 | 标出的是开关（隐状态翻转），不是门。格 6 已经说明，检测开关的几何读数就是 HCDP |
| V4：位置，≤ k，把门格从复形里去掉 | **k* = 到房间 1 第一格的 BFS 步数 = 到门步数 + 1，25/25 逐点相等**，Spearman = 1 | 按构造成立 |
| 错模型：10% 的转移项随机改向（1 门） | V3、V4 的 k* 与**模型上的** BFS 仍逐点相等（Spearman 1.000），与真 BFS 降到 0.890 | 模型错在哪里，k* 就跟着错在哪里。k* 是 d_model 的函数 |
| 环形迷宫：门加第二个开口，自由空间的 Betti 数为 (1, 1) | b1 从 0 变 1 的 k* = 障碍 4 个邻格 BFS 距离的最大值，逐点相等。k* 对门距离的 Spearman 为 0.882，"过了" 0.8；对 min(门, 开口) 的 Spearman 为 1.000 | k* = min(到门, 到开口) + 2，每个起点都相等（另行核对过偏移恒为 2）。过关是因为 min(门, 开口) 本身与到门距离高度相关，与拓扑无关 |

补充（同一脚本的第一段输出）：toggle_grid 位置图的关节点（cut vertex，networkx / Tarjan，O(V + E)）恰好是每扇门的门格加两侧邻格，1、2、3 门都是这样。不需要视界参数就直接找到门。

## 4. R2：最强的廉价同源对照

**k* 部分：**
- 模型上的 BFS 距离场 d_model(s, ·)，用同一批查询；
- 从它直接读出的瓶颈量：关节点和前沿汇合点。

它们与读数恒等，或者严格包含读数的信息。

**子目标 / 探索部分：** 在同一个 R_{≤K}(s) 上用非拓扑规则选子目标，例如：
- 球内访问次数最少的状态；
- BFS 前沿（Go-Explore 式）；
- 关节点。

选好后沿 BFS 路径走过去。第二对照用格 12 的谱瓶颈（Fiedler 向量，Liang 2026）。

原预测里的对照"计数基线"不用模型，拿到的信息比 k* 方法少，违反 R2 修正 (2)（对照不能少拿信息）。k* 赢计数基线，只能说明有模型的规划赢了无模型的计数。

## 5. 结局是否已被定理或恒等式决定

是，由第 2 节的恒等式决定：
- **预测 1（Spearman > 0.8，< 0.4 判死）：** V3、V4 读法下是恒等式（Spearman = 1），V1 读法下 k* 不存在。在有环的迷宫里，k* 由"到各开口距离的最小值"决定。无论哪种，kill 判据都杀不了它；而且按 R1 修正 (2)，通过也不能记成拓扑多给了东西：主判据须含 (c)，k* 相对同源 BFS 的增量恒为 0。
- **预测 2（子目标优于计数）：** 胜负取决于对照选谁。对同源的 BFS 前沿或关节点子目标，k* 子目标只是 d_model 的一个特定函数。拓扑事件只发生在门、开关和环路处，而这些正是关节点和割迹所在。所以没有理由期待它更好；即使更好，也是"选了 d_model 的哪个函数"的差别，不是拓扑的贡献。

## 7. 判决：可以思想实验判

做法：
1. 写出恒等式 R_{≤k}(s) = { d_T(s, ·) ≤ k }，以及 β(k) = d_T 的子水平集同调。不需要算力。
2. 附上第 3 节的真值核对：
   - 自然读法下 Betti 曲线恒定；
   - 能产生 k* 的读法下，k* 与 BFS 逐点相等；
   - 用错模型时，k* 跟着模型的 BFS 走；
   - 有环时 k* = min(门, 开口) + 2。
3. 按 R1 (c) 与 R2：读数相对同源量的增量恒为 0。

**建议：** 记为 `thought_killed`，理由写"可达集 Betti 曲线 = 模型 BFS 距离的子水平集同调（恒等式）"。handoff 作者自审的"weak：k* 就是 BFS 距离"成立，而且结论比 weak 更强：这是恒等式。如果还想做"瓶颈当子目标"，那是格 12 的问题，以关节点和谱瓶颈为对照，拓扑版没有带来新东西。

**唯一不受恒等式约束的残余：** 连续状态空间里，可达集只能靠采样近似，PH 读的是样本点云，k* 会依赖采样量和尺度参数。这不是几何的优势，而是额外的估计误差；BFS 的连续版本（最短时间函数，或可达集的增长）同样能用。状态改动请 Z 定，本检查没有改 `cells.yaml`。
