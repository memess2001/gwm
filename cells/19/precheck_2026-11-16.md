# 格 19（切触哈密顿世界模型）写预注册前的预检（2026-11-16 JST）

**写给 Z。** 格 19 是 8 + 15 的合并：用切触哈密顿量 H(q, p, S) 当世界模型的潜动力学。

结论是，切触结构在**可观测**的 (q, p) 动力学上只剩一条约束：保形辛（conformally symplectic），也就是"HNN + 一个标量线性动量阻尼"。这有一个短定理。所以本格自审写的消融对照（HNN + 摩擦项）和它是**同一个函数族**，结局按恒等式打平。

`zoo` 的阻尼单摆恰好落在所有候选模型族的交集里，这里测不出切触带来的任何差别。能测出差别的世界都不在 `zoo` 里，而且谁赢由世界的摩擦律决定，不由切触几何决定。

**判决：可以思想实验判。**

## 大白话

1. **切触方程里多了一个 S。** 如果 S 不反过来影响 (q, p)（否则模型就要从历史里推一个看不见的隐变量），H 只能是 H₀(q, p) + γS。这时 S 只是记账变量，(q, p) 的动力学就是 ṗ = −∂H₀/∂q − γp：普通的哈密顿系统加一个常数系数的线性阻尼。
2. **单摆只有一个自由度。** 任何只依赖角度的力都是保守力，所以这个模型族又等于 Gruver 式的二阶模型 θ̈ = a(θ) − γθ̇。三个名字，同一个模型族。
3. **`zoo` 的阻尼单摆**（θ'' = −ω₀² sin θ − 2γθ'）正好是这个族里的一员：1000 个随机点上，切触向量场与 `zoo` 向量场的差为 0。D-HNN、port-Hamiltonian、自由 MLP 都包含它。所以实验只能比较"约束紧不紧"，比不出"切触几何"。
4. **读数部分也退化了。**
   - "耗散率 = ∂H/∂S"就是那个标量摩擦系数；
   - 格 15 的散度在这个族里被写死为常数 −nγ，模型读不出散度地图；
   - "S = 熵"有规范自由度（H₀ 加常数会改 S 的方程、不改 (q, p)），从数据里辨识不出来。

## 1. 主张与类型

**一句话：** 把世界模型的潜动力学约束为切触哈密顿流（H(q, p, S)，S 是 Bravetti 式的"熵 / 作用量"坐标），在耗散世界里能得到更稳的长程 rollout 和更准的能量衰减率，并由 ∂H/∂S 读出耗散率。

**类型：约束**（readout = predict）。按 R3，约束格靠消融证明自己。∂H/∂S 的读数是附带的，按 R3 属于预测分布的泛函（见 §4）。

## 2. 切触结构在可观测量上约束了什么（定理）

**切触哈密顿方程**（接触形式 dS − p·dq，n 个自由度）：

q̇ = ∂H/∂p，ṗ = −∂H/∂q − p ∂H/∂S，Ṡ = p·∂H/∂p − H

**定理：(q, p) 的动力学不依赖 S，当且仅当 H = H₀(q, p) + γS（γ 为常数）。**

证明：
1. ∂_S q̇ = ∂_S∂_p H = 0，所以 H = A(q, p) + B(q, S)。
2. ∂_S ṗ = −∂_q∂_S B − p ∂²_S B，要对所有 p 为零，所以 ∂²_S B = 0 且 ∂_q∂_S B = 0，即 B = γS + C(q)，C 并进 H₀。
3. 多自由度时逐分量同理。

sympy 核对见脚本第 1 节：H₀ + γS 时 ∂_S(q̇, ṗ) = 0；H₀ + γS²/2 时 ∂_S ṗ = −γp；H₀ + S·k(q) 时 ∂_S ṗ = −k′(q)。

**于是：**
- **S 不反馈时（世界模型从观测预测观测的通常情形），** 动力学是 q̇ = ∂H₀/∂p，ṗ = −∂H₀/∂q − γp。这是保形辛流（McLachlan & Perlmutter 2001 的 conformal Hamiltonian systems）：
  - 沿流 ω 按 e^{−γt} 收缩；
  - (q, p) 散度处处为 −nγ（脚本：n = 1 时为 −γ，n = 2 时为 −2γ）；
  - Lyapunov 谱成对：λ_i + λ_{2n+1−i} = −γ（Dressler 1988）。
  - S 只是记账：Ṡ = p·∂H₀/∂p − H₀ − γS。
- **S 反馈时，** S 是模型必须从历史里推断的一维隐状态。切触模型就成了"带一个额外隐坐标、耦合方式由单个标量函数 H 规定的增广 ODE"。
- **与坐标无关的内容。** 在潜空间坐标可以自由学的世界模型里，"存在某个辛形式使流保形辛"的必要条件是：
  - 每个不动点处 Jacobian 的迹相同（都等于 −nγ）；
  - 每条周期轨道（每个遍历不变测度）上的平均散度也等于 −nγ。

  一个自由度时，几乎只剩这一条。

## 3. 与各对照比较（R2：最强的廉价同源对照）

**最强的廉价同源对照：** Gruver 式二阶模型 q̈ = a(q) − γq̇，γ 是标量，用 Verlet 加精确的 e^{−γh} 阻尼分裂积分。它的输入、观测、模型查询与切触模型完全相同，不用任何辛 / 切触结构。

| 对照 | 与切触模型（S 不反馈）的关系 | 结局 |
|---|---|---|
| HNN + 标量线性摩擦（本格 self_review 写的消融对照） | 同一个函数族（§2 定理） | **打平，恒等式定** |
| 二阶模型 a(q) − γq̇（1 自由度） | 同一个函数族：一维里任何 a(q) 都是 −V′(q) | **打平，恒等式定** |
| port-Hamiltonian，R 为常数（单位质量） | ṗ = −∂_qH − γ∂_pH，∂H/∂p = p 时与切触相同；`zoo` 单摆就是这样 | 在 `zoo` 上打平 |
| D-HNN（学 Rayleigh 函数）、pH（学 R(x)）、PH-Dreamer、H-JEPA、ELWM | 严格更大的族，都包含 `zoo` 的真向量场 | 切触最多因为"约束更紧且恰好正确"而赢，这一点上面的二阶对照同样具备 |
| LeHami（守恒的 leapfrog） | 不能耗散 | 切触按构造赢，是稻草人；LeHami 加标量阻尼就是切触 |
| 自由 MLP、LeWM | 更大的族 | 同 D-HNN 那一行 |

**长程稳定性。** "rollout 比 HNN + 摩擦项稳"取决于积分器。保形辛积分器（阻尼的精确指数分裂加辛步；Bhatt, Floyd, Moore 2016；切触变分积分器 Vermeeren, Bravetti, Seri 2019）在离散时间里精确保持收缩率。把同一个积分器交给对照模型，两者就是同一个离散映射。对照若用 RK4，差别是积分器的消融，与切触几何无关。

## 4. 读数部分

- **能量衰减率。** 沿切触流 dH₀/dt = −γp·∂H₀/∂p。`zoo` 单摆上是 −γp²，与 `zoo` 的 dE/dt = −2γω² 一致（γ_contact = 2γ_zoo），对照模型给出同一个量。按 R3，它是预测分布的泛函，任何把动力学学对的模型都能读出来。
- **∂H/∂S = γ。** 这就是摩擦系数，一个拟合出来的标量。
- **"格 15 的散度成为推论"。** 在这个族里散度被写死为 −nγ，是假设而不是测量。在 friction_patch 这类散度不均匀的世界里，模型只会输出一个均匀值。
- **"S = 熵"有规范自由度。** H₀ → H₀ + k 不改 (q, p)，只把 Ṡ 改掉 −k（脚本第 3 节）；S(0) 也是自由的。切触力学里 S 是 Herglotz 作用量，不是耗散的热，从 (q, p) 数据里辨识不出来。

## 5. `zoo` 里有没有能测出差别的世界（回答问题）

**没有。** `zoo/pendulum.py`：θ'' = −ω₀² sin θ − 2γθ' + u，转动惯量为 1，所以动量 = 角速度。
- 取 H = p²/2 − ω₀² cos q + 2γS，切触向量场与 `Pendulum.vector_field` 在 1000 个随机状态（S 任取）上的最大差为 **0**（γ = 0.05、ω₀ = 1 与 γ = 0.3、ω₀ = 1.7 两组）。
- 散度 −2γ 与 `ground_truth()['divergence']` 一致。
- 力矩 u 是加性的（H 里加 −u·q），结论不变。

同一个向量场也是：
- port-Hamiltonian，R = diag(0, 2γ)；
- D-HNN，耗散函数 D = −γp²；
- 二阶模型 a(θ) − 2γθ̇。

所有候选模型族都包含真值，实验量到的是容量和正则强度，不是切触。

**能测出差别、但不在 `zoo` 里的世界（脚本第 4 节）：**

| 世界 | 不动点处 Jacobian 的迹（坐标无关） | 切触（S 不反馈）能否表示 | 谁赢由什么决定 |
|---|---|---|---|
| 双摆，关节粘性摩擦（−c·相对角速度），c = 1 | 下-下 −6，下-上 −2，上-下 −2，上-上 −6 | **不能**：没有任何坐标卡或辛形式能让它保形辛 | 摩擦律 |
| 双摆，与质量成正比的阻尼（−c·p） | 四个不动点都是 −2 | 能 | 摩擦律 |
| Van der Pol（μ = 1） | 原点 +1，极限环平均 −1.06 | 不能 | 切触必输 |
| friction_patch | 散度集中在补丁里 | 不能 | 切触必输 |
| S 真正参与动力学（H 对 S 非线性，类似 Nosé–Hoover 恒温器，Bravetti & Tapias 2016） | — | S 不反馈的模型不能；一般切触模型能，S 成为隐状态 | 只有世界按切触方程构造时才对。最强对照是"增广神经 ODE（多一维隐状态）"；没找到物理上自然、又恰好满足切触耦合的世界 |

**结论：** 每一种可测的情形，结局都由实验者选的世界决定（摩擦是否与质量成正比、有没有极限环），和格 9 的"机制 × 坐标卡"表是同一种情况。按 R1、R2，这不是几何主张。
