## 大白话

IGCI 判断因果方向的办法是：把两个变量都缩放到 [0, 1]，看谁的分布更均匀。原因更均匀，结果被机制挤压得更不均匀。所以它比的就是两个边缘分布的熵。

问题在于熵依赖刻度。把原因换一种单调的刻度（比如把 x 换成 x⁴），结论就可能翻转，而因果关系和所有预测都没变。世界模型的潜变量正好可以随意换单调刻度：编码器换了，转移和解码器跟着换，预测一点不变。所以在潜空间里读 IGCI，读到的是坐标怎么选的。

## 2. 恒等式

确定性、可逆的 Y = f(X)，两个变量都缩放到 [0, 1]（均匀参考测度）：

C(X → Y) = E[log f′(X)] = H(Y) − H(X)

判 X → Y 当且仅当 C < 0，也就是"结果的熵更低"（Daniusis 等 2010）。斜率估计和熵差是同一个量的两个估计器。用高斯参考测度（标准化）时同理，比的是两个边缘的非高斯性。

## 3. 真值核对

**A. 两个估计器一致**（X 均匀，Y = f(X)）：

| f | 斜率估计 C | H(Y) − H(X) | 判向 |
|---|---|---|---|
| x³ | −0.924 | −0.861 | X → Y，对 |
| √x | −0.183 | −0.197 | X → Y，对 |
| Beta(0.5, 2) 的分布函数 | −0.773 | −0.755 | X → Y，对 |

差别在估计器噪声以内。

**B. 换原因的刻度 X′ = g(X)。** 因果方向（X′ → Y）、机制（f∘g⁻¹）、所有预测都不变。

| g | C(X′ → Y) | 判向 |
|---|---|---|
| x | −0.861 | 对 |
| x² | −0.574 | 对 |
| x⁴ | +0.692 | **错** |
| x¹⁰ | +5.652 | **错** |

随机的机制 f 和随机的刻度 g（都取 Beta 分布函数）：原坐标上 300 个世界全部判对；换一个随机刻度后，153 个（51%）翻转。

**C. 平稳过程。** 圆周上的无理数旋转，三种刻度下 H(z_{t+1}) − H(z_t) 的绝对值都 ≤ 4e-4。平稳时 z_t 与 z_{t+1} 的边缘相同，任何刻度下 C 都是 0。

## 4. 三条预测的后果

- **(a)** 在观测变量上（没有刻度自由），这就是已发表的 IGCI（Daniusis 等 2010；Janzing 等 2012），在真实因果对上的基准评估见 Mooij 等 JMLR 2016。本格写的是"对学到的转移，在潜变量对之间算"，而潜变量的单调刻度是自由的（B 节），所以按 R3 第一层，读数测的是坐标选择。
- **(b)** 平稳数据上恒为 0（C 节）。暂态数据上它等于边缘微分熵随时间的变化；换刻度会给两个不同的边缘加上不同的 E[log g′]，在潜空间里同样是坐标选择。这与格 28 的死法相同（平稳态下统计量恒为 0）。
- **(c)** "沿真实因果方向分解的模型，在单个机制变化后适应更快"是 Bengio 等 2019 的前提，他们正是用适应速度判两个变量的因果方向（摘要已核）。用 IGCI、适应速度还是 ANM 去挑分解，是判向方法之间的比较，不涉及几何。在 mechanism_pair 世界里（不在动物园），哪种分解迁移更好由世界的构造决定。
