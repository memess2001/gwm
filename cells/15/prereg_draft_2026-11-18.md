## 0. 大白话

镜头斜着拍单摆时，从画面里量出来的"相空间体积变化"会出现一个假的耗散，比要测的真耗散大 5 到 9 倍。第一周发现一个不用标签的修法：把输入的几帧倒过来再量一次，两次取平均。假的那部分在时间反演下变号，被平均掉；摩擦造成的真耗散不变号，留下来。在精确的渲染器和精确的动力学上，这个修法把假的部分压到信号的 3% 以下。

还没回答的问题是：换成学到的世界模型，它还管用吗？学到的模型自己有误差，这些误差在时间反演下变不变号，没有定理能告诉我们，只能实验。这是 32 格里唯一一处不被恒等式事先决定、又可能对别人有用的地方。

## 1. 问题

**主问题。** 在学到的世界模型上，窗口反演对称化能否去掉观测映射造成的假散度，恢复真实的耗散（均匀的 −2γ，以及局部的耗散图）？它和"先在保守世界上标定、再相减"（rules.R5）比，谁更准？

**为什么不被恒等式决定。** 对称化在精确模型上恰好消掉 T 奇的分量，这是定理。学到的模型带来两类新误差：编码器 / 转移网络并不严格满足时间反演等变；网络自身的拟合误差宇称未知。审稿已测到：在等变渲染器上，学到的解码器自己就造出 0.09–0.16 的假散度（`dec_k00.out`、`dec_k00_long.out`），与信号 0.1 同量级。这些误差有多少在对称化下抵消，只能实验。

**同源对照（rules.R2）。**
- **与读数同一个量的：** 观测空间里沿轨迹的对数密度变化率 d log ρ/dt（Liouville：等于 −div）。它不用模型，只用数据。它带着同一个相机项，所以同样要做窗口反演对称化之后再比（`cells.yaml` 格 15 的 same_source，Code 复核的写法）。两者在无穷数据、精确模型下相等；有限数据下谁更准是"更好的统计量"之争，按 R3 预注册具体指标（§5 的 P15.4）。
- **真正的竞争者：** 标定后相减。在同一相机、同一架构下训练一个保守世界的模型，把它的读数从耗散世界的读数里减掉。它需要一个有标签的保守参照世界；对称化不需要。审稿指出学到的解码器会把相机项放大 10–20%，不可加，所以相减法要在至少两个伪迹强度上检查可加性（`rules.code_review.R5`）。
- **只作检查的：** 轨道平均散度（= Lyapunov 谱之和）不受相机影响、对潜空间重参数化不变，但 Wang 2026 / LeHami 已用过，而且它给不出局部的图。

## 2. 外部靶子：LeHami 式潜体积读数

LeHami（arXiv 2610.15267）用 (1/n)Σ log|det J(z_i)| 追踪 rollout 中的潜相体积，报告无约束的 LeWM 在保守单摆上持续收缩。这里有一个与相机无关、可以先写出来的混杂：

- 潜维数 d 大于状态维数 2 时，log|det J| 是 d 维体积的变化，包含数据流形法向的 d − 2 个方向。
- 一个把潜状态拉回数据流形的转移网络，在法向是收缩的；这在保守世界里也会发生，而且是好事（rollout 不离开流形）。
- 所以 d 维读数里的"收缩"可能来自法向，而不是流形上的假耗散。

**可证伪的预测（P15.5）：** 在保守世界上，无约束 JEPA 的 d 维潜体积读数的均值显示收缩；限制到数据流形切空间（切空间由潜点云的局部 PCA 估计，不用标签）之后，均值约为 0。若限制后仍显著收缩，LeHami 报告的"虚假收缩"就是流形上的，与法向无关。

用均值而不是逐点的大小：编码器在潜流形上诱导的面积元 ν_E 不是常数（VICReg 只约束全局协方差），所以即使转移完全保守，切空间读数在每一点上也等于 log ν_E 沿流的差分，逐点不为零；它是一个上边缘，在不变测度下均值为 0。LeHami 的读数本身也是均值。

## 3. 真值预检：便宜的观测能不能代替像素

`cells/15/exploratory/precheck_point_camera_proxy.py`：不用 64×64 像素，而是观测摆锤经过同一个倾斜相机后的像点位置（二维）。

| 相机 | 像点观测的假散度 RMS | 像素的假散度 RMS（审稿的 a_analytic） |
|---|---|---|
| 射影 k = 0 | 0.000 | 0.000 |
| 射影 k = 0.3 | 0.437 | 0.473（log a 的相关 0.999） |
| 射影 k = 0.6 | 0.938 | 0.906（相关 0.996） |
| 仿射，竖直压缩到 0.88 | 0.267 | 0（审稿：仿射不造假散度） |
| 仿射，竖直压缩到 0.54 | 1.266 | 0 |

- 射影相机下，像点观测几乎逐点重现像素的假散度。
- 仿射相机下两者不同：像素的范数带面积权重（a(θ)² = ∫|∂θI|²|det DH|ds，仿射时 |det DH| 是常数），像点的速度不带。

**对设计的后果：** 像点观测可以用来检验"对称化在学到的模型上是否还有效"（第一阶段，便宜）；"哪一类相机安全"的标定不能从像点搬到像素，要在像素上做（第二阶段）。

## 4. 设计

**世界。**
- 单摆，γ ∈ {0, 0.05}（真散度 0 与 −0.1，均匀）。
- **局部摩擦单摆（新世界）：** 阻尼随角度变化，γ(θ) = γ₀ · 光滑鼓包（例如中心 π/2、宽 0.5 rad，γ₀ = 0.2），真散度图是 −2γ(θ)。这是本格"耗散**图**"主张唯一像样的检验；动物园里没有，需要扩展 `zoo/pendulum.py`（约半天，含两套测试）。

**观测。**
- 第一阶段：像点观测，相机 = 射影 k ∈ {0, 0.3, 0.6}、仿射压缩到 0.54。需要给单摆加一个观测模式（约半天，含测试）。
- 第二阶段（第一阶段结论清楚、Z 再点头之后）：像素，相机 = 射影 k ∈ {0, 0.3}、仿射压缩到 0.54。

**窗口。** history = 3（对称窗口）。审稿的 check6：k = 0.3 时，三帧窗口的反演对称化在精确模型上把假项压到 0.0008，两帧窗口换序只到 0.014。

**模型。** baseline 的 recon（预测观测，读数在观测空间里算），尺寸 S、M，3 个种子，20k 步。P15.5 另用 jepa-sym（无解码器）。不加任何几何约束：本格的对象是读数，不是模型。

**读数**（全部在冻结的分析集上算，分析代码对条件不可见）：

| 读数 | 定义 |
|---|---|
| Ψ | recon 的一步窗口映射。解码器只输出当前帧（`baselines/mlp_wm.py` 的 `loss`：D(z_t) ≈ o_t），所以 Ψ(o_{t−2}, o_{t−1}, o_t) = (o_{t−1}, o_t, D(F(E(o_{t−2}, o_{t−1}, o_t))))，即平移后补上一帧预测 |
| M-raw | Ψ 在观测窗口流形二维切空间上的体积变化率：M-raw(w) = (1/Δt)·log\|det(U(Ψ(w))ᵀ · DΨ(w) · U(w))\|。U(w) 是 w 处切空间的正交基（观测窗口的局部 PCA），两侧用两个点各自的基；用同一点的基会因切平面转动多出 log cos 的假收缩。按真值 (θ, ω) 分箱成图 |
| M-sym | ½ [M-raw(w) + M-raw(R w)]，R w 是倒序的窗口 (o_t, o_{t−1}, o_{t−2}) |
| M-cal | M-raw(耗散世界) − M-raw(同相机、同架构的保守世界)，在同一个 (θ, ω) 箱上相减 |
| D-sym | 不用模型：观测窗口的 kNN 密度沿轨迹的对数变化率，再做同样的对称化（同源对照） |
| L-full / L-tan | P15.5：jepa-sym 潜转移 F 的 d 维 log\|det J\| 的均值（LeHami 的读数）；限制到潜点云局部 PCA 切空间的 (1/Δt)·log\|det(U(F(z))ᵀ J(z) U(z))\| 的均值 |

真值 (θ, ω) 只在分箱与计分时使用。

## 7. 风险

- **切空间估计的噪声**会在 M-raw 与 M-sym 里都引入误差；P15.0、P15.1 是它的检查。
- **倒序窗口不在耗散世界的训练分布上。** 保守世界时间反演对称，倒序窗口仍是合法的正向窗口；γ > 0 时倒序窗口对应反阻尼的运动，离训练分布 O(γΔt)。M-sym 要在这些窗口上用模型的 Jacobian，模型在那里是外推。P15.1 只用保守世界，查不出这一点；它会体现在 P15.2 的误差里。γ = 0.05 时偏离很小，但要在结果里单独报告：耗散世界上 M-raw(R w) 与保守世界同一 (θ, |ω|) 箱的差。
- **局部摩擦世界的参数**（鼓包位置、宽度、γ₀）在冻结前定，冻结后不改。
- **第一阶段的相机分级不能搬到像素**（§3）。第一阶段只回答"对称化在学到的模型上是否有效"。
- **LeHami 的时效：** 它把耗散留作后续工作（附录 C.4）。本格的价值在标定，不在抢先做耗散模型。
