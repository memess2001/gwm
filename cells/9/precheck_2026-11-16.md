结论：这一条没有几何专属的机制。在本格选定的世界（Wright–Fisher 计数）里，Fisher 时钟由恒等式决定：
- 噪声主导时，它就是墙钟加随机抖动；

## 大白话

1. **"在 τ 里训练、回墙钟评估"本身就是一个墙钟模型。** 它把向量场拆成"速率 × 单位方向"，训练样本按 τ 均匀分布。度量只决定"单位"按什么范数算，以及样本往哪里多放。任何弧长都一样。
2. **在 Wright–Fisher 里，噪声协方差恰好是 Fisher 度量的逆**（格 2 用过的同一事实）。所以每一步噪声贡献的 Fisher 弧长与状态无关，Fisher 时钟在噪声主导处就是墙钟。同时 Fisher 度量等于 √x 坐标里的欧氏度量，所以 Fisher 时钟恒等于 √ 变换后的欧氏弧长。这个对照不需要任何几何。
3. **不动点附近，所有弧长时钟都会停**（确定性情形），换回墙钟需要的 dt/dτ 发散，单位方向场在不动点处奇异。
   - Fisher 在单纯形顶点附近更糟：速率按 √距离 衰减，τ 有限时就撞到边界，τ 里的动力学不满足 Lipschitz 条件。
   - logit 坐标里，纯选择是匀速直线，墙钟本身就是最好的时钟。
4. 按 R1、R2，这和格 2 是同一类结局：几何读数等于一个同源的非几何量。不需要训练模型就能判。

## 2. "在 τ 里训练、回墙钟评估"是什么（回答问题 4）

设真动力学为 ẋ = f(x)，度量 G 下的弧长时钟 dτ/dt = r_G(x) = ‖f(x)‖_G。在 τ 里，dx/dτ = u_G(x) = f/‖f‖_G，是单位速度的方向场。

回墙钟评估：要预测 x(t + kΔt)，必须同时积分 dx/dτ = u 和 dτ/dt = r。合起来就是 **ẋ = r(x)·u(x)，仍是一个墙钟模型**，只是参数化成"速率 × 单位方向"。它和直接在墙钟里训练的模型只差三处：
1. **参数化**：f = r·u，‖u‖_G = 1；
2. **样本分布**：训练锚点按 τ 均匀，相当于每单位墙钟时间按 r_G 加权；
3. **离散化**：固定 Δτ 等于随速度自适应的 Δt。

G 只通过两处起作用："单位"按哪个范数算，以及加权往哪里偏。三处都对任何弧长成立，没有一处偏向 Fisher。

**墙钟评估需要的东西：**
- **一个速率模型 r̂(z) = dτ/dt。** Fisher 时钟定义在**后验**上，要用观测。开环 rollout 时没有后验，未来的 τ 算不出来，只能学一个速率头，或者改用先验的 σ（那是另一个时钟）。速率误差会直接变成时间误差。
- **连续 τ 的转移，或 τ 步之间的插值。** 墙钟目标点一般落在两个 τ 网格点之间。RSSM 式的固定步长模型要另加这一块。
- **两阶段训练。** τ 来自模型 A 的后验，再训练模型 B。按 R2，冻结 σ、惊奇等同源时钟都要取自同一个 A；墙钟条件也要用同样的两阶段预算，否则 B 比墙钟模型多拿了 A 的信息。
- **经验风险最小化的论证。** 评估风险是"墙钟均匀锚点上的 k 步误差"，直接最小化它的经验版就是墙钟训练。τ 训练把样本和容量挪向快的片段（协变量偏移）。容量无限时两者都收敛到真值；容量有限时，偏移的方向由度量决定，没有理由偏向 Fisher。

## 3. 不动点附近的时钟（回答问题 2）

**确定性路径（C 部分）：**

| 机制 → 不动点 | 时钟 | 速率 ∝ 距离^斜率 | 速率 < 最大值 1% 的墙钟时间占比 |
|---|---|---|---|
| 选择 → 顶点 | 欧氏 | +0.93（≈ 1） | 0.76 |
| | Fisher | **+0.44（≈ 1/2）** | 0.66 |
| | logit | **−0.01（常数）** | **0.00** |
| 迁移 → 内部点 m | 欧氏 / Fisher / logit | +1.00 / +0.99 / +0.99 | 0.85 / 0.84 / 0.84 |

（600 步，dt = 0.1，即 60 个时间单位。）

- **所有弧长时钟都会停。** 在 2/3 以上的墙钟时间里，时钟速率不到最大值的 1%，dt/dτ 跨好几个数量级。在 τ 里学、回墙钟评估时，大部分评估点落在 τ 几乎不动的区段，全靠速率模型外推。
- **单位方向场在不动点处奇异。** u = f/‖f‖ 在不动点没有定义，|∇u| ~ 1/距离。光滑网络在那里拟合不了，而 f 本身在不动点附近是线性的。这对任何度量都成立。
- **Fisher 在边界不动点更糟。** 靠近顶点时 ‖ẋ‖_G = √Var_x(f) ~ √距离，所以 dx_j/dτ ~ √x_j，即 d√x_j/dτ ≈ 常数。在 τ 里，种群在**有限 τ** 就撞上边界，τ 动力学在边界处不满足 Lipschitz 条件，解不唯一，边界在 τ 里也不再是不变集。墙钟里边界只被渐近逼近。
- **内部不动点处各度量局部等价**（斜率都是 1），Fisher 没有特殊之处。
- **随机情形：** 漂移消失，噪声不消失，时钟变成"噪声计数器"。Fisher 时钟这时就是墙钟（见 §5），欧氏时钟按杂合度加权。

## 4. logit 坐标（回答问题 3）

- **纯选择**：θ(t) = θ₀ + t·Δf，是 e-测地线，墙钟就是它的仿射参数。在 θ 坐标里，转移是常数向量场，最好学，最合适的时钟就是墙钟。logit 弧长 = 墙钟 × 每段一个常数（C 部分斜率 −0.01）。
- **Fisher 时钟在选择路径上的速率**：‖ẋ‖²_G = Σ x_i(f_i − f̄)² = Var_x(f)，这正是 Fisher 基本定理里的那个量。它随状态变化，在固定时趋于 0。所以 τ_F 把一条匀速直线弯成了变速曲线，模型反而要多学一个 r(x) = √Var_x(f)。
- **迁移**：x 坐标里的直线（m-测地线），速度指数衰减。用 x 的欧氏弧长重参数化后是匀速直线。
- **Fisher 的位置**：Fisher（α = 0，Levi-Civita）既不把选择变直，也不把迁移变直。哪个时钟最合适由机制 × 坐标卡决定，这就是 v0.6 里"Fisher 8 胜 1、欧氏 5、logit 2"背后的定理。

## 5. 恒等式：Wright–Fisher 里，Fisher 时钟 = 噪声区的墙钟 ⊕ 漂移区的 Hellinger 弧长

### 5.1 高斯滤波下 Fisher 时钟的分解

**设定。** 后验 N(μ_t, P_t)，转移先验 N(μ_{t+1|t}, P_prior)，更新后 N(μ_{t+1}, P_post)。卡尔曼更新给出 μ_{t+1} = μ_{t+1|t} + Kν，Cov(Kν) = P_prior − P_post。

**Fisher 时钟（只看均值部分）：**

E‖μ_{t+1} − μ_t‖²_{P_post⁻¹} = ‖μ_{t+1|t} − μ_t‖²_{P_post⁻¹} + tr(P_post⁻¹ P_prior) − d

**惊奇时钟：**

E KL[post ‖ prior] = ½ log det(P_prior P_post⁻¹)

两者的解读：
- Fisher 时钟 = 可预测漂移（用当地 σ 白化）+ 新息项；
- 惊奇时钟只有新息项；
- 两个新息项是**同一个矩阵** P_prior P_post⁻¹ 的两个函数（一维时分别是 r − 1 和 ½ log r）。
- 另有 2(dσ/σ)² 项，它在大 n 时可以忽略，c9_meanfield_chart 已说明它可能是平均场伪迹。

### 5.2 WF 的两种噪声都是 Fisher 型

- **一次多项式重抽样：** Cov(Δx) = (diag x − xxᵀ)/N，于是 E‖Δx_noise‖²_G = Σ_i x_i(1 − x_i)/(N x_i) = (K − 1)/N，**与状态无关**。
- **欧氏度量：** 同一噪声给出 H(x)/N，H 是杂合度。
- **计数观测：** 噪声协方差同样 ∝ diag x − xxᵀ。

所以理想滤波的后验协方差 ≈ c·G⁻¹(x)，c 是常数。新息项 ≈ (K − 1)[1/N − (1 − a²)c]/c，其中 a 是局部收缩因子，只在吸引不动点附近修正几十个百分点。**Fisher 时钟的噪声部分与状态无关**，速率就是墙钟。

### 5.3 Hellinger 恒等式

Shahshahani 线元满足 Σ dx_i²/x_i = 4 Σ (d√x_i)²。后验方差 ∝ μ(1 − μ) 时，后验 Fisher 时钟 = (1/√c) × 后验均值在 √x 坐标里的欧氏弧长，即 2|Δ√μ|。

### 5.4 数值（B 部分，精确滤波，去掉前 20 步烧入期）

三个情形：
- **噪声主导：** N = 100，n_obs = 100，s = 0.5，u = 0.1；
- **停在平衡点：** N = 2000，n_obs = 2000，s = 3，选择方向不变，大部分时间停在突变–选择平衡点；
- **来回横扫：** 同上参数，选择方向每 40 步翻转，种群来回横扫。

| | 噪声主导 | 停在平衡点 | 来回横扫 |
|---|---|---|---|
| 漂移² > 噪声的步数占比 | 0.01 | 0.00 | 0.55 |
| 后验方差 / μ(1−μ) 在 5 个 μ 分箱间的 CV | 0.021 | 0.012 | 0.028 |
| 单步增量² 的分箱剖面，Fisher（1 = 恒速） | 0.98–1.03 | 0.97–1.02 | 0.10 → 2.78 → 0.10 |

| Fisher 单步增量的 CV | 0.75 | 0.75 | 0.83 |

A 部分（`zoo`，K = 3，选择）：

- **噪声区，Fisher 时钟就是墙钟加抖动。** 单步增量的 CV 是 0.75，正好是半正态分布 |N(0,1)| 的 CV（0.756）。所以每一步 Fisher 增量就是一个噪声样本的模长。固定 Δτ 的 τ 网格等于由噪声决定的随机墙钟时刻。在 τ 里训练，相当于把加性噪声换成随机的时间变换，只会更难。

- **惊奇时钟处处是恒速。** 模型知道动力学时，它看不见可预测的漂移；横扫时它与 Fisher 几乎不相关（0.16）。

## 6. 最强同源对照（R2）与结局是否已定

**最强的廉价同源对照：后验均值（或平滑后的观测频率）在 √ 变换后的欧氏弧长。**
- 它用同一批样本、同一个模型查询 μ，不用 σ，比 Fisher 时钟少拿信息。
- 观测版就是 TOTR 加上计数数据的标准方差稳定变换（Anscombe）。
- 按 §5.3，它在 WF 里**恒等于** Fisher 时钟，相差一个常数。实测单步相关 0.998–1.000，累计时钟的 R² = 1.0000。

逐个对照的结局：

| 对照 | 与 Fisher 时钟的关系 | 结局 |
|---|---|---|
| √ 变换后的弧长（后验均值或观测） | 恒等（§5.3） | **打平，恒等式定** |
| 墙钟 | 噪声区：恒等加抖动（§5.2）；漂移区：Fisher 是一种弧长 | 噪声区打平或输（抖动）；漂移区是 TOTR 的通用问题 |
| 惊奇时钟 | 只有新息项，处处 ≈ 墙钟 | 同上 |
| 冻结 σ 白化欧氏 | 只差一个杂合度加权 | 符号随机制而变（§4），没有偏向 Fisher 的机制 |
| 观测空间欧氏弧长（未变换的 TOTR） | 同冻结 σ | 同上 |

关于 √ 变换的两点说明：
- **"√ 变换不就是 Fisher 几何换了个名字吗？"** 是的，Hellinger 嵌入就是 Fisher 几何。但 R2 问的是：不带几何主张的廉价做法（计数数据先做方差稳定变换）能不能做到一样好。在 WF 里它能，而且是恒等的，所以"模型内生的 Fisher 时钟"在这里没有多给任何东西。
- **重参数化不变性只是资格条件。** 这是 Fisher 时钟常被当作优点的地方，按 R1 的修正它只是资格，不是主张；而且观测空间的弧长（TOTR、√ 变换版）同样有这个性质。

## 7. 有没有几何专属的机制（回答问题 1）

逐个候选：

| 候选机制 | 是否几何专属 |
|---|---|
| 去掉速度、消除刚性、步长均匀化 | 否：任何弧长都有（TOTR 的地盘） |
| 对潜空间重参数化不变 | 否：观测空间弧长同样不变；而且只是资格条件（R1） |
| "等信息量"的样本分布 | 否：只是一种样本加权。没有定理把它和墙钟 k 步误差联系起来，经验风险最小化的论证反而偏向墙钟（§2） |
| 用当地 σ 归一化 | 在 WF 里恒等于 √ 变换（§5.3）。在别的世界里取决于模型自己的 σ，而 σ 由 ELBO / free nats 平衡决定（v0.4 notes (4)），不是世界的性质 |
| 不动点附近的行为 | 不利于所有弧长，Fisher 在边界上最差（§3） |

**结论：** 没有找到一个"Fisher 做到、而某个非几何的通用选择做不到"的机制。
