## ★ 结论先行（2026-11-03，草案写完之后做的计算型思想实验，如实披露）

写完下面的 v0 草案之后，我做了两个几秒钟的数值检查（脚本在 `cells/7/exploratory/`，输出在 `cells/7/alpha_check.txt`）：

1. **α-计的命题成立。** 在 K = 3、4、6 和 α ∈ {−2, −1, −0.5, 0, 0.5, 1, 2} 下直接积分 α-测地线方程。r((1−α)/2) 约为 1e-11（数值零），argmin 精确找回 α，对时间采样方式不敏感；选择段 → +1，迁移段 → −1。
2. **P7.2（连续性）在零噪声下就失败。** 40 组随机参数 × 11 个混合权重，结果如下：

| 读数 | Spearman(α̂, ρ) | α̂ ∈ [−1.2, 1.2] 的比例 | 其他 |
|---|---|---|---|
| 全局拟合 | 0.29 | 48% | 逐组参数的 Spearman 中位数 0.30 |
| 逐点"密切 α" | 0.42 | 53% | 5–95% 分位为 [−4.5, +5.1] |

单看一组参数也一样。例如 w = 0.5 → −2.1，w = 0.75 → +2.26，w = 0.9 → +1.0。对混合权重不单调，而 ρ 随 w 单调，所以这个失败与 ρ 怎么定义无关。

**原因（事后解释）：** α-联络对 α 是仿射的。α 只能吸收法向加速度里"沿 Amari–Chentsov 张量方向"的那一部分。混合场的加速度里有交叉项（DF_sel·F_mig − μ·F_sel），它不在这条线上。K = 3 时法空间是一维，任何曲线都能被"某个 α"逐点匹配，但这个 α 是两个标量之比，分母接近零时就爆掉。这就是看到的重尾。

**按 §5 事先写好的判定规则**（规则写在检查之前）：P7.2 失败 → "α 不是连续量，只剩二分检验 = 旧结论 → 不单独成文，降为格 2 的工具；novel → low"。P7.1（噪声下的二分）没有跑，但它在合理信噪比下几乎是定理，跑它不改变这个结论。

**我的建议：**
- 格 7 记为 `thought_killed`（被杀的是"连续 α-计"这一主张）。
- 二分 e/m 检验和 r_min（"不是直线"的检测）作为工具并入格 2。
- 格 3 的"三种直线"叙事里，e/m 一侧只保留二分版本。
- 第一个真正的 kill test 改做格 6。
- 如果 Z 认为还有别的连续读数值得试（比如直接拟合机制参数的"机制回归"，那已经不是几何了），可以再议。

**对抗审稿（2026-11-03，holds_with_caveats；脚本在 `cells/7/exploratory/reviewer/`）：**
- 命题 (A) 两个方向都已核实：几何上是归一化 α-混合路径，这是标准结论。
- 结论 (B) 成立，而且是**结构性**的，与估计器无关。混合轨迹在 w = 0 附近的一阶法向偏离对适应度向量 f 是奇函数，所以任何光滑、参数化不变的 α 读数，都会在一半的 f 方向上先跌到 −1 以下。审稿人测了 9 种读数（Fisher 加权 / 似然拟合、短窗、早段、密切 α、曲率回归、端点锚定、限制在 [−1, 1] 内，T 从 0.5 到 4），合并 Spearman 都只有 0.27–0.64，单调的参数组最多 35%。我用的无加权 SVD 是其中最弱的。另外，它在 λ = 0 处的定义不是 λ → 0 的极限，造成 3.6% 的读数恰好落在 +1。
- "只剩二分检验"说得太重。还剩一个分级的 e/m 残差对比 C = (√J_m − √J_e)/(√J_m + √J_e)（J 为 Fisher 加权残差）。它与 ρ 的 Spearman 为 0.75–0.78（200 组参数，按种子 0.70–0.85），略低于本草案的 0.8 门槛，而且在约 70% 的参数组里不严格单调。它是软的 e/m 分数，不是 α，作为工具并入格 2。复活条件中的"单调"应理解为严格单调。

## 0. 对原版 kill test 的意见（为什么要改）

原版判据是"α 估计恢复相位标签准确率 > 90%"。在精确频率上这是定理，不是实验：
纯选择段在自然参数 θ_i = log(x_i/x_K) 里严格共线，纯迁移段在混合参数 x 里严格共线（Fujiwara 1993 加上定义）。
拿真实频率去测，准确率必然是 100%，测不出任何东西，也正是审计说的"线性不是新意"。

所以本草案把判据放在三件**可以错**的事上：

1. **噪声下还准不准**：有限抽样（每代只数 n_obs 个个体）和有限种群漂变下，尺子的读数随信噪比怎么退化。交付一条曲线，不是一个数。
2. **是不是连续的尺子**：选择和迁移同时作用（mixed）时，α̂ 是否**单调地**落在 −1 和 +1 之间。这一条决定 α 是"一把能读数的尺子"，还是"只是一个是/否开关"（后者 = Fujiwara 级别的旧结论）。
3. **能不能报出"不是直线的世界"**：最优 α 处的残差 r_min 能否把 RPS（旋转）和直线类过程分开。这是它给格 2 当诊断前端的那一半。

## 1. 尺子的定义（锁定）

**记号**：Amari 约定，α = +1 ↔ e-联络（θ 中的直线），α = −1 ↔ m-联络（x 中的直线）。
Koide & van de Venn 2026 的符号相反，引用时换号。代码里只用 Amari 约定。

**命题**（本草案的技术核心；已数值验证，见 §9）：令 λ = (1−α)/2。单纯形上一组点落在同一条 α-测地线上
⟺ 逐分量幂 x_k^λ 张成一个**过原点的二维线性子空间**（λ → 0 的极限退化为 θ 共线）。
理由：α-联络在正测度空间里于 α-表示 x^λ 下是平坦的，单纯形的 Fisher 法方向就是径向（伸缩）方向，
所以单纯形上的 α-（前）测地线 = α-表示里过原点的平面与单纯形的交，也就是归一化的幂均值路径
x(s) ∝ [(1−s)p^λ + s q^λ]^{1/λ}（Amari 的 α-integration / α-mixture）。

两个读数：

- **快速版**：r(λ) = (Σ_{i≥3} σ_i²)^{1/2} / σ_2，σ_i 是矩阵 [x_k^λ]_k 的奇异值；λ = 0 时用中心化 θ 矩阵的 σ_2/σ_1。
  α̂_fast = 1 − 2·argmin_λ r(λ)。
- **主版本（带噪声）**：在幂均值路径族上做多项分布似然拟合（p、q 和每个观测的路径坐标 s_k 都是自由参数），
  对 λ 求 profile likelihood；α̂ = 1 − 2λ̂，95% 区间取自 profile likelihood。
  λ 网格取 [−1, 2]（α ∈ [−3, 3]），**允许 α̂ 落在 [−1, 1] 之外**。

两个版本都只看点集，不看时间间隔，所以对时间重参数化不变（这一点也要写测试验证）。
要求 K ≥ 3：K = 2 时一维单纯形上任何曲线对所有 α 都是测地线，尺子无定义。主实验 K = 3，副实验 K = 5。

## 2. 世界与数据

- 世界：`wright_fisher`，dt = 0.1；每段长 L ∈ {10, 20, 40} 个观测。
- 机制：selection / migration / mixed（两场相加）/ uniform mutation（= 向均匀分布迁移）/ rps。
- 噪声阶梯：观测抽样 n_obs ∈ {∞, 10⁴, 10³, 10²}；漂变 N ∈ {∞, 10⁴}。
- 信噪比的主变量是每段的 **Fisher–Rao 弧长 ℓ_FR**：参数随机抽，结果按 ℓ_FR 分箱报告。理由是短段在任何尺子下都分不开，不分箱的准确率没有意义。
- 种子：参数 seed 0–9，每个条件 200 段。Held-out seed 100–109 只在最后复查幸存者时用。

## 大白话

选择是"按比例放大"：每种类型的数量各乘一个固定倍数，它在"对数坐标"里走直线。
迁移是"往一个固定配比里掺"：它在"普通比例坐标"里走直线。
这两件事是定理，拿准确数据去考它没意义。

真正的问题有两个。

1. 数据有抽样噪声时，还认不认得出是哪一种？
2. 两种过程同时发生时，尺子的读数是不是平滑地落在两头之间？

如果第 2 条成立，它就是一把能读"世界有多像在做选择"的连续尺子，这是新的。
如果不成立，它只是一个是/否开关。那是 1993 年就有的结论，不值得单独做。
