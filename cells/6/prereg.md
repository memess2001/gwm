## 1. 问题，以及几何主张在哪里

和乐读数：从同一个潜状态 z 出发，沿一个观测闭合的环路 γ 走一圈，与一条同样步数、不进开关的参照环路比较，看两者预测出的未来观测是否不同。真值上，它不为零当且仅当环路进开关奇数次。

v0 审稿指出，这个读数本身是历史可分辨性检验，也就是 HCDP 的诊断指纹（Zhang et al. 2026-07），没有几何内容。只要模型学对了，它就会成功。所以本格分两层：

1. **读数层**（P6.1–P6.3）：在学到的模型上，读数能否探测奇偶隐状态、能否无标签地把来源定位到开关、对零和乐的对照是否特异。这一层基本由模型质量决定，主要作用是确认流水线和模型没有问题。
2. **几何层**（P6.6，共同主判据）：基于环路结构的读数（环路和乐、小方格曲率图），是否比同样规范不变的非几何探测器多给东西。非几何探测器就是 `same_source`（rules.R2）：两段非环路历史停在同一观测上，比较它们的预测未来；定位则对"差异由哪一步制造"做归因。按 rules.R3，本格只能主张"更好的统计量"（AUC、定位精度、数据效率），不能主张"看到了更多信息"。

和乐与非几何基线打平，几何主张即判死，本格并入 HCDP（`merged_into:HCDP`）。

"H_obs ≠ 0"的准确含义：模型的预测未来依赖沿 γ 的历史，而不只依赖当前观测。路径无关的额外信息（例如 o_0 或时钟）给出 H_obs = 0。

## 2. 世界、条件与数据档

世界：`toggle_grid`，n_doors = 1，房间内部 5×5，episode 63 步转移（64 帧），从 R0 开局。开关在 (2, 2)，门在 (6, 3)，门左邻格是 (5, 3)。

| 条件 | 世界参数 | 数据策略 | 隐藏位 | 作用 |
|---|---|---|---|---|
| H-act | 默认（门隐藏、开局门关） | active | 1 | **主条件**：P6.1、P6.2、P6.6 |
| H-pc | 同上 | passive_cover | 1 | P6.5 |
| H-pn | 同上 | passive_nocover | 1 | P6.5（正确的不可辨识） |
| C-open | `switches_enabled=False, init_doors=(1,)` | active | 0 | P6.3 同构对照：门常开，开关失效 |
| C-vis | `door_visible=True` | active | 0 | P6.3 对照：门的状态可见 |

审稿指出 `switches_enabled=False` 加门关的对照根本走不出 R0，所以这里用门常开的版本。"开关不可见"条件删除（清单第 5 条）：开关标记是静态输入，会被第一层偏置吸收，对模型没有作用。"读标记"的定位器（precision@4 = 1）是写明的平凡基线，不需要跑。

**数据策略**（`c6lib.sample_policy`，固定）：
- **passive_cover**：均匀随机动作，等同于 zoo 的 `random`。
- **passive_nocover**：均匀随机，但在门左邻格上，"右"换成上 / 下 / 左中均匀的一个。门从不被尝试，隐藏位从不可观测。
- **active**：环路拼接（随机游走 U{2..8} 步，再贪心最短返回，同 zoo 的 `loops`）；每闭合一个环路，以概率 p_home 做一次 homing 探针：走最短路到门左邻格，再"右"一次。
- **p_home 的固定规则**：从 {0, 0.005, 0.01, 0.015, 0.02, 0.03, 0.05, 0.1} 里取一个值，使隐藏世界在匹配种子（`SPLIT_SEEDS["train"] + 777`，不参与训练）上 2000 条 episode 的开门尝试次数最接近 passive_cover 在同一种子上的次数，平局取小值。结果是 **p_home = 0.01**（223 次对 213 次）。粗网格 {0, 0.1, …} 会选到 0：主动档的环路很短，10% 的 homing 已经给出 5 倍的开门次数。

**操纵检查**（训练前核对，`cells/6/manipulation_check.json`，训练种子，2000 条 episode）：

| 条件 | 开门尝试 | 门开时尝试 | 进开关 1 / 2 / 3 次后的尝试 | R0 外帧比例 |
|---|---|---|---|---|
| H-act | 1570 | 234 | 173 / 82 / 33 | 0.8% |
| H-pc | 1139 | 220 | 149 / 103 / 58 | 1.6% |
| H-pn | 0 | 0 | 0 / 0 / 0 | 0% |
| C-open | 1331 | 1331 | 169 / 75 / 33 | 4.6% |
| C-vis | 1570 | 234 | 173 / 82 / 33 | 0.8% |

所以 H-act 与 H-pc 的覆盖按事先选定的指标（门开时的尝试）匹配，P6.5 的"覆盖匹配"条件成立。H-pn 没有任何开门尝试。

**规模：** train 2000 条 episode，种子 `SPLIT_SEEDS["train"]`；val 200 条，种子 `SPLIT_SEEDS["val"]`。数据种子与模型种子无关。数据效率附加 run（只用 H-act）：train 250 与 500 条，同一数据种子。

## 3. 模型与训练

- baseline 的 recon 变体，history = 1，转移 F(z, onehot(a)) 为残差 MLP，d = 8，尺寸 S（10.0 万参数）与 M（50.0 万参数），种子 0 / 1 / 2。
- 整段开环：`anchors="episode"`，horizon 63，K = 63。λ_lat = 0：一致性目标 E(o_t) 不含门的状态，λ_lat > 0 会把潜变量往"不带隐状态"的方向拉。
- AdamW，lr 1e-3，batch 128，CPU 单线程，4 个 run 并行。
- **所有潜变量都来自 `model.rollout(E(o_0), actions)`。** `baselines.encode` 是无记忆的 E(o_t)，在 λ_lat = 0 下只在 o_0 上训练过，不能用。

**步数由 pilot 决定（固定规则）：**
- pilot：H-act、尺寸 S、种子 99（不在主种子里），10k 步，约 20 分钟。只看训练损失和 gate，计分脚本拒绝对 pilot 计算任何读数（`c6_score.py` 里写死）。
- 若 pilot 在 10k 步时通过 gate（§4），全部 run 用 10k 步。
- 否则再跑一次 20k 步的 pilot（种子 99）。通过就全部用 20k 步。
- 仍不通过，就**停**，把 pilot 的 gate 结果交给 Z：这说明按现在的数据档，模型学不会数奇偶。改数据或模型都算清单外偏离。

## 4. Gate（脚本化的平衡事件集）

审稿指出原 gate 下门开的比例只有 12–17%，"门开当且仅当进过开关"这条启发式就能拿到 95.6%。所以改为脚本化的平衡事件集（`c6lib.gate_set`，种子 `SPLIT_SEEDS["analysis"] + 602`）：

- 每个事件 episode 从 R0 开局，先走 U{0..30} 步不进开关的随机前缀，再恰好进开关 n 次（n ∈ {0, 1, 2, 3}），然后走到门左邻格，尝试"右"。总长 ≤ 63。
- 每个 n 200 个事件，共 800 个。门的状态 = n mod 2（C-open 例外：门常开）。
- **门 gate**：对最后那次尝试之后的一帧，用解码帧中智能体通道的 argmax 给位置打分。每个 n 的正确率都 ≥ 0.95 才算通过。
- **位置 gate**：这 800 个 episode 里其余所有步的位置正确率 ≥ 0.95。
- H-pn 只用位置 gate（它的数据里没有开门尝试，门 gate 没有定义）；其余条件两个 gate 都要过。
- 真值检查（`tests/test_holonomy.py`）：真值预测器通过；无记忆预测器在 n = 1 上正确率为 0；"进过就算开"的预测器在 n = 2 上正确率为 0。
- 副读数：所有 run 的分层 AUC 对 gate 正确率作表。

## 5. 分析集与读数

所有查询都在真值模拟器上构造，只依赖种子（`c6lib.analysis_set`，缓存在 `runs/c6/_sets/`）。

**z 的取法：** 从 R0 开局，走 U{0..15} 步均匀随机前缀，得到 z；z 不在开关格上。评估集 100 个 z（种子 `SPLIT_SEEDS["analysis"] + 600`），校准集 50 个 z（种子 `+ 601`，只用于 P6.3 的阈值）。

**环路**（每个 z）：用构造法生成，进开关的次数是精确的（`holonomy.constructive_path`）：
- 16 条奇数环路：进开关 1 次或 3 次，各一半。
- 16 条"≥ 2 次的偶数环路"：恰好进 2 次。
- 8 条零环路：不进开关。

构造过程是：不进开关的随机游走 U{2..8} 步 → n 次"走到开关、进入、离开、0–2 步不进开关的游走" → 不进开关的最短路回到起点。环路总长 ≤ 28，所以前缀 + 环路 + 探针 ≤ 15 + 28 + 20 = 63，不超出训练时程（清单第 8 条）。标签是 zoo `holonomy()['flips']`（"从别的格到达开关"才算进入）。

**时间匹配的参照分支：** 每条环路 γ 配一条步数相同、不进开关的位置闭合环路 γ₀，先生成零环路，再插入撞墙动作（状态不变；门格不算墙）补齐步数（`holonomy.null_reference`）。读数比较的是 F_γ z 与 F_γ₀ z，两个分支走过的开环步数相同，模型随时间的漂移不会混进读数。

**探针集 Π**（`holonomy.probe_set`）：64 条长 20 步的均匀随机动作序列，种子 60064，与位置无关。审稿人在真值上算过：64 条随机探针检出隐藏位的概率在每个 R0 格上都 ≥ 0.94。"走到门前尝试通过"的探针利用了"隐藏位在哪里变得可观测"的知识，只作 oracle 上界的副读数。

**主读数 M2（观测和乐）：** H_obs(γ, z) = max over π ∈ Π of（20 个探针帧里，两个分支 argmax 解码出的智能体位置不同的帧所占比例）。门可见的世界里，"位置不同或解码出的门位不同"都算不同。读数只用解码出的观测，对潜空间重参数化不变。副读数：探针取平均而不是取最大；M1 = ‖F_γ z − F_γ₀ z‖ / s（s 是 gate 集 rollout 上一步潜位移的中位数），M1 对漂移敏感，只作描述。

**曲率图（P6.2）：** R0 的 16 个小方格。对每个 z、每个小方格：沿不进开关的最短路把 z 运到该小方格的一个非开关角（离 z 最近的那个，平局随机），然后顺时针走一圈。参照分支走同样的运送路径，再做 4 步"出去—回来—出去—回来"（邻格既不是开关也不是门）。小方格的分数是 H_obs 在 100 个 z 上的平均。真值：含开关的小方格恰好 4 个，随机排序的 precision@4 = 0.25。R1 的 16 个小方格作副读数（运送路径走完整动力学，可以经过开关和门）。

**非几何基线（P6.6，rules.R2 的 same_source）：**
- **探测：** 每个 z 取 40 对历史（16 对奇、16 对偶 ≥ 2、8 对零），两段都是从 z 出发的构造路径，进开关次数为 (n₁, n₂)，终点是同一个随机 R0 格（不是开关，也不是 z 自己所在的格）。较短的一段用撞墙补齐。奇 = n₁ − n₂ 为奇数，取自 {(1,0), (0,1), (1,2), (2,1)}；偶 ≥ 2 取自 {(1,1), (2,0), (0,2), (2,2)}。分数是两段历史预测未来的 H_obs，与环路读数同一个统计量、同一组探针。
- **定位：** 每个 z 取 16 对无标签的通用历史（与 16 个小方格的查询预算相同）：h₁ 是 U{4..12} 步均匀随机游走；h₂ 是另一段独立的随机游走，再走最短路到 h₁ 的终点格；较短的一段用撞墙补齐。对每个 R0 格，算"两段历史进入该格次数的奇偶差"与该对 H_obs 的 Pearson 相关，作为该格的归因分数。小方格的分数是它四个格的分数之和。

**同分布模型检查（"死"的前提，清单第 11 条）：** 沿评估集环路分支 A 的全部探针 rollout，比较模型解码的位置与真值。两种正确率都要 ≥ 0.95：一是全部帧，二是"位比特敏感帧"，即真值位置会随门的状态改变的那些帧。只看全部帧不够：无记忆的真值预测器在全部帧上有 0.97，在位比特敏感帧上只有 0.59。

**分析单位：** 按 z 聚类。区间一律用 z 层面的聚类 bootstrap（2000 次）。

**长度分层：** 环路总长分四层 [4,10]、[11,16]、[17,22]、[23,28]。分层 AUC = 各层 Mann–Whitney AUC（平局计 1/2）的加权平均，权重 = 该层正例数 × 负例数，缺一类的层跳过。

## 6. 预测与判据

| 编号 | 内容 | 角色 |
|---|---|---|
| P6.1 | H-act 上，H_obs 区分"奇数次进入"与"≥ 2 次的偶数次进入"的分层 AUC ≥ 0.90。按 run 判，每个尺寸 ≥ 2/3 个种子成立（gate 不过的种子记为不成立）。S 与 M 都要成立 | **主判据**（读数层） |
| P6.2 | H-act 上，R0 的 16 个小方格按分数取前 4，与 4 个含开关小方格重合的 precision@4 ≥ 0.75。按 run 判，每个尺寸 ≥ 2/3 个种子；S 与 M 都要成立 | **主判据**（读数层） |
| P6.3 | 阈值 τ = 同一 (尺寸, 种子) 的 H-act run 在校准集"≥ 2 次偶数环路"上 H_obs 的 95 分位。三组超阈比例的 95% 上界（z 聚类 bootstrap 的 95 分位）都 ≤ 0.10：(a) 同一 run 评估集上的 ≥ 2 次偶数环路与零环路；(b) 配对的 C-open run 的全部观测闭合环路；(c) 配对的 C-vis run 的观测闭合环路（偶数次与零次）。对照 run 的 gate 不过记为不成立。每个尺寸 ≥ 2/3 个种子；S 与 M 都要成立 | **主判据**（读数层，特异性） |
| P6.6 | 几何层：只在读数层通过时才有意义，结果照常记录。差值按 gate 通过的种子取中位数，每个尺寸单独算。和乐必须在同一项指标上、在 S 与 M 两个尺寸上都以写死的幅度胜出：(i) 分层 AUC 比基线高 ≥ 0.05；(ii) R0 precision@4 比基线高 ≥ 0.25；(iii) 数据效率：设 N_req = {250, 500, 2000} 中最小的训练集大小，使 ≥ 2/3 个种子达到阈值（探测看 AUC ≥ 0.90，定位看 precision@4 ≥ 0.75；这里不看 gate，因为两种读数读的是同一批模型），要求 N_req(和乐) ≤ N_req(基线) / 2，基线始终达不到而和乐达到也算胜出 | **共同主判据**（几何层） |
| P6.5 | 覆盖才是关键：每个尺寸上，H-act 与 H-pc 的分层 AUC（种子中位数）之差绝对值 ≤ 0.05，且 H-pn 的分层 AUC ≤ 0.6。H-act − H-pc > 0.10 则 P6.5 被证伪（两档覆盖已按规则匹配）。H-pn 的 AUC > 0.6 标红：读数报出了没有数据依据的差异 | 副 |

## 7. 判定表（预先写死，`c6_score.aggregate`）

**一个尺寸可评判**，当且仅当 H-act 的 3 个种子里至少 2 个过 gate。对每个尺寸，先给出状态：

| 尺寸状态 | 条件 |
|---|---|
| NE | 不可评判 |
| PASS | 可评判，且 P6.1、P6.2、P6.3 都成立（各自 ≥ 2/3 个种子） |
| FAIL_CHECKED | 可评判，至少一条不成立，且同分布模型检查成立（≥ 2/3 个种子） |
| FAIL_UNCHECKED | 可评判，至少一条不成立，且同分布模型检查不成立 |

读数层的判定由 (S 的状态, M 的状态) 决定：

| S \ M | PASS | FAIL_CHECKED | FAIL_UNCHECKED | NE |
|---|---|---|---|---|
| **PASS** | 读数有效 | 不确定 | 不确定 | 不确定 |
| **FAIL_CHECKED** | 不确定 | 读数死 | 读数死 | 读数死 |
| **FAIL_UNCHECKED** | 不确定 | 读数死 | 不确定 | 不确定 |
| **NE** | 不确定 | 读数死 | 不确定 | 不确定（模型学不会） |

记录"读数死"时，同时写明是哪条不成立。"P6.1 与 P6.2 成立、只有 P6.3 不成立"单独标注为"读数不特异"。

最后的状态：

| 读数层 | 几何层（P6.6） | `cells.yaml` 格 6 的 status |
|---|---|---|
| 读数有效 | 胜出 | `alive` |
| 读数有效 | 没有胜出（含打平） | `merged_into:HCDP`（Zhang et al. 2026-07） |
| 读数死 | — | `dead` |
| 不确定 | — | 不变，notes 写明哪一格不确定 |

v0 里"换带记忆的滤波器 WM 重跑"的兜底已删除，所有这类情况一律记为不确定。

## 9. 预算与时间盒

- **run 清单：** 主实验 5 个条件 × 2 个尺寸 × 3 个种子 = 30 次；数据效率 H-act × {250, 500} × 2 个尺寸 × 3 个种子 = 12 次。共 42 次，另加 1–2 次 pilot。
- **计时**（`results/bench_cpu.md`，整段开环 K = 63，单线程）：S 约 0.108 s/步，10k 步约 18 分钟；M 约 0.306 s/步，10k 步约 51 分钟。42 次约 24 个单线程机时，4 个并行约 6–7 小时（机器空闲时）。若 pilot 定为 20k 步则加倍。
- **计分：** 每个 run 在 S 上约 2–5 分钟，M 更久。
- **时间盒：** 实现（已完成）之后，计算与分析 1 天，pilot 定为 20k 步则 2 天。

## 11. 风险

- **模型学不会数奇偶。** H-act 上进开关 2 次、3 次后的开门尝试只有 82 次和 33 次。pilot 的 gate 会先暴露这个问题，规则见 §3。
- **64 步开环 BPTT 不稳定。** gate 会抓出来，结果记为不确定，不会误判为死。
- **读数层几乎由 gate 推出。** 这是设计上已知的（§1），所以真正能错的是 P6.3 和 P6.6。
- **基线和环路读数在离散网格上可能完全等价。** 这正是要检验的命题：打平即并入 HCDP。

## 12. 大白话

在一个房间里绕一圈回到原地，看到的和出发时一样，但如果路上踩过开关，门的状态就变了。好的世界模型应该记得这件事：从"绕过一圈"的状态出发，它预测的未来会和"没绕"时不一样。这个"看起来回到原点，其实没有"的量就是和乐。

这个实验要回答两层问题：

1. 不给任何标签，单靠模型自己的预测，能不能挑出"踩了奇数次开关"的那些圈？能不能把"弯曲"定位到开关所在的那几个小方格上？
2. 更关键的一层：一个更笨的办法也能做到吗？这个办法不用圈，只是比较两段"走法不同、停在同一处"的历史，看模型的预测有没有分歧，再看分歧来自哪一步。如果它一样好，"几何"就只是给一个已知的检验换了个名字，这一格就并入已有的工作（HCDP）。
