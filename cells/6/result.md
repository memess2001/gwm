## 大白话

**读数层有效。** 训练好的模型上，和乐读数能分清"进开关奇数次"与"偶数次"的环路（AUC 约 0.997），不看标签也能把来源定位到开关所在的 4 个小方格（precision@4 = 1.0），在门常开、门可见两个对照上都不误报。

**几何层没有胜出。** 不走环路的非几何基线，即 rules.R2 的 same_source、HCDP 式的"两段历史停在同一处、比较预测未来"，几乎一样好：
- AUC 只差 0.012，写死的门槛是 0.05；
- 定位两者都是 1.0；
- 数据效率两者一样；
- 在 500 条训练数据时，基线的定位还更好（1.0 对 0.75）。

按 §7，状态改为 `merged_into:HCDP`：环路结构没有给出比非几何检测器更好的统计量，这个读数就是 HCDP 的诊断指纹。

**要说清楚的一点：** 这个最终状态只有在 v1.4 下才可达。v1.3 要求 S 与 M 两个尺寸都 PASS；S 的 pilot 从没过门 gate，按 v1.3 的表这次会判"不确定"。Z 认可 v1.4 时看过 §13 的"判据变宽松了"一段，审稿记录的非阻塞问题 (1) 也写明 v1.4 新开放的最终状态正是 alive 与 merged_into:HCDP。结论只对尺寸 M、20k 步、3 个种子中 2 个过 gate 的情况成立。

| 种子 | gate | 模型检查 | 分层 AUC（95% CI） | precision@4（R0） | τ |
|---|---|---|---|---|---|
| 0 | 过 | 0.972 | 0.998（0.996–1.000） | 1.00 | 0.00 |

| 2 | 不过 | 0.674 | 0.627（0.610–0.645） | 1.00 | 0.95 |

**P6.3（特异性），超阈比例：** 下表是 H > τ 的点估计与 95% 上界，判据为上界 ≤ 0.10。

| 种子 | 同 run 零环路 | C-open 全部环路 | C-vis 环路 | 同 run ≥ 2 次偶数环路（只报告） |
|---|---|---|---|---|
| 0 | 0.010 / 0.023 | 0.025 / 0.049 | 0.004 / 0.008 | 0.018 / 0.034 |
| 1 | 0.023 / 0.043 | 0.024 / 0.046 | 0.004 / 0.011 | 0.026 / 0.046 |

注意：种子 0、1 的 τ = 0。H_obs 在校准集 ≥ 2 次偶数环路上至少 95% 恰好为 0，所以特异性判据实际上是"H_obs 不为零的环路比例 ≤ 10%"。H ≥ τ 的比例因此恒为 1，这一列没有信息。这是按预注册的定义算出来的，不是偏离，但读者应当知道阈值退化到了 0。

**对照模型检查：** C-vis 种子 1、2 的模型检查是 0.940 / 0.939，低于 0.95。按 §6，这只影响"P6.3 不成立时算不算已检查"；P6.3 成立，所以不影响判定。但 C-vis 这一组的特异性证据，来自一个本身没完全过模型检查的对照模型。

## P6.5 与副读数（描述）

- **P6.5：** 分层 AUC 的种子中位数：
  - H-act 0.996，H-pc 0.508，H-pn 0.501，H-act − H-pc = 0.488；
  - H-pn 没有标红（≤ 0.6）；
  - H-pc 的 3 个种子都没过门 gate（门正确率 0.32–0.53），所以这个差值主要反映 H-pc 没学会门，不是覆盖本身的作用。两档覆盖本来就不匹配（§2），不作检验。
- **H-pn：** 按 §4 只用位置 gate，3 个种子都过。它的数据里没有开门尝试，模型学成"门永远关着"：门在 n = 1、3 时正确率为 0，n = 0、2 时为 1，符合预期。
- **来源还是后果：** H-act 过 gate 的种子里，两个门邻接小方格的排名是 (7, 9) 与 (7, 10)，都没进前 4，读数定位到的是来源（开关），不是后果（门）。门邻接小方格进前 4（具名失败模式"定位到的是隐状态的后果"）的有 6 个 run：n = 250 的三个与 H-pc 的三个，都没过门 gate。同样没过门 gate 的 n = 500 三个与 H-act 种子 2 没有进前 4。所以这个失败模式只出现在没学会门的模型上。
- **其余读数（H-act 种子 0 / 1）：**
  - 合并 AUC 0.999 / 0.997；
  - 探针取平均 0.998 / 0.997；
  - oracle 探针 0.998 / 0.999；
  - M1（潜空间距离，对漂移敏感）0.999 / 0.999；
  - R1 里没有开关，precision 无定义，分数存在各 run 的 `scores.npz`。
- **对照：**
  - C-open：AUC 0.503–0.504，P@4 0.25，等于随机；
  - C-vis：AUC 1.000，P@4 1.00。
- **AUC 对 gate 正确率：** 所有门 gate 不过的 run，AUC 都在 0.49–0.55，只有 H-act 种子 2（门正确率 0.91 / 0.56 / 0.69）读到 0.63。读数层的成败基本由模型有没有学会门决定，与 §1 的预期一致。
